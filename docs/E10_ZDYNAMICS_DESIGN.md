# E10 设计稿 v1：隐空间动力学辅助监督（z-dynamics）

> 状态：**草案，待教师评审**。源自用户 2026-09-15 提出的想法，经两轮澄清定形。
> 判决线预先承诺：与冠军同配方单变量对照，best val mean_edge > **+0.1003** 才算有效，否则弃案。

## 一、需求背景（为什么走到这一步）

**原始需求**：商品期货盘中信号辅助人工交易——模型喊"多/空/观望"并给出 θ 上下轨，
用户自己判断是否执行。不需要收益率预测，只要方向 + 可解释边界。

**当前冠军**：E3 v1.1（KLineTransformer，13 品种 × 60/30m 混训，当日收盘锚定
first-passage 三分类 + 路径状态辅助头），val mean_edge s42=+0.1003 / s7=+0.1262，
单仓回测 +10.06%、成本加倍 +7.24%，前向实盘记录中（live/forward_log.csv）。

**核心瓶颈（P1 诊断坐实）**：标签信息量稀薄——三分类 ~1.5 bit/样本、90% 为"无"，
冠军第 2~4 epoch 即峰值，此后只剩过拟合；lr/调度/batch 三嫌疑均已排除。

**已证伪的方向（判决档案见 docs/PRODUCTION.md）**：

| 方向 | 实验 | 判决 |
|---|---|---|
| 对比学习预训练（噪声不变性） | E7-aug0：probe 0.350 < 随机 0.385 | ❌ 噪声不变性把方向信号当噪声抹掉 |
| 自回归预训练（预测下一根 bar） | E7-B：微调 +0.0661 vs 冠军 +0.1003 | ❌ 有害（-34%），特化迁移失败 |
| linear probe 仪器本身 | 冠军表示 0.383 ≈ 随机 0.385（两次复现） | ❌ 标签信息高度非线性，仪器作废 |
| 标签视野拉长 | T+1 次日收盘：+0.0749 vs 冠军 +0.1003 | ❌ 信号短时效，拉长只稀释 |

**归纳出的信号画像**：薄（1.5 bit/样本）、短时效（集中近端）、非线性（线性读不出）。
三个方向（表示侧预训练、视野拉长）都已封死，剩下唯一未探的大方向 =
**提高每个样本的监督密度，且监督必须与"未来"同向**。

## 二、用户原始想法（逐字演化记录）

1. 初版：窗口 a，未来 K 线 b，训练一个 c 使 a+c=b（由 E7-A 加噪实验反向启发——不加噪，
   直接学"从现在到未来的变换"）
2. 澄清一：**b 是 a 的"投影"而非价格空间的残差延续**——即变换发生在表示空间：
   z_a = 编码(历史)，z_b = 编码(未来)，学 z_a + c ≈ z_b
3. 澄清二：c 应是**复杂的非线性变换**，不是简单向量加法
4. 扩展：5m/日K/周K 多频率都可纳入；训练对用**前后相同根数**的对称窗口

## 三、方案定形（v1）

**名称**：隐空间动力学辅助监督（z-dynamics auxiliary），JEPA/BYOL 家族——
不预测原始价格，预测**未来的表示**；监督与标签天然同向（first-passage 标签本就是未来路径的函数）。

**结构**：

```
主任务（冠军配方逐项不动，一行不改）：
  [日K×20][外盘日K×20][分钟窗口 N 根] → 主干 → 三分类头 + 路径状态头

辅助动力学头（新增，唯一变量）：
  z_a = 主干表示(过去 N 根)                    ← 学生侧，回传梯度
  z_b = 主干表示(未来 N 根)  + stop-gradient   ← 教师侧，只看不改
  ẑ_b = z_a + MLP(z_a)                          ← 残差非线性变换（BYOL predictor 结构）
  L_dyn = MSE(ẑ_b, sg(z_b)) + λ_var · 方差正则
```

**防坍缩三件套**（E7-A InfoNCE 崩到 0.038 的教训，坍缩是这个家族的标准死法）：

1. 未来侧 stop-gradient（教师编码不被辅助损失修改）
2. 学生侧非对称预测头（残差 MLP，恒等路径保留 → c→0 时退化为"未来=现在"的安全吸引盆）
3. 表示方差正则（逐维度 std 下界惩罚，从损失上堵死"全部映射到同一点"的解）

**数据**：训练段内构造对称 (a, b) 对，N = 主窗口长度（60m≈35 / 30m≈60，约一周）；
b 超出本段的样本辅助损失 mask 掉，主任务样本不受影响。标签免费（未来数据不需要标注）。

**损失**：L = L_冠军配方 + λ_dyn · L_dyn，λ_dyn = 0.1（与 path_aux 同量级，
避免 E4 excursion 辅助头反噬主任务的前科）。

**与已死实验的界限（防重复归因）**：

- ≠ E7-A：E7-A 学"对噪声不变"，本方案学"向未来对齐"，目标方向相反
- ≠ E7-B：E7-B 在**价格空间**预测**下一根**；本方案在**表示空间**预测**未来一周**，
  监督密度差两个量级，且 E7-B 是预训练（路线已封存），本方案是监督训练内的辅助头
- ≠ E4：E4 辅助头（excursion 分桶）语义与主任务冲突；本方案的预测目标与
  主标签的信息源完全相同（都是未来路径），无语义冲突

**明确不做的（v1 收缩纪律）**：预训练形态不复活；多频率动力学（5m/周K 各自的 z_a→z_b）
留作第二个变量；λ_dyn 扫描等首发判决后再说。

## 四、判决协议（预先承诺）

1. 与冠军逐项同配方（seed 42），唯一变量 = 辅助动力学头
2. best val mean_edge > +0.1003 → 有效，加 seed 7 确认后进入生产口径回测判决
3. ≤ +0.1003 → 弃案封存，进族谱
4. 辅助头自身的 z_b 预测误差只作诊断，不作判决依据

## 五、想请教师判断的问题

1. **坍缩防护是否足够**？stop-grad + 非对称头 + 方差正则三件套在"学生教师共享同一主干"
   （而非 BYOL 的 EMA 双塔）下是否仍然成立？共享主干有没有隐性坍缩通道？
2. **z_b 应取哪个位置**？我们默认取主干 last readout（与主任务同位置）；教师是否认为
   应该池化整段未来序列（mean-pool）以避免"只对齐未来末尾"的短视？
3. **方差正则的强度**有没有先验参考？我们计划逐维 std 下界 0.1（归一化表示上），
   过强会不会把表示撑爆、干扰主任务？
4. **对称窗口 N=一周** vs 与主标签对齐的"到当日收盘"变长窗口：我们选了对称（任务难度一致），
   但代价是辅助任务视野（一周）长于主标签（平均半天），教师是否认为这是错配？
5. 若本方案也失败，"提高监督密度"这条路是否还有别的形态值得试（如直接分位数回归头），
   还是应当接受"该数据集上监督信号已榨干"并转向数据扩容（E8：ru/au 新品种）？
