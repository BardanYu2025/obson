# Macro History768：固定已有读取器，检验共同粗路径能否帮助状态

2026-10-01。接[同状态读出复核](BABEL_GROUNDED_READOUT768_REVIEW.md)。上一轮已经证明部分历史内容可以从现有状态读出；本轮不再从随机辅助头起步，直接研究编码器是否能在保留价量信息的同时形成更稳定、可复用的共同历史内容。

## 唯一假设与既有实验的区别

**用已会读历史、且参数固定的接口来约束较长区间的物理内容，能否改善原768维状态？** 冻结辅助读取器，使它无法通过自己改权重来掩盖状态变化；原价量查询头仍照常训练，所以三组都保留原重建适配能力。

不是全新注意力架构，也不是声称解码一致性从没做过。History Structure已经做过同周期粗路径损失，Cross Period做过短链接变化一致性，Shared History自由64维头有忽略区间的反例，Grounded History新头资格失败。这里将三点合并为一次有界检验：已验证原读取器的冻结副本、较长且严格同物理节点的粗路径、内容监督与对齐的独立同期对照。不能将结果单因归功于其中某一项；本轮不另扫冻结方式、区间长度、层数或权重。

如果仍需牺牲原信息或用途才能改善共同路径，收束这条辅助路径配方，不继续自动追加读头或一致性网格。

## 模型和三组对照

起点为Shared History `control_s42/s43`各自验证best（100/99），通过已完成Grounded Readout报告和完整原始来源链校验。保持768维、4层、8头、原28维输入、原局部诊断与原历史查询头。删除不参与原输出的自由辅助头；先严格恢复全部源参数再移除，不使用`strict=False`。

辅助读取器是各自源历史查询头的独立冻结副本，仍只接收一个bar状态。它不会读取真实价格、原始bar、其他视图状态，也不会接受目标作为输入。无新可训练辅助模块。辅助梯度通过冻结函数返回编码器；冻结参数不等于切断输入梯度。

| 分支 | 原编码器／原查询头训练 | 进入编码器的新增项 |
|---|---|---|
| control | 原价量重建继续 | 无 |
| content | 同上 | 0.10 × 固定读取器的真实共同粗路径误差 |
| aligned | 同上 | content项，再加0.01 × 共同粗路径一致性 |

辅助项不更新原可训练查询头。control也计算辅助诊断，但不给编码器梯度。原总损失保留：查询价格0.4/0.2/0.1、成交持仓活动0.3，远历史结构1.0，断开编码器梯度的局部头0.25。主线没有放弃成交和持仓信息，也没有新增未来行情标签。

## 查询的物理含义

三视图为较早细周期A、当前细周期B、粗周期C。同合约、经原始OHLCV/OI聚合核验的链接定义真正共同收盘节点。训练的两个不相交查询为粗窗口索引`[79,95)`和`[95,111)`，每段覆盖16个粗bar槽位；较早窗口移位只取1/16。所有辅助节点必须早于三个状态的当前bar。

对每段实际核验到的节点按时间排序，至少8个；均分为四个顺序组，每组至少2个节点。同一个查询的A/B/C使用完全相同节点、分组及权重。**这四组不保证等时长**，也不是对缺失收盘价插值。30→60受交易时段边界影响，固定四等宽小格会大量丢弃有效样本；当前几何选择依据原始支持度，在看新模型结果前固定。报告保留所有坐标和mask。

读取器先恢复各历史节点相对当前的价格坐标，再减去自己预测的最早共同节点作为原点。共同当前锚点会消去；不把真实锚点喂入解码器。得到四组平均相对价格与三个相邻组变化，共7个有物理定义的数值。真实目标使用相同节点和运算；A/B/C的物理目标逐批检查一致（原log-percent单位绝对／相对容差均2e-5）。

每个查询除以`训练集close delta_scale × sqrt(共同区间跨度的细bar根数)`。三个视图采用同一尺度；不按每段实际波动归一化，因此保留幅度信息。价格组与变化组各占一半MSE；两查询及三视图等权。对齐项为同周期A/B与15→30的B/C误差平均。它不是自由latent距离，不需要人为要求有效秩64。

这些是共同**采样粗路径**，不能代表全部宏观形态，更不等同于头肩顶等模式已经被识别；四组均值可能丢失组内转折。

## 一次命令的完整流程

1. 来源／源码／数据锁、磁盘检查；按原数值路径回放原模型分数。
2. 零拟合、零更新的固定读取器验证：对两个种子，三个视图分别比较真实区间、问错区间及零变化基线。两个查询真实内容差异足够的样本上，正确误差须至少低10%，合约bootstrap2000次的95%上界小于0，至少50行／5合约。错误查询转换回目标查询的相同尺度。仅使用既有验证时间分区；不拿研究集调准入。
3. 两种子都过则自动进入六组训练；否则退出3／blocked并打包完整预测，编码器不更新。不进行新头预热。
4. 六组各100轮、每轮4800组三视图、有效batch128、38更新。同种子完全相同抽样／移位／中途prefix／学习率；编码器和局部头3e-5、原查询头3e-4，原warmup/cosine。合计600轮／22800次更新，不拿100轮新组与原累计训练直接判架构胜负。
各组对齐的是来源、数据曝光和更新预算。辅助分支多了经冻结读取器的反向计算，不能声称相同FLOPs或GPU小时；各组实际耗时和峰值显存独立记录。

5. 原价格保护／近期与远期minimax选模，epoch0回退；保存全部best与last，锁定全部选择以后再评价。支持断点续跑、完成后仅核验，以及只重跑评价。

默认最多两worker、micro16。先做零更新反向与真实CUDA峰值预检；两worker不够显存但一个能放下时自动串行，batch及预算不变；一个也放不下则在更新前停止。磁盘按实际权重／优化器估计，绝不自动删除源文件。记录分项损失、梯度范数／夹角、裁剪及实际编码器首步位移；夹角不能当作无退化保证。

## 评价、成功与停止

保留原全部价格、近远历史、当前字段、成交／持仓和用途协议：12个best/last状态、13个任务各5个训练／验证正则候选，共780次解析拟合；原744项信息／用途比较不放宽。评价采用新组自己的原查询头，同时用**固定源查询头**读取新状态的共同粗路径，避免辅助读取器适配制造虚假进步。

粗路径研究采用保留索引`[75,91)`／`[91,107)`及shift8；几何不同但与训练片段有重叠，不能称完全未见历史。本轮训练链接仅15→30，研究分开报告15→30与30→60。此前已反复使用这些研究集，区间未校正多重比较，不能写成独立泛化证明。

- content相对同预算control：每视图实际粗路径误差至少改善5%。
- aligned相对content：同／跨周期差异至少下降10%。
- 两候选实际粗路径误差相对各自对照及源模型不超过5%退化；保持胜过零变化与错误区间的内容检查，不能靠两边都变平取胜。
- 两种子、best/last、两研究集及15→30／30→60均检验；配对整合约重采样。每对照同时满足原信息和活动保护，才记有限的共同粗路径候选；还要原状态用途改善才记表示用途候选。两周期都有时新增464项，原744项保留；如15→60有支持另外披露。
- 完成固定矩阵后停止，不自动晋升主模型、扩大网格或续训；小的辅助loss不代表模型成功。
