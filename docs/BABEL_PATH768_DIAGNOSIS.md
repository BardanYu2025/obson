# 768路径退步：旧报告复算与本轮问题

2026-09-24。只复算已交付报告及既有原始数据，不进行本地神经训练或真实模型推理。来源归档：`babel_bar_alignment_reports.tar.gz`，SHA256 `13a6c20c8b66a18c32ca8aa1b7fdb4acdc9cefdc12c0949e0df84f847e1f77fd`。原品种984个窗口、跨品种453个窗口均保留。下表为各自原验证选择的best；所有原始晋升失败记录继续有效。

768_joint的综合误差相对512降低25.41%/28.34%。同一全局解码后裁取近期16根，综合误差为0.271646/0.183149，512为0.344625/0.230524。不能把“没有通过全部保留门槛”说成“没有进步”。

## 2. 退步并非均匀发生于全部窗口

定义每个窗口`delta = path_MSE(768_joint) - path_MSE(512_endpoint)`。正向退步总量为`sum(max(delta,0))`；最大窗口占比的分母不是净退步，也不是全部误差。

| 研究集 / 种子 | 512路径MSE | 768_joint路径MSE | 路径改善窗口比例 | 最大窗口占正向退步总量 |
|---|---:|---:|---:|---:|
| 原品种 / 42 | 0.02253813 | 0.02239503 | 73.48% | 47.11% |
| 原品种 / 43 | 0.01959360 | 0.02231822 | 78.05% | 67.17% |
| 跨品种 / 42 | 0.00324586 | 0.00167119 | 70.86% | 47.74% |
| 跨品种 / 43 | 0.00259957 | 0.00299859 | 77.48% | 84.56% |

种子43原品种的最大退步窗口是`ag/60/SHFE.ag2606`、端点2026-02-11 14:00：窗口路径MSE从8.04925到12.54492。跨品种最大是`au/60/SHFE.au2606`、端点2026-02-25 00:00：从0.27446到0.76742。原品种第二、三大退步还包括MA60与ag15，不能归结为只有一个品种/周期的问题。

两个大窗口在当前数据中的历史价格变化确实较大。按原定义、排除当前bar，ag窗口相对窗口前收盘的累计对数百分比变化范围约[-52.264,4.698]，历史价格最大/最小约1.768；au对应约[-21.162,-3.007]、价格比1.236。这只是对所给数据的复算，不是对行情真实性的外部核实。对数百分比变化不能直接解释为普通收益率。

这些窗口必须继续纳入评价；不能删贵金属、删大波动窗口、按研究集重新拟合尺度或只展示中位数。现象提示检查幅度与累计路径的保留，但不能单凭此确定是水平偏移、漂移还是局部形状错误。旧归档仅保存少量完整重建样例，本轮会对全部窗口输出三项误差分解。

## 3. 第200轮并没有证据证明已经收敛

| 验证路径MSE | 180轮 | 200轮 |
|---|---:|---:|
| 512_endpoint / 42 | 0.003220 | 0.002984 |
| 768_joint / 42 | 0.002497 | 0.002363 |
| 512_endpoint / 43 | 0.003730 | 0.003626 |
| 768_joint / 43 | 0.003146 | 0.002711 |

第200轮768_joint的验证路径误差比同轮512低20.80%/25.23%；180到200轮仍下降约5.36%/13.80%。两个joint父模型都由原综合验证分数选中200轮。种子43单独路径最小值在187轮，但不能据此事后改用新的选择器并沿用旧门槛。

768_endpoint与768_joint之间也不是所有路径指标同向：joint相对endpoint在原品种种子42、跨品种种子43的均值更差，另外两个更好。因此还不能把尾部问题唯一归因于维度或局部监督。

## 4. 收敛到一个可检验的问题

旧模型需要从单步gap/body和EMA等摘要学会保留累计路径；累计路径本来就是当前窗口已经观察到的信息。检验把它作为一个显式因果输入，是否能帮助固定768表示保留幅度，属于同信息下的归纳偏置改变，不增加未来信息，也不直接把目标绕过embedding送入解码器。

只做`control/path × seed42/43`四组：同一200轮父模型、恢复优化器和RNG、各追加100轮、只改变一个零初始化路径投影是否开启。control用于隔离额外训练收益，原512用于保留检查。先冻结协议再接收新结果，详见[BABEL_PATH768.md](BABEL_PATH768.md)。

自查边界：本分析和实现由同一执行者完成，不冒称独立同行评审；现有研究集已被多次查看，这一实验不能充当最终独立泛化确认。补新数据仍有最终确认价值，但用户已明确它不是继续当前研究的前置条件。
