# E7-A 设计稿 v2：K线双视图一致性自监督预训练

> 状态：v2，已按教师模型 2026-09-14 评审收紧。待最终批准后实现。
>
> **归因声明**：E7-A 是原始 E7（分钟窗口 ↔ 日K/外盘跨模态 CLIP）的**收缩版**。
> 原 E7 因假负样本坑被否决，E7-A 改为"同一完整窗口的两种扰动视图"，
> 与原 E7 不是同一个实验，结果不得互相归因（MIDTERM_REVIEW.md 已同步注明）。
>
> 动机已由 P1 诊断坐实：三分类标签 ~1.5 bit/样本、90% 为"无"，
> 第 1~4 epoch 榨干，改 lr/调度/batch 均无效（见 MIDTERM_REVIEW.md 第六节）。

## 一、一句话方案

用**训练段**全部无标签 K 线窗口预训练 encoder：
**同一个时间窗口的两种扰动视图，encoder 的表示必须相近；不重叠、不同语义的窗口表示必须相远。**
预训练后先过**表征探针门禁**，再进入微调；微调、选模、评测口径与冠军完全一致。

## 二、为什么是这个变体

- 直接 CLIP 式跨模态对齐（分钟 ↔ 日K/外盘）被否决：正确配对稀疏，时间邻近窗口互为假负样本。
- 同窗口双增强是视觉领域最稳的范式（SimCLR/MoCo），正样本定义严格 = 同一窗口。
- 不引入新模型、新数据，只引入新的**训练目标**；主干架构一行不改。

## 三、视图构造（先审计，后训练；最小增强起步）

### 3.1 增强语义合法性审计（第一步，不训练下游）

对固定样本生成多个扰动版本，纯统计检验（不调任何模型）：

- 窗口累计收益变化 / 末端价格相对变化
- 最大正向/反向 excursion 变化
- 波动率分位变化
- 趋势方向代理是否翻转
- 末 3 根 close-path 锚定是否变化
- 是否影响时间特征和 causal mask

**判决只看语义破坏率，不看下游收益**——增强强度不允许由测试期/生产收益反推
（否则等于在测试期上调参）。

### 3.2 收益率抖动的定义（修正 v1 的含糊处）

```text
r'_t = r_t + ε_t
ε_t ~ N(0, α · σ_window / sqrt(L))
```

- `σ_window` = 该窗口原始收益率标准差；`L` = 分钟窗口长度
- `α` = **窗口级总扰动强度**（不是每根 bar 独立放大）
- 审计扫描 `α ∈ {0.02, 0.05, 0.10}`；若 α=0.10 造成明显 regime 翻转，直接淘汰

### 3.3 增强阶梯（一次一变量，禁止组合搜索）

```text
E7-A0：仅轻微收益率抖动（审计通过的中低强度）     ← 首轮唯一方案
E7-A1：+ 5% 时间遮蔽（短连续块，禁遮窗口末端关键 bar，只遮数值通道不动时间位）
E7-A2：+ 10% 时间遮蔽
（通道丢弃、幅度缩放默认关闭，以后再说）
```

### 3.4 禁止的增强

时间反转、bar 乱序、窗口裁剪（改变标签语义 / 破坏 causal 结构）。

### 3.5 正负样本规则（v2 收紧）

- **正样本对**：同一窗口的视图 A ↔ 视图 B。唯一。
- **负样本**：同 batch 内其他窗口，但：
  - **输入窗口存在 bar 重叠的样本不得互为负样本**（v2 新增，替代 v1 的"5 交易日"粗规则）
  - 跨品种负样本保留，但**必须单独报告 symbol probe**，防止模型只学品种身份
  - 可选进一步收紧：batch 内同品种分层采样、跨品种负样本降权（先不做，看 probe 再说）

## 四、架构与损失

- 主干：现有 KLineTransformer **一行不改**（保护冠军架构）。
- 预训练头：encoder 输出 → 2 层 MLP → 128 维 → L2 归一化；**预训练后丢弃**。
- 损失：NT-Xent（InfoNCE），τ=0.1 起步；τ ∈ {0.05, 0.1, 0.2} 是唯一预训练超参扫描。
- 预训练训练量：20 epoch 或对比损失平台期即停，单 seed 先行。

## 五、数据协议（严格版，v2 钉死）

```text
预训练：仅训练段无标签窗口（按窗口锚点日期切分，锚点落在训练段外的一律不取）
预训练 checkpoint 选择：训练段内部指标或固定 epoch，不用验证段
微调：训练段
早停 / E7-A1/A2 方案选择：验证段
最终评测：测试段，方案冻结后只跑一次
```

旁支实验（可选、隔离命名）：

```text
E7-transductive：预训练用训练+验证+测试全部无标签窗口。
只回答"如果允许用所有历史行情，工程收益是多少"，
不得进入冠军判决，不得与严格版混报。
```

## 六、表征探针门禁（v2 新增，微调前的预先承诺）

预训练完成后**先不做完整微调**，冻结 encoder 跑三个 linear probe：

1. label probe：预测三分类标签
2. path probe：预测路径状态
3. symbol probe：预测 symbol_id（+regime 可选）

门禁规则：

- label probe **相对 scratch baseline 明显下降（>5%）** → 判定一致性目标抹掉了方向信息，
  E7 路线暂停，不进入微调（v2 按我的保留意见：probe 是线性读数，轻微下降不枪毙，
  但必须记录幅度）
- symbol probe 接近满分而 label probe 不提升 → 判定模型只学了品种身份，
  回头收紧负样本设计，不算 E7 路线失败
- 通过后进入微调，两个变体共用**同一预训练 checkpoint、同一套增强、同一 τ**：
  - E7-A1：主干全解冻，lr 1e-4
  - E7-A2：主干半冻结（前 4 层冻住），lr 3e-4
- 微调选模/早停/生产回测口径与冠军完全一致，双 seed（42/7）

## 七、判决线（v2 三层，预先承诺）

**A. 扶正**（生产口径，双 seed 均须通过）：

```text
单仓收益 ≥ 冠军 + 0.5 个百分点（> +10.56%）
成本加倍 ≥ 冠军 + 0.5 个百分点（> +7.74%）
最大回撤 ≤ 2.5%
信号数 ≥ 冠军的 50%
p 品种不出现明显拖累
```

**B. 表征有效但不扶正**（保留为后续实验底座）：

```text
相对 scratch baseline：方向 probe 或 mean_edge 有稳定改善（双 seed）
且生产口径无系统性恶化、成本加倍不转负、回撤不超上限
```

**C. 弃案**（须区分两种失败，禁止模糊封存）：

```text
表示失败：probe 门禁不过 → E7 自监督路线暂停
适配失败：probe 过但 A1/A2 微调都不行 → 保留预训练底座，另做适配实验
```

## 八、已知风险（v2 更新）

1. ~~增强语义污染~~ → 已由 3.1 审计前置处理，审计不过不进训练
2. **一致性抹掉方向信号**（根本风险）→ 不由 InfoNCE loss 判断，
   由第六节 probe 门禁判断；symbol probe 异常主导单独诊断
3. 计算量：预训练 ≈ 1.5 次正常训练时长，AutoDL 单卡可承受
4. 表示空间可能学成"时间排序"而非"形态分类"——不视为 bug，但 probe 结果要留意

## 九、不做清单

- 不做跨模态 CLIP —— 假负样本坑，已否决
- 不做掩码重建（MAE 式）—— 留作 E7-B 候选，一次一变量
- 不改主干架构、不改标签、不改评测口径
- 不做增强组合搜索 —— 按 3.3 阶梯一次一变量
