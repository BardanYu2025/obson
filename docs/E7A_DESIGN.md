# E7-A 设计稿：K线双视图一致性自监督预训练

> 状态：待教师模型排雷 → 批准后实现。
> 动机已由 P1 诊断坐实：三分类标签 ~1.5 bit/样本、90% 为"无"，
> 第 1~4 epoch 榨干，改 lr/调度/batch 均无效（见 MIDTERM_REVIEW.md 第六节）。
> 唯一未试过的突破口 = 标签之外的信息源。

## 一、一句话方案

用全部 5 年 K 线（几十万窗口，**不需要标签**）先预训练 encoder：
**同一个时间窗口的两种扰动视图，encoder 的表示必须相近；不同窗口的表示必须相远。**
然后冻结/低 lr 微调主干，接回现有的三分类头 + 路径状态头，其余全部沿用冠军配方。

## 二、为什么是这个变体（而不是别的）

- 教师模型否决了直接 CLIP 式跨模态对齐（分钟窗口 ↔ 日K/外盘）：
  两种模态的"正确配对"稀疏，**时间邻近窗口互为假负样本**的坑严重。
- 同窗口双增强是视觉领域最稳的范式（SimCLR/MoCo），金融序列上
  增强设计得当则**没有假负样本问题**（正样本定义严格 = 同一窗口）。
- 我们不引入任何新模型、新数据，只引入新的**训练目标**。

## 三、视图构造（关键设计，风险集中在这里）

对一根输入窗口（分钟主窗口 + 日K + 外盘日K 的组合序列）做两种随机扰动，
得到视图 A、视图 B。扰动必须**不改变未来走势的语义**：

| 增强 | 做法 | 理由 |
|---|---|---|
| 收益率抖动 | 每根 bar 的收益率加 ε~N(0, 0.1σ_bar) | 模拟微观噪声，不改变趋势 |
| 幅度缩放 | 整个窗口收益率 ×U(0.9, 1.1) | 波动率 regime 不变性 |
| 时间遮蔽 | 随机遮掉 10% 的 bar（置零+mask 位） | 强迫上下文鲁棒性 |
| 通道丢弃 | 随机丢 volume/OI 通道（20% 概率） | 防模型死记单通道 |

**禁止的增强**：时间反转、bar 乱序、窗口裁剪（改变标签语义 / 破坏 causal 结构）。

正负样本规则：

- **正样本对**：同一窗口的视图 A ↔ 视图 B。唯一。
- **负样本**：同 batch 内其他所有窗口的视图。
- **假负样本防护**：与正样本窗口**时间距离 < 5 个交易日**的窗口从负样本池剔除
  （邻近窗口未来走势高度相关，视为同语义，不应推开）。跨品种窗口不做剔除
  （rb 和 p 本来就是不同语义）。

## 四、架构与损失

- 主干：现有 KLineTransformer **一行不改**（保护冠军架构）。
- 预训练头：encoder 输出 → 2 层 MLP 投影到 128 维 → L2 归一化。
  投影头**预训练后丢弃**，微调时不带它。
- 损失：NT-Xent（InfoNCE），温度 τ=0.1 起步，
  τ ∈ {0.05, 0.1, 0.2} 作为唯一预训练超参扫描（一次一变量）。
- 预训练训练量：20 epoch 或对比损失平台期即停，单 seed 先行。

## 五、预训练 → 微调流程

1. **预训练**：全部品种全部历史窗口（含测试期之前的所有数据；测试期窗口
   是否纳入预训练需教师模型裁定——严格派会禁止，务实派允许因为无标签，
   我的默认立场：**只用训练+验证段**，不给任何争议留口子）。
2. **微调**：加载预训练 encoder 权重，接分类头+路径头，
   用 v1.1 配方微调。两个变体对照：
   - E7-A1：主干全解冻，lr 1e-4（比从零训练低一档）
   - E7-A2：主干半冻结（前 4 层冻住），lr 3e-4
3. 选模/早停/测试/生产回测口径**与冠军完全一致**，双 seed（42/7）。

## 六、判决线（预先承诺）

- **扶正**：生产单仓回测 > +10.06% 且成本加倍 > +7.24% 且回撤 ≤ 2.5%
- **有价值但不扶正**：mean_edge > +0.10 但生产口径不超冠军 → 记录为预训练有效、
  作为后续实验的新底座
- **弃案**：mean_edge ≤ +0.09 或生产口径转负 → 自监督路线封存，转向 E8 数据扩容

## 七、已知风险（请教师模型排雷）

1. **增强语义污染**：收益率抖动如果幅度过大，会把"趋势窗口"变成"震荡窗口"，
   σ 系数 0.1 是拍的，需要看训练后的下游指标反推。
2. **对比学习与方向预测的目标错位**：一致性学的是"稳定特征"，
   可能恰恰抹掉了对方向最敏感的微弱信号。判据：微调后 mean_edge 是否 ≥ 从零训练。
3. **计算量**：预训练约等于 1.5 次正常训练时长，AutoDL 单卡可承受。
4. **窗口构造重叠**：相邻窗口共享大量 bar，正样本对定义虽严格，
   但表示空间可能学成"时间排序"而非"形态分类"——这不是 bug 但要想清楚是否想要。

## 八、不做清单

- 不做跨模态 CLIP（分钟↔日K/外盘）——假负样本坑，教师已否决
- 不做掩码重建（MAE 式）——留作 E7-B 候选，一次一变量
- 不改主干架构、不改标签、不改评测口径
