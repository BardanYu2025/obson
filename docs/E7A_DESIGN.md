# E7-A 设计稿 v3：K线双视图一致性自监督预训练

> 状态：**协议冻结**（教师模型 2026-09-14 批准 + 6 处修正全部落实）。可进入实现。
>
> **归因声明**：E7-A 是原始 E7（分钟窗口 ↔ 日K/外盘跨模态 CLIP）的**收缩版**。
> 原 E7 因假负样本坑被否决，E7-A 改为"同一完整窗口的两种扰动视图"，
> 与原 E7 不是同一个实验，结果不得互相归因（MIDTERM_REVIEW.md 已同步注明）。
>
> 动机已由 P1 诊断坐实：三分类标签 ~1.5 bit/样本、90% 为"无"，
> 第 1~4 epoch 榨干，改 lr/调度/batch 均无效（见 MIDTERM_REVIEW.md 第六节）。

## 一、一句话方案

用**训练段**全部无标签 K 线窗口预训练 encoder：**同一个时间窗口的两种扰动视图，
表示必须相近**；对负样本只施加可观测的近邻与重叠排除，
**不宣称剩余样本一定语义不同**（残余 false negative 风险承认存在，第一轮不处理）。

预训练后先过**表征探针门禁**，再进入微调；微调、选模、评测口径与冠军完全一致。

## 二、实验命名（v3 修正歧义）

```text
增强阶梯：  E7-aug0 = 仅收益率抖动
            E7-aug1 = 抖动 + 5% 时间遮蔽
            E7-aug2 = 抖动 + 10% 时间遮蔽
微调变体：  E7-ft-full    = 主干全解冻，lr 1e-4
            E7-ft-freeze4 = 前 4 层冻结，lr 3e-4
实验名示例：E7-aug0-ft-full-s42
```

## 三、视图构造（先审计，后训练）

### 3.1 增强语义合法性审计（第一步，不训练下游）

对固定样本生成多个扰动版本，纯统计检验。**审计代理提前固定**，不许事后挑选：

- 窗口末端相对收益符号是否翻转
- 线性回归斜率符号是否翻转
- 最大正/负 excursion 主导方向是否翻转
- 波动率 regime 分桶是否漂移
- 窗口累计收益 / 末端价格相对变化幅度
- 末 3 根 close-path 锚定是否变化
- 是否影响时间特征和 causal mask

可**附加报告**标签翻转率作为诊断，但不得作为唯一合法性标准
（避免审计与标签定义耦合）。**判决只看语义破坏率，不看下游收益。**

### 3.2 收益率抖动定义

```text
r'_t = r_t + ε_t
ε_t ~ N(0, α · σ_window / sqrt(L))
```

- `σ_window` = 该窗口原始收益率标准差；`L` = 分钟窗口长度
- **α 的含义**：噪声累计标准差 ≈ α × σ_window。α=0.10 表示
  "整个窗口累计噪声的标准差约为窗口自身波动的 10%"，不是每根 bar 加 10%
- 审计扫描 `α ∈ {0.02, 0.05, 0.10}`；造成明显 regime 翻转的强度直接淘汰

### 3.3 增强阶梯

首轮只跑 **E7-aug0**（纯抖动）。aug1/aug2 在 aug0 结论出来后一次一变量加入。
时间遮蔽规则：短连续块、禁遮窗口末端关键 bar、只遮数值通道不动时间位置。
通道丢弃、幅度缩放默认关闭。

### 3.4 禁止的增强

时间反转、bar 乱序、窗口裁剪。

## 四、负样本排除规则（v3 收紧为样本级谓词）

完整输入 = 分钟主窗口 + 日K×20 + 外盘日K×20 + 技术指标 + 时间特征，
重叠判断必须覆盖全部上下文：

```text
negative_allowed(a, b) =
    不共享分钟输入 bar
    and 不共享日K上下文窗口
    and 不共享外盘上下文窗口
    and 不属于同一时间近邻保护区
```

- 跨品种负样本保留（品种语义确实不同），但配合 symbol probe 监控（第六节）
- 若排除后 batch 内有效负样本不足：记录 `effective_negative_count`，
  **不得静默减少 InfoNCE 分母**
- 同品种分层采样、跨品种降权、debiased loss 均为后续可选项，第一轮不加

## 五、架构与损失

- 主干：现有 KLineTransformer **一行不改**
- 预训练头：encoder 输出 → 2 层 MLP → 128 维 → L2 归一化；预训练后丢弃
- 损失：NT-Xent，τ=0.1 起步；τ ∈ {0.05, 0.1, 0.2} 是唯一预训练超参扫描
- 预训练量：20 epoch 或对比损失平台期即停，单 seed 先行

## 六、数据协议与表征探针门禁

### 6.1 数据边界（v3 钉死，覆盖 probe）

```text
预训练：        仅训练段无标签窗口（按窗口锚点日期切分）
预训练 ckpt：   训练段内部指标或固定 epoch
probe 训练/判决：仅训练段+验证段；测试段不参与 probe 训练、选择、判决
微调：          训练段
早停/方案选择：  验证段
测试段：        方案冻结后只跑一次，用于与现役冠军同 harness 对比；
                不宣称为独立泛化证明（测试集历史上参与过候选选择），
                真正独立确认靠前向实盘 + 未来 walk-forward
```

旁支 `E7-transductive`（全部无标签窗口进预训练）：隔离命名，只回答工程收益，
不得参与冠军判决。

### 6.2 探针门禁（v3：诊断制，非单阈值枪毙）

冻结 encoder，训练段+验证段跑 probe：

| probe | 指标 | 作用 |
|---|---|---|
| label probe | balanced accuracy / macro-F1 / CE | 方向信息是否被抹掉 |
| path probe | balanced accuracy | 路径信息是否保留 |
| symbol probe | accuracy | 是否只学了品种身份 |

判决规则（v3 修正"5% 硬杀"为告警线）：

- 与 scratch baseline 做**相同数据划分、相同 probe 训练预算、相同随机种子**对照
- 报告**双 seed 差值 + bootstrap 置信区间**
- 5% 仅为**临时告警线**；自动暂停需要"双 seed 同向下降 + 置信区间不重叠"
- 没有历史 probe 噪声估计前，先跑 scratch 重复训练估计噪声带
- symbol probe 高本身**不是罪**（品种身份是合法信息）；危险组合是：
  `symbol probe 很高 + label probe 不提升 + 跨品种 InfoNCE 明显优于同品种`
- 同时报告：各品种 label probe、按品种下游 mean_edge，看方向信息是否被挤占

### 6.3 微调变体

同一预训练 checkpoint、同一套增强、同一 τ：

- E7-ft-full：主干全解冻，lr 1e-4
- E7-ft-freeze4：前 4 层冻结，lr 3e-4

选模/早停/生产回测口径与冠军完全一致，双 seed（42/7）。

## 七、判决线（v3：三层 + 不确定性要求）

**A. 扶正**（双 seed 均须通过）：

```text
单仓收益 ≥ 冠军 + 0.5pp（> +10.56%）
成本加倍 ≥ 冠军 + 0.5pp（> +7.74%）
block bootstrap（按交易日/品种分块）置信区间不明显劣于冠军
最大回撤 ≤ 2.5%
信号数 ≥ 冠军的 50%
p 品种不出现明显拖累
```

（冠军样本仅 ~58 笔，不允许靠一两笔交易越过阈值；不要求置信区间显著优于冠军，
但不得明显劣于。后续 confirmation set / walk-forward 不得反向崩溃。）

**B. 表征有效但不扶正**（保留为底座）：

```text
相对 scratch：方向 probe 或 mean_edge 双 seed 稳定改善
且生产口径无系统性恶化、成本加倍不转负、回撤不超上限
```

**C. 弃案**（区分两种失败）：

```text
表示失败：probe 门禁不过（双 seed 同向下降 + CI 不重叠）→ E7 路线暂停
适配失败：probe 过但微调变体都不行 → 保留底座，另做适配实验
```

## 八、已知风险

1. 增强语义污染 → 3.1 审计前置，审计不过不进训练
2. 一致性抹掉方向信号（根本风险）→ 6.2 probe 门禁诊断制处理
3. 残余 false negative（同 regime 远窗互推）→ 承认存在，第一轮不处理
4. 计算量 ≈ 1.5 次正常训练，AutoDL 单卡可承受

## 九、不做清单

- 不做跨模态 CLIP；不做 MAE 式掩码重建（E7-B 候选）
- 不改主干架构、不改标签、不改评测口径
- 不做增强组合搜索；第一轮不加分层采样/降权/debiased loss
- 测试集不宣称独立泛化证明
