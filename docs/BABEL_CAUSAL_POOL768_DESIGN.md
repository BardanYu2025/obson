# 下一项核心决定：在编码端汇总不同距离的历史

2026-09-27。状态：**设计论证完成，尚未实现训练入口，也未启动新训练**。本文件接续 [History Structure768复核](BABEL_HISTORY_STRUCTURE768_REVIEW.md)，不修改任何已完成实验的门槛或结论。

## 决定及依据

下一项核心优先检验**因果分尺度汇聚**：在同一个768维bar状态形成之前，给不同距离的历史增加可学习的汇总通路。保留4层、8头、FFN3072主干、原28维输入和原共享查询解码器。暂不同时加深、扩宽、增加EMA或恢复跨周期约束。

理由不是“证明768维装不下”，而是目前两项事实：统一查询监督加强了近期读出；补远程结构监督又显著加强远处，但相对同预算control付出近期代价，冻结用途没有稳定增量。已经有充分理由试一次编码端的结构变化，没有充分理由继续叠相同损失或声称容量不足。

这是一个有边界的结构假设：让历史信息更直接地进入当前状态，可能改善近远信息的共同保留。它不能保证解决共享主干的梯度竞争，也不保证提高用途成绩。

## 当前代码实际做了什么

当前 `CoordinateEncoder` 对全部可见bar做因果Transformer，得到每个位置的768维隐藏状态，再经768→768坐标映射形成该bar的向量。旧路径已经通过注意力看到历史，**不是只编码当前一根bar**。

当前 `HistoryQuery.memory` 接收一个已经压缩的768维向量，经过全维线性混合后展开成4个192维token。它们位于解码端，不能把编码时已经遗漏的信息补回来；它们也不等同于四个独立时间尺度。

拟新增的汇聚位于编码端：先读取截至当前bar的多个因果隐藏状态，再形成唯一的768维向量。之后解码器仍只读取这个向量和历史距离，不能越过它访问隐藏序列、原始bars、真实锚点或目标mask。

## 具体结构

设主干隐藏状态为 `h[0:t]`，旧向量为 `z_old[t] = coordinates(h[t])`。增加以下残差通路：

1. 对每个隐藏状态做同一个LayerNorm。Q/K/V各为768→768投影，分别拆成4路192维；Q来自当前 `h[t]`，K/V来自可见历史 `h[j]`。
2. 四路分别对包含当前bar的最近16、32、64、128个隐藏状态加权汇总。历史不足时使用实际可见部分，每路至少有当前bar，不产生全遮蔽softmax。四个范围嵌套，并非不重叠的四段历史。
3. 每路使用相对bar距离的可学习偏置，长度128、初值0。拼接四个192维结果，经768→768输出投影得到修正量。
4. 输出 `z[t] = z_old[t] + correction[t]`。输出投影权重和偏置初值均为0，使新模型第0轮与来源模型函数一致；其余投影使用固定种子初始化。
5. 原共享查询头、旧局部诊断头及冻结用途读出均只能消费最终 `z[t]`。编码器端到端训练；旧局部诊断仍断开编码器梯度。

这是增加编码器内的历史汇聚，不是增加一个绕过状态的解码器。四路合计仍为768个数，入口没有先共用一个192维瓶颈；不能把单路宽192误报为整个表示秩只有192，也不能仅据维数声称768维都被有效利用。

需准确限定“分尺度”的含义：`h[j]` 本身已经包含更早的因果历史，Q也来自全上下文的当前状态。因此16根通路只限制**直接汇聚的位置范围**，不意味着其信息严格只来源于16根。最终残差相加、查询头全维混合后，也不宣称某192维切片天然等于纯短期/纯长期语义。这不是显式解耦证明。

128仍是本次可见原始窗口上限，没有实现无限历史记忆。窗口第一根不会凭空拥有窗口之前的隐藏状态；原因果特征的既有预热规则不改。每个前缀均需正确工作，不能只实现末端接口。

## 必要对照：一轮只回答一个结构问题

|分支|编码端改动|作用|
|---|---|---|
|plain|无新增汇聚|相同来源、监督和预算的继续训练对照|
|full_pool|同样四路192维汇聚，每路都看全部可见历史|控制新增参数、额外注意力及直接历史通路|
|scale_pool|同一模块，只把四路可见范围改为16/32/64/128|检验时间范围限制的增量|

full_pool与scale_pool所有参数逐张量同初始化，只有注意力mask不同。plain初始函数也相同，但参数和算力较少：不能把full_pool对plain的收益单独归因于“多尺度”，也不能用这一比较证明优于普通新增Transformer层。scale_pool与full_pool的比较才隔离本次范围限制。

按上述模块，新增参数解析计数为2,364,416（Q/K/V/输出四个带bias线性层、LayerNorm、4×128距离偏置）；实现后必须逐项实测核对。两种pool的参数量及稠密计算shape相同；plain不等参数。报告实际显存、时长及更新数，不称三组等算力。

每种子共同来源取已完成History Structure的 **control best** 及其配套查询头：先保留已有较强近期状态，再检验结构改动。该来源的seed42选100、seed43选99；两种子不是相同预训练轮数，必须披露，同种子三分支起点严格相同。旧structure/consistent仅作固定历史参照，不能拿其预算与新模型比较训练增量。

三分支使用相同目标：原uniform查询目标＋1.0已实现远程结构目标；旧local诊断断开编码器梯度，不增加0.10结构一致性。不新增趋势分类标签或PCA教师。这里改变了相对来源control的目标，但三分支同时改变，架构的因果比较只在本轮内部进行。

两种子42/43，各100轮、3800更新；沿用4789组三视图、有效batch128及相同prefix计划，使用新的401..500采样流。全部组重置优化器，沿用encoder1e-5、query3e-4、local3e-5及既有日程；新增汇聚学习率与encoder相同，不给候选额外调参机会。

主干、汇聚、查询头和旧local分别裁剪梯度，避免新模块梯度仅通过改变裁剪系数就缩小主干更新；plain也采用同一主干裁剪口径。零输出初始化使新增内部Q/K/V第一步梯度为0、输出投影可获梯度，是预期行为，测试不能将它误判为整个分支失效。人工设非零输出后须确认四路和主干均有梯度。

## 选模要保护实际关心的同末端近期能力

上一轮验证保护只相对起点，且原生近期均值不等同于同末端80/128读出。此次选模需显式加入同末端目标，但保持48/80/112为未参与选模的位置：

- 验证集比较**64/128**上下文的同一末端、同一过去16根真实目标，使用既有物理价格转换和自有预测锚点评分，不能用真实历史去纠偏。
- 验证另看128末端的最远65..127粗结构，定义不变；原生查询综合仍保护。
- 三分支共用相同第0轮参考。上述近期真实误差、远处结构及原生查询综合均不超过起点1.05倍；近期两上下文差异、远程level/trend各不超过起点1.10倍。合格轮次最小化近期/远程两项相对起点比值中的较大者，平均比值打破平局，仍相同则保留较早轮；第0轮回退。
- 这些是新实验事前选择条件，不回改上轮选模，也不能保证胜过新同预算plain。各项需有非零、有限的来源分数及足够样本，异常直接失败，不随意加大epsilon掩盖问题。

全部六份best及last锁定后，一次完成既有冻结用途拟合和评价。未训练/选模的80/128同末端近期检查保留；旧研究集仍是研究集，不冒称新留出。用途、当前字段、逐根各任务族、shift64共同历史及尾部误差均保留报告，不能只报新增汇聚指标。

## 成功层级与停止规则

两个pool分别对plain报告；scale_pool另对full_pool报告。不得按研究排名只保留更好的那一个。

1. **近远保留改善**：近期同末端真实误差与远处粗结构均在同预算plain的1.05倍以内，且至少一项降低5%；两条改善路径分别标注。同时保留既有查询差异、任务族、共同历史、当前字段和用途保护条件。只改善曲线但破坏用途仍记权衡。
2. **尺度限制有增量**：scale_pool对full_pool也满足相同近远改善和保护规则，才支持分尺度这一具体设计。若二者效果相近、但都胜plain，只支持新增汇聚模块这项组合变化。
3. **可用表示候选**：在前述保护成立后，冻结历史用途相对同预算plain至少改善5%，并独立报告原raw/PCA/current完整用途协议。完整协议未过，仍不能宣布重建阶段全面达到使用要求。

best、固定last、两种子、两集合都报告，沿用周配对及任务族保护计算，不能用平均值遮住种子退步。实现阶段必须把以上条件逐一映射为有测试的判据；若发现无法按此协议执行，先更正文档再启动，不在收到新结果后修改标准。

本矩阵完成即停止这条重建架构支线，不默认扩到8路、调窗口/损失网格、加层或追加100轮。若重建改善而用途仍无增量，保留有限表示并记录边界，不能再把重建loss下降当成下一轮实验的充分理由。跨分辨率与未来任务需要各自的研究问题，不能用来掩盖本轮未达标。

## 工程实施清单

- 新模块和独立入口，不改71份旧绑定源码；来源权重和数据只读。恢复旧PathInput包装、原查询统计量及全部buffer，严格加载。
- 训练前校验三分支第0轮函数/来源评分；同种子两个pool初始化逐张量一致；在实际micro上零更新反向预检。新增mask必须和张量同设备。
- 合成测试覆盖非零汇聚下的因果前缀/未来扰动、四个范围边界、极短前缀、不同位置和批量、同设备、有限梯度、单向量解码边界、初始化恒等、参数量/有效通路、micro累积、选择与恢复。
- 新机制在非零输出时才能证明因果与范围限制；不能只用初值0输出通过所有测试。测试范围限制需独立扰动汇聚输入的K/V；对真实主干不能把“短通路不应受更老raw bar影响”写成错误断言。
- 正式更新只在AutoDL；本地仅合成数据前后向，神经optimizer.step保持no-op。CPU测试不冒充CUDA通过。
- 复用数组，不重复导出全位置embedding；只保留必要best/last及恢复状态。先根据实际参数/优化器测算磁盘，不直接复用旧9GiB数字，也不要求恢复已删除缓存。
- 同一入口顺序完成预检、并行训练、统一评价及成功/失败打包；报告统一放到 `/root/autodl-tmp/download`。一次交付完整启动、恢复、仅评价和仅导出命令。

当前没有可执行的新训练命令。以上准备事项完成、协议落实到测试后，才交付AutoDL入口；用户不需要重复训练或重新上传上一轮报告。

## 方法参考与适用边界

[Perceiver IO](https://arxiv.org/abs/2107.14795)研究把信息压入latent array，再用查询产生结构化输出；[Perceiver AR](https://arxiv.org/abs/2202.07765)说明压缩式cross-attention可以结合因果遮罩。它们支持该机制值得作为设计参考，不构成金融bar、768维、四尺度或本任务用途效果的证据。本方案是基于当前工程约束的残差汇聚假设，不是完整复现上述模型。
