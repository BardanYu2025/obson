# 长历史第一阶段：冻结局部编码器，建立因果片段记忆

使用大主干 z256 的 best.pt。神经网络权重保持冻结，不做梯度更新。
本阶段检验历史存储/读取和简单上下文基线，尚未训练可学习的上层聚合器。
不承诺全部历史可以被一个固定向量精确还原，不预测未来，不输出开仓建议。

## 数据与边界

同一真实合约、同一周期内，每 128 根组成一个历史片段。为了与已有 stride=16
的当前窗口严格对齐，缓存每个可能的 128 根窗口向量；读取时以 128 根步长
取片段，因此同一次读取内各片段互不重叠。不同查询的片段划分可以不同。
缓存保留该合约全部可用历史，包括不在滞后主力选择中的旧片段；当前评价
端点仍沿用原 HistoryWindows 的选择及分割，便于比较。
每个缓存另存索引：合约/周期、结束行、可用时间和窗口前价格锚点，支持将来
恢复绝对价格与建立跨片段位置关系。这一版简单均值探针尚未使用这些锚点，
因此不能把其结果当成历史支撑阻力识别能力的完整测试。

缓存可能同时包含更晚时刻的数据，但读取函数明确截断到当前端点。
检索候选必须结束于当前窗口起点之前，不允许检索当前窗口、重叠窗口或未来。
不跨合约或周期拼接。每个合约的历史长度由本地文件覆盖决定，因此不是市场
上市以来的无限历史。所有时间以 Asia/Shanghai 表示，available_at=bar 开始时间+周期。
EMA 可以继承更早历史；验证和测试读取更早训练期片段属于合法的过去信息。

## 固定对照

- local256：原当前窗口向量，256 维，用于复核原中尺度探针成绩。
- mean4_256：最近最多 4 个连续片段均值，最多 512 根，256 维。
- mean16_256：最近最多 16 个连续片段均值，最多 2048 根，256 维。
- multiscale768：拼接上述三个向量，768 维。它同时改变了信息范围与读出维度，
  不能将它的任何收益全部归于长历史。

历史不足时只平均已有片段，不复制/伪造缺失历史。报告每个分区有足够 4/16
片段的样本数和平均可用片段数，短历史与长历史结果不可盲目混为同一种输入。
均值丢弃片段顺序，所以阴性结果不代表可学习的长历史模块没有价值。

对原规则的短/中/长三个状态标签分别做冻结表示的平衡 ridge 读出。
标准化仅拟合训练集，alpha=1/10/100 仅按验证集选择。测试统一在拟合后评估。
三组标签都描述当前已发生历史，不是未来监督。此任务仍存在规则标签局限。
短/中/长是已有结构规则的三个 ATR 阈值尺度（0.75/1.5/3.0），并不是新增的
固定时间长度标签，不能与 128/512/2048 根输入范围一一对应。
source checkpoint 已按重建验证损失选定；测试时期被多次检查，后续需新留出期。
不比较随机验证切分，也不把重叠窗口数当独立样本数。

检索对同一合约此前全部不重叠片段计算余弦相似度，展示前三个。
余弦并非校准概率或已验证的形态相似性，也不意味着之后走势相同。
固定抽取六个测试位置，不挑效果；图中全是真实行情，每个面板独立缩放，
用于核对历史来源、时间方向和形态。没有人工打分要求。

## 运行与导出

```bash
cd /root/autodl-tmp/obson
git switch features/babel
git pull --ff-only origin features/babel
export BABEL_DATA=/root/autodl-tmp/data/contracts
export BABEL_MEMORY_SOURCE=checkpoints/babel_ae_w256_l6_z256_s42
export BABEL_MEMORY_RUN=checkpoints/babel_memory_z256_s42
export BABEL_MEMORY_LOG=logs/babel_memory_z256_s42.log
export BABEL_DOWNLOAD_DIR=/root/autodl-tmp/download
mkdir -p logs
nohup bash scripts/babel_memory_autodl.sh all > "$BABEL_MEMORY_LOG" 2>&1 &
tail -f "$BABEL_MEMORY_LOG"
```

GPU 只执行冻结特征提取，之后 CPU 拟合线性读出；这不是新一轮 200 轮训练。
缓存按合约存储并记录 SHA256；重复运行只在源权重和元数据相同的情况下复用。
缓存缺失或 checksum 不匹配会重新计算。中断后可以追加日志重跑同一命令；
先确认旧进程结束，不同时写同一个缓存目录。
源文件指纹在结束时复查，不覆盖源模型。

报告自动复制到 download/babel_memory_z256_s42/，缓存与大权重不复制。
回传 manifest.json、memory_metrics.json；memory_examples.html 可在本地打开，
若有疑问再提供对应 memory_examples.json。错误退出也导出已有报告和日志。
下一阶段根据结果设计带时间信息的可学习聚合/检索，而不是自动启动另一次训练。
