# Uniform Context768：每个被监督bar拥有完整的128根上下文

2026-10-03。H3执行协议。代码已准备，真实CUDA训练结果待AutoDL；本轮不宣布新模型更优。

## 为什么现在做

主目标仍是可复用的价量历史状态，而非为了重建分数反复换读取器。上轮状态转移能接近真实未来状态，却没有未来价格优势，收束该确定性外推配方。位置监督实验又表明：直接把短前缀都加进来，会改变上下文、目标覆盖和端点权重，不能等同于每根bar学会相同职责。

本轮把职责具体化：**截至某根bar，用同一编码器压缩其最近128条因果特征，并由同一查询解码器读取过去。** 不要求相邻状态数值接近，也不要求跨周期整向量相同。没有新未来预测任务。

已有窗口重采样让多个末端得到监督；本轮新结构则让同一数据块中多个bar共享计算，同时每个状态有相同的128条特征感受野、不受块边界位置影响。另设独立滚动编码对照，防止把补足历史误报成架构收益。

## 固定三组，两种子

| 组 | 训练时怎么编码 | 同一物理bar的可见历史 | 作用 |
|---|---|---|---|
| prefix | 最后128根一次全局因果注意力，抽4个中间位置+末端 | 中间位置32～127根，末端128根 | 从头训练的传统前缀对照 |
| rolling | 对相同5个物理端点分别编码最近128根 | 都是128根 | 区分上下文与目标覆盖的收益 |
| relative，预定主候选 | 255根数据块，一次有限范围相对距离注意力 | 每个被监督状态都是128根 | 检查一致职责与共享计算的新结构 |

三组均从随机初始化开始，seed42/43成对共享所有可训练参数的初始数值；输入28、状态768、4层、8头、FFN3072，参数数量相同。每组120轮，合计720 worker-epoch；没有额外学习率网格。原Macro control97/94编码器和原查询头只读作强参考，**预训练历史不等，不能当作同预算竞赛**。新prefix也不是复刻旧Macro全部课程或输入适配器。

prefix→rolling改变训练上下文及可监督的历史范围；不称单一损失变量。rolling→relative保持各状态的输入历史和监督目标一致，但同时改变局部连接与相对位置，不能再拆成“仅位置编码贡献”。按样本/更新匹配，计算量不匹配；分别记录参数、有效样本、更新和耗时。

## 新编码器的准确含义

原全局组：28→768线性输入，加固定正弦位置编码，四层pre-norm因果Transformer，768→768坐标变换。

relative组：相同可训练模块，去掉绝对位置；每头注意力得分加固定距离惩罚，并遮住未来和过远位置。四层局部范围分别为33、33、33、32（含当前），总感受野为`1+32+32+32+31=128`。**不是每层看128根**，后者叠四层会看509根，构成不公平信息优势。固定8个斜率从0.25到1，每bar惩罚为斜率/8；此为本轮唯一预定配方，不扫描距离核。

一个255根块的前127根用于预热，后128根都已拥有完整特征上下文。训练仍每块抽4个中间位置（32～127，排除48/80/112）与末端，不是128个位置同时等权计算损失。查询目标年龄1～127，当前bar不作为历史复制标签。

relative在充分预热后不依赖块起点：同一bar最近128条输入相同，单独滚动窗口与长块输出应数值一致。CPU合成测试及GPU训练前预检/训练后数值诊断覆盖此性质、未来扰动与精确感受野。当前实现仍使用稠密注意力算子和局部mask，**不宣称已实现稀疏加速或KV流式服务**。

原28维特征中EMA按单合约连续因果计算，因此“128条特征”不等于原始行情信息严格截断128根。研究接口仍截至当前收盘，不跨合约拼连续价格。

## 数据和目标

- 来源与上轮相同，完整核验Macro谱系、原统计量和CSV指纹；默认原始目录仍由已绑定清单指定（通常`/root/autodl-tmp/data/contracts`）。不自动读取新快照。
- 保持原train/val/test/cross_research端点身份；本轮要求额外预热后整个255特征块位于同合约、同原分区。逐行导出新增剔除原因；三组和旧参考只评价共同可用端点。
- 原输入均值尺度与目标尺度均来自原训练集，所有组一致；不在验证或研究集重拟合。缓存最终128输入需复放原输入；原特征截断重算必须一致。
- 不按涨跌或未来筛样本；本轮所有标签均是截至所监督bar已发生的历史。没有未来价格或未来状态损失。
- 同一个历史查询头：768状态→4×192内部向量；按历史距离查询，两层交叉注意力、4头、FFN384，输出价格路径、实体和5项成交/持仓活动。所有新组相同随机初始化，状态尺度固定单位尺度，不从旧编码器引入统计假设。
- 训练损失保持历史查询`0.4路径+0.2相邻变化+0.1实体+0.3活动`，加远处4/16根聚合结构损失1.0；训练用Huber，报告用MSE。先在可用年龄带内平均，再五个端点等权。原独立局部头的输入被detach，不能训练编码器；本轮三组统一不再维护该诊断头。

## 训练、选模与资源

AdamW，batch128个原端点，每端点5个状态；默认micro8，梯度累积；学习率3e-4，前10轮预热，随后余弦降到5%，weight decay0.01，梯度裁剪1。没有AMP/TF32和dropout。每轮遍历共同训练端点一次；两个种子的抽样独立，同种子的三组顺序/位置计划相同。轮数固定120，不早停。

验证固定物理位置32/64/96/128，**所有组均独立拥有完整128历史**；使用共同查询加结构MSE选best，含epoch0回退，严格变好才替换；最后一轮照常报告。不能把short-context评分和full-context评分直接比较。训练末段和best/last差异用于识别欠训练或过拟合；120轮是有限筛选预算，不证明全部收敛或架构全局最优。

默认一worker适配近期12GiB卡；显存较大的设备可设`BABEL_UNIFORM_CONTEXT_JOBS=2`。先实际CUDA前向/反向测每组峰值（不更新参数），加优化器状态和余量后检查并发预算。不自动扩大batch或降低micro；micro绑定协议，改动需新输出目录。记录每epoch耗时与该worker剩余时间；总时间含尚未启动的其他组，不能拿一个worker ETA当全部时间。

需要至少8GiB可用磁盘用于模型/优化器日志与临时原子写入，已有训练完成后评价阶段检查2GiB余量。断点保存每epoch完整优化器和最佳权重，last是原子日志源，best/history可恢复；中断最多重跑未提交的一轮。输出目录/锁避免重叠运行，研究评价前模型、训练/验证缓存和读取器均锁定。

## 验收，不把总loss当成胜利

1. 历史回读：固定四个物理端点，分末端与中途，近1～16、中17～64、远65～127的价格与活动；原Macro两种子相同上下文并列；所有best/last均报告。
2. 冻结状态用途：原端点768状态读出16/64方向、趋势直线度、波动及7个当前字段。全部用同一五档Ridge；只有train拟合、val选alpha。附完整3584输入、train-only PCA768、当前28字段及原Macro参考。这些是历史描述诊断，非模型预训练规则标签，也非未来盈利证据。
3. 新结构主判据：relative相对rolling的平衡价格误差至少改善5%，每个年龄带和活动保留10%；末端与中途各自的价格/年龄带/活动也保留10%；冻结用途保留5%，方向/波动分别保留10%。双种子、两个研究集都要月级配对95%区间支持（至少100端点/6月）。全部为固定交集门槛，不挑单个好结果。
4. 附prefix→rolling、relative→旧Macro配对结果与品种/周期分组。当前字段R²/支持数单列，不能把缺失字段当0监督。主架构筛选通过也不等于当前字段全部可靠或替换旧主模型；没有自动晋升。
5. 研究集反复使用，明确为探索性研究证据，不称新留出确认。失败结束这套有限配方，不自动加轮、加深、扫位置偏置或放宽门槛。

保留且本轮未完整验证：从头训练的128位置同时等权、多分辨率共同物理历史对齐、条件性预测联合训练、随机创新/分布预测。H3只按这里的有限结构测试，不代表所有一致职责设计。
