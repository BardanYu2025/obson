# Grounded History768：先证明读对区间，再研究共同表示

2026-10-01。继续因果bar状态主线：每根bar的768维状态压缩当时已经发生的历史，支持历史读取及后续用途。本轮不训练未来价格预测、不增加层数、不把辅助loss下降等同于突破。

## 起点与唯一问题

起点为已完成Shared History768的`control_s42/s43`各自best。保留768维／4层／8头编码器、原28输入、原查询头及原0.3活动重建权重。严格恢复全部源参数后，仅替换训练用的自由区间辅助头；旧查询头输出必须原样回放。

旧自由一致性存在忽略查询也能得分的反例。本轮问：**先让辅助向量独立恢复指定共同区间的实际内容，再把这份监督与一致性引入编码器，能否帮助原768维状态？**

## 内容、坐标与读取器

使用已有经原始OHLCV/OI聚合核验的同合约链接。每个窗口三视图为较早细周期A、当前细周期B、同时收盘粗周期C。训练仍采样4800组三视图／轮，同一随机种子各组共用采样及prefix。

在原训练粗周期索引103..115的有效链接中，必须有至少4段；分别取最前2段和最后2段，形成同一状态的两个互不重合请求。区间按时间排序，使用真正细／粗映射端点；A的坐标随移位修正。所有端点严格早于各自状态，当前bar和未来不进入辅助目标。原中途bar查询、价量主损失均保留。

辅助目标是每段真实收盘价对数变化，共2个有序数值。直接从已绑定的价格目标还原物理变化，并逐批检查A/B/C相等，容差沿用原数据审计的绝对2e-5、相对2e-5（原log-percent单位）。固定资格训练样本独立拟合一个标量均值、标准差，所有后续数据只应用它。**本轮辅助内容只绑定价格；成交与持仓继续由原主任务重建**。没有把标准化活动特征跨周期求和。

读取器：标准化单个z→192维；2段端点年龄／127→64维；拼接后经192维GELU和线性层→64维、无可训练仿射的LayerNorm。内容解码器仅接收这64维，经128维GELU输出2个变化值。解码器看不到z、坐标、原bar、目标或缺失mask，没有旁路。64维表示只能称辅助内容表示，不预先赋予交易含义。

## 阶段一：冻结编码器资格检查

每个种子缓存同一固定4800组训练曝光与原验证时间分区的15→30共同链接；实际编码器只前向。验证链接来自原始数据和既定分区，必须有50条和5个合约。缓存、归一化、源状态与源码都有哈希绑定。

三个相同架构、同初始化的辅助读取器各训练40轮，AdamW3e-4、weight_decay1e-4、batch128、各自按全部验证MSE选best：

- 正常输入z和Q；
- 仅状态：查询几何输入恒0；
- 仅查询：状态输入恒0。

对同状态两份真实内容差异的标准化MSE≥0.05的样本，逐A/B/C视图比较正常预测与：换错Q的输出、仅状态头、仅查询头、训练均值。正常误差须比每个对照至少低10%，且按完整合约bootstrap2000次的95%区间上界<0。支持不足也不通过。相似行情不要求强行分开。这是预先定义的**验证准入门槛**，不是独立泛化结论，也不代表门槛是市场的普遍常数。

两个种子都通过才进入联合训练。任一种子不通过，写`audit_status.json: blocked`，退出码3，自动导出；这表示按协议停止，不是Python异常。不会重新调权重、增加预热或拿研究集修补门槛。

## 阶段二：公平的三个分支

| 分支 | 编码器收到的辅助梯度 | 辅助头训练目标 |
|---|---|---|
| control | 无；只有原重建 | 内容＋一致性 |
| content | 内容 | 内容＋一致性 |
| aligned | 内容＋一致性 | 内容＋一致性 |

全部从同一个合格辅助best起步、重新初始化优化器。三组头都接受相同监督，区别仅是进入编码器的路径。每种子各100轮、每轮4800组三视图、batch128，共38次更新；编码器／局部头3e-5、原查询头／辅助头3e-4，沿用5轮warmup／cosine。micro只影响显存；各项都是逐样本损失，累计梯度后统一裁剪各参数组。

原损失不变：query中价格权重0.4/0.2/0.1、活动0.3，远历史结构1.0，detach编码器的局部诊断0.25。辅助增加`0.1×内容MSE +0.01×(同周期latent MSE +15→30 latent MSE)/2`；非15→30的跨周期项为0。LayerNorm固定辅助尺度；内容绑定与错Q验证负责排除内容塌缩，不能单独用一致性距离证明有效。

选模沿用原价格保护／近远minimax、epoch0回退，不用辅助分数选主模型。保存best、last和全部历史。记录辅助分项、分组梯度裁剪、每轮第一步实际编码器位移，以及初末固定训练microbatch上的价格／活动／结构／内容／一致性分解梯度范数与夹角；这些记录不能保证原任务不退化，最终靠原评价及同期对照判断。

## 评价与停止

保留原全部768状态评价：13个固定读取任务×5个训练／验证正则候选、12个状态共780次解析拟合；原价格、近远历史、重叠稳定性、当前字段、成交持仓、方向／波动用途及原基线均保留。源结果先复放，训练状态／选模锁定后才研究集评价。比较content/control、aligned/content，以及aligned/control用途；原信息保护不放宽。

辅助研究使用原保留几何99..111、shift8，分别报告15→30、30→60和已有15→60支持。重新检查内容准确性与同状态错Q、均值对照，然后比较共同latent的正确／错配距离比；同周期与跨周期分开。低秩内容允许有效秩≥2（不套用旧自由64维头的≥8），但低距离、尺度和秩均不能绕过内容检查。全部种子、best/last、两个研究集均披露，不因某一项改善自动晋升。研究集多次使用，置信区间未作多重比较校正。

通过只产生研究候选；不自动替换主模型，不追加训练预算。不通过则收敛本方案的结论，回到已保存control基线。

## AutoDL执行、恢复、导出

```bash
cd /root/autodl-tmp/obson
git pull --ff-only origin features/babel
mkdir -p logs /root/autodl-tmp/download
BABEL_GROUNDED_HISTORY_JOBS=2 BABEL_GROUNDED_HISTORY_MICRO=16 \
nohup bash scripts/babel_grounded_history768_autodl.sh all \
  > logs/babel_grounded_history768.log 2>&1 &
tail -f logs/babel_grounded_history768.log
```

默认源`checkpoints/babel_shared_history768`，输出`checkpoints/babel_grounded_history768`。需要不同源用`BABEL_GROUNDED_HISTORY_SOURCE`。同命令恢复同输出；jobs可以改为1，不改变实验内容。MICRO修改需新输出。先核查磁盘，绝不自动删除旧模型。资格阶段会读原始数据和缓存CPU状态，GPU暂时空闲不意味着挂住；大矩阵开始前执行CUDA显存预检。真实耗时以日志为准。

正常、资格拦截、异常均自动打包到`/root/autodl-tmp/download/babel_grounded_history768_reports.tar.gz`。若只需补导出：

```bash
cd /root/autodl-tmp/obson
bash scripts/babel_grounded_history768_autodl.sh export
```

上传该tar包即可，包含资格对照、归一化、数据锁、运行状态与日志；若进入联合阶段，还包括全部训练、选模、原状态用途、共同内容评价。权重、优化器、缓存不入下载包。评价中断后使用`evaluate`只重做缺失评价，不训练；必须六个worker已完成。并行worker数只控制调度，不保证显卡满载。
