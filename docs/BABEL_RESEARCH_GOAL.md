# Babel 实验目标与阶段台账

本文件记录用户要求：每轮实验先对齐总目标、当前阶段问题和验收标准，避免指标驱动的方向漂移。更新实验结论时同步更新本台账。

实验设计、代码审查和结论分级遵循 [BABEL_EXPERIMENT_REVIEW.md](BABEL_EXPERIMENT_REVIEW.md)。测试通过与实验设计有效必须分别检查，有限预算结论不得扩大为方向性否定。

## 总目标

每根已收盘bar产生因果embedding，表达其之前可观察的行情历史及状态；既包含价格形态，也应保留有用的交易活动信息。短状态和长状态共同表达局部变化与更长历史。历史重建用于检验压缩信息的保留能力，后续分类或自回归是独立阶段，不能用历史重建成功冒充预测成功。

不要求每根bar猜出下一根涨跌，不要求以OHLCV/OI唯一还原真实买卖盘或开平仓行为；暂不把这些不可识别的含义硬赋予潜变量。

## 已有证据与边界

- 已形成长状态与512维短GRU状态的实验基线。长尺度价格形态重建较好，1bar变化相关性约0.36、标准差比约0.4，逐根细节仍弱。
- 自回归解码、增加EMA、降低影线权重等对照未证明稳定全面优于当前方案，不能因此不断扩大同类试验。
- activity512：增加量仓显式特征和保守输入分支未取得稳定价格收益；持仓变化线性读出R²约-0.13。不能据此断言量仓没有价值或embedding绝无相关信息。
- 测试时段被反复研究使用，当前报告属于研究集证据，定型后需要新的留出评估。

## 当前阶段：量仓历史保留的训练目标对齐

实现与运行说明见 [BABEL_ACTIVITY_ALIGNMENT.md](BABEL_ACTIVITY_ALIGNMENT.md)。

问题：在编码器容量和输入固定的情况下，加入观察历史的辅助重建约束，能否让状态更容易读出量仓变化，同时保住价格表达？

唯一主改动：量仓历史辅助损失。无约束/弱约束/较强约束，两个种子。冻结状态再进行线性与非线性读出；增加当前量仓输入对照，分开报告当前目标和不含当前bar的历史目标，审计异常记录敏感性。

阶段验收同时要求：历史读出跨种子改善、有配对证据、超过当前输入对照、价格重建和状态读出保留。训练loss下降、当前输入复制、单个种子最好值，不构成完成。

2026-09-21收到activity_alignment512报告：6组各30轮完成，源文件未变，总运行约19分47秒。辅助监督确实改善历史信息读出，但两档权重均未通过预先约定的完整验收，主模型保持原方案。

- 相对同输入control，辅助权重0.05/0.20的过去目标线性读出误差平均下降1.62%/3.52%，非线性下降1.00%/3.09%；两种子、两种读出均有周配对改善证据。
- 过去目标综合标准化MSE：线性control0.8353、弱0.8218、强0.8059，当前量仓输入对照0.7439；非线性分别0.8347/0.8263/0.8089，对照0.7362。因此未通过超越当前输入的综合标准。
- 不等于毫无历史记忆。过去1～16根相对成交活跃度的线性R²：control0.310、强约束0.344、当前输入0.060；lag4同项0.129/0.171/0.001。当前输入对照本身含因果EMA上下文，是已有特征的强对照，不是毫无历史信息的原始单bar。
- 价格/状态保留不稳定：弱约束seed42收盘误差+2.09%、状态BA下降1.05个百分点；强约束seed43收盘误差+3.85%、BA下降3.11个百分点。不能用跨种子平均掩盖退步。
- 全部984个测试窗口的17bar目标跨度都通过异常筛查，all和clean是同一个集合；不能声称获得额外独立稳健性证据。更早的输入前缀不在此clean定义内。
- 结论仅支持“监督能改变信息保留，但当前共享状态微调出现取舍”，不能证明512维不足、GRU无效或量仓无用。线性和本轮小MLP都未解决逐根持仓变化读出，不等于所有非线性读出都无效。

30轮阶段完成分析，升级验收未通过。但尚未充分检验训练预算，因此不能据此排除共享状态或优先改新架构。用户指出主模型训练预算差异后，复核确认：large512局部Transformer曾训练200轮，聚合30轮、联合20轮；后加短GRU训练30轮，最近实验是短GRU微调，不是对整套Transformer继续完整训练。

## 当前优先任务：同预算续训核验

见[BABEL_ACTIVITY_EXTEND.md](BABEL_ACTIVITY_EXTEND.md)。暂停新增结构，三组两种子从各自30轮last的完整状态延长到总100轮，不重置优化器/随机状态，不提高辅助权重。保留原价格选模，新增训练拟合/验证评分的量仓历史选择器，不能拿未训练的control辅助头loss选模。两种规则分开报告，不用测试挑赢家。100轮不自动等于收敛。

旧实验不是全部作废：同起点同预算对照保留其条件内结论；AR冻结编码器60轮不能否定联合AR训练；EMA的共同预训练有EMA历史偏向，none失败时epoch0不能当作训练后性能；新特征/零门控短微调不能排除从头充分训练的潜力。涉及最终方案选择时再补关键初始化与完整训练对照，不机械重跑所有历史实验。

2026-09-21收到activity_alignment100报告：6组各100轮完整，原30轮history完全保留，恢复验证差异为0，父产物未改动，运行46分50秒。预算质疑得到实质支持：较强约束的统一历史验证Ridge误差从第30轮约0.75持续降到第100轮0.6061/0.6140，尚不能宣布收敛。原价格选模和新增历史选模仍均未通过完整升级验收。

- 历史选模下两种子平均过去目标MSE：control线性0.8287/MLP0.8313，弱约束0.8043/0.8143，强约束0.7526/0.7515；强约束较对应control改善约9.18%/9.60%，两种子均有周配对改善证据。此收益同时涉及训练预算和新增选择器，不能全归因于多训练。
- 当前输入对照仍为0.7439/0.7362；强约束与其差异的周配对区间跨0，不能说已超越，也不能说已证明等效。辅助监督目标读出不是未见任务迁移证据。
- 历史选择器强约束两种子都选第60轮。seed42测试收盘误差比对应control高2.91%、状态BA低约1.38个百分点；seed43保留通过。原价格选择器的强约束则seed43保留失败。平均值不能遮蔽失败种子。
- 强约束第100轮的验证价格门槛失败：seed42收盘误差比固定参考高2.61%（门槛2%）；seed43高12.56%，base/change16/detail也不合格。报告未包含这两个最终状态的测试读出，因此尚未量清末轮信息收益及其代价。
- 全部984测试窗口all与clean仍相同，不能当作第二份稳健性复现。

下一步固定评价全部六组第100轮last，不继续训练编码器，不根据测试结果挑轮次，也不放宽门槛。独立last_diagnostic只做诊断，不替换主次选模、不自动升级。先区分“学到更多”和“满足价格保留”，再决定是否需要改变优化/信息分配。代码补齐不等于AutoDL诊断已完成。

2026-09-21收到固定第100轮诊断，完整复核见[BABEL_ACTIVITY_LAST100_REVIEW.md](BABEL_ACTIVITY_LAST100_REVIEW.md)。6组评价完成，原107个报告/数据产物逐字节不变。强约束历史线性/MLP MSE平均0.6373/0.6420，较同轮control下降23.07%/22.80%，较当前输入对照下降14.33%/12.80%；两种子两种读出的周配对区间均支持改善。因此“末轮状态尚未超过当前输入”的说法不再成立；之前第60轮合格候选的结论保留。

价格仍有代价：强约束两种子相对同轮control收盘误差增加3.775%/3.017%，均有周配对退步证据；状态BA保留通过，完整升级仍失败。control本身晚期也退步，不能将全部退步归因于量仓容量竞争。主要收益在过去16根统计状态，lag4/16逐根成交量变化仍弱。

本阶段确认监督及足够预算可以增加可读出的量仓历史信息，但尚未兼顾价格表达。主模型不替换。下一优先建议是固定control/强约束两种子末轮编码器，以共同来源解码器、匹配预算做价格再适配对照，区分可恢复的解码适配与仍待定位的表示/优化问题。尚未实现或运行新训练；不据此提前判定512维不足或增加新分支。

用户确认后实现价格再适配入口，协议见[BABEL_PRICE_READAPT.md](BABEL_PRICE_READAPT.md)：四组固定编码器，缓存端点状态；共同预训练解码器、各100轮、batch256、同样余弦学习率。原解码器、验证选中、固定末轮和固定父参考一起报告，失败候选明确标注，不把继承量仓读出算新复现。下一任务为AutoDL运行并检验价格恢复，不预写实验成功。

2026-09-21收到价格再适配报告，复核见[BABEL_PRICE_READAPT_REVIEW.md](BABEL_PRICE_READAPT_REVIEW.md)。四组100轮完整，冻结回放最大差异0，来源未改，选模重算一致。强约束两种子收盘误差45.516/47.726bp降至43.704/43.713bp，分别选头第20/24轮；量仓历史读出因编码器未变而保留。说明相当一部分价格退步可通过解码适配恢复，不能直接归因为编码器价格信息丢失。

相对固定父control，两组价格/detail都通过保留；相对适配后control，收盘误差仍增加1.778%/2.123%，均有配对残余代价，seed43超2%门槛，完整验收仍失败，不放宽门槛、不自动替换。所选头均早于25轮，训练loss继续下降但验证detail后期回升，不优先延长同一解码器训练。1bar标准差比仍约0.40，逐根细节未解决。

下一优先建议：固定价格control和量仓增强候选，转向未直接监督的历史状态任务及可获得的新留出评价，检验通用表示价值。避免把研究目标收缩成围绕同一重建门槛调参；规则仅作冻结读出评价，不回流编码器训练。新阶段尚未实现或运行。

## 每轮实验前后必须回答

1. 这轮在总目标中解决什么具体缺口？上一轮哪项证据支持继续？
2. 主改动是什么，控制了哪些数据、初始化和预算差异？
3. 是否把目标缩窄成只会重建价格曲线、只会分类或只会复制当前输入？
4. 选模是否仅使用训练/验证，测试结论是否区分研究探索与最终泛化？
5. 实际通过了哪些验收，哪些仍是推测？若无稳定收益，是否应停止当前分支？

当前阶段结束后先据报告回答这些问题，再决定下一步。不得把持续加特征、加层数或追逐单项最低loss作为默认路线。
