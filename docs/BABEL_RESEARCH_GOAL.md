# Babel 实验目标与阶段台账

本文件记录用户要求：每轮实验先对齐总目标、当前阶段问题和验收标准，避免指标驱动的方向漂移。更新实验结论时同步更新本台账。

实验设计、代码审查和结论分级遵循 [BABEL_EXPERIMENT_REVIEW.md](BABEL_EXPERIMENT_REVIEW.md)。测试通过与实验设计有效必须分别检查，有限预算结论不得扩大为方向性否定。

## 总目标

每根已收盘bar产生因果embedding，表达其之前可观察的行情历史及状态；既包含价格形态，也应保留有用的交易活动信息。短状态和长状态共同表达局部变化与更长历史。历史重建用于检验压缩信息的保留能力，后续分类或自回归是独立阶段，不能用历史重建成功冒充预测成功。

不要求每根bar猜出下一根涨跌，不要求以OHLCV/OI唯一还原真实买卖盘或开平仓行为；暂不把这些不可识别的含义硬赋予潜变量。

## 已有证据与边界

- 已形成长状态与512维短GRU状态的实验基线。长尺度价格形态重建较好，1bar变化相关性约0.36、标准差比约0.4，逐根细节仍弱。
- 自回归解码、增加EMA、降低影线权重等对照未证明稳定全面优于当前方案，不能因此不断扩大同类试验。
- activity512：增加量仓显式特征和保守输入分支未取得稳定价格收益；持仓变化线性读出R²约-0.13。不能据此断言量仓没有价值或embedding绝无相关信息。
- 测试时段被反复研究使用，当前报告属于研究集证据，定型后需要新的留出评估。

## 当前阶段：量仓历史保留的训练目标对齐

实现与运行说明见 [BABEL_ACTIVITY_ALIGNMENT.md](BABEL_ACTIVITY_ALIGNMENT.md)。

问题：在编码器容量和输入固定的情况下，加入观察历史的辅助重建约束，能否让状态更容易读出量仓变化，同时保住价格表达？

唯一主改动：量仓历史辅助损失。无约束/弱约束/较强约束，两个种子。冻结状态再进行线性与非线性读出；增加当前量仓输入对照，分开报告当前目标和不含当前bar的历史目标，审计异常记录敏感性。

阶段验收同时要求：历史读出跨种子改善、有配对证据、超过当前输入对照、价格重建和状态读出保留。训练loss下降、当前输入复制、单个种子最好值，不构成完成。

- 相对同输入control，辅助权重0.05/0.20的过去目标线性读出误差平均下降1.62%/3.52%，非线性下降1.00%/3.09%；两种子、两种读出均有周配对改善证据。

- 全部984个测试窗口的17bar目标跨度都通过异常筛查，all和clean是同一个集合；不能声称获得额外独立稳健性证据。更早的输入前缀不在此clean定义内。
- 结论仅支持“监督能改变信息保留，但当前共享状态微调出现取舍”，不能证明512维不足、GRU无效或量仓无用。线性和本轮小MLP都未解决逐根持仓变化读出，不等于所有非线性读出都无效。

30轮阶段完成分析，升级验收未通过。但尚未充分检验训练预算，因此不能据此排除共享状态或优先改新架构。用户指出主模型训练预算差异后，复核确认：large512局部Transformer曾训练200轮，聚合30轮、联合20轮；后加短GRU训练30轮，最近实验是短GRU微调，不是对整套Transformer继续完整训练。

## 每轮实验前后必须回答

1. 这轮在总目标中解决什么具体缺口？上一轮哪项证据支持继续？
2. 主改动是什么，控制了哪些数据、初始化和预算差异？
3. 是否把目标缩窄成只会重建价格曲线、只会分类或只会复制当前输入？
4. 选模是否仅使用训练/验证，测试结论是否区分研究探索与最终泛化？
5. 实际通过了哪些验收，哪些仍是推测？若无稳定收益，是否应停止当前分支？

当前阶段结束后先据报告回答这些问题，再决定下一步。不得把持续加特征、加层数或追逐单项最低loss作为默认路线。
