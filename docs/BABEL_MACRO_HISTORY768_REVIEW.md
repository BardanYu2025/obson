# Macro History768复核：固定读取器的稳定性改善，尚无表示用途升级

2026-10-01。报告`babel_macro_history768_reports.tar.gz`，训练源码`355d3f0`；[事前协议](BABEL_MACRO_HISTORY768.md)，[完整机器复核](BABEL_MACRO_HISTORY768_REVIEW.json)。

## 先说结论

**增加真实共同粗路径内容监督有明确局部作用；再加一致性约束，没有稳定的额外收益。当前结果不支持替换主模型。**

必须区分两个问题：原查询头随编码器一起训练后的重建表现，以及把旧查询头固定住读取新状态的表现。普通续训在前者继续改善，在后者明显变差；内容监督大幅缓解了这种旧接口失配，但与训练前相比，仍有部分视图未恢复。因此不能将相对普通续训的大幅改善解释为“新增了同等幅度的历史记忆能力”。

这支持“固定读取接口可约束状态漂移”的有限判断。编码器与可训练解码器共同适配，是对现象的合理解释；没有做状态变换分解或同一宏观任务的新旧头完整对照，不能声称已经证明全部原因是坐标旋转，也不能由固定头变差断言状态丢失了对应信息。冻结头本身偏向源状态的坐标，是本指标的边界。

## 1. 普通续训：原任务进步，但旧固定接口漂移

相对本轮训练起点，control的原可训练查询头：

- 留出位置收盘MAE降低5.91%～8.83%；
- 历史成交／持仓活动误差降低16.97%～24.61%；
- 同末端近期路径误差降低5.72%～12.71%；
- 状态用途综合误差变化为改善1.11%至变差2.86%，没有共同增益。

同一个control更新后的状态，使用固定源查询头读共同粗路径，误差却变成源模型的2.03～21.58倍（不同视图、两种子、两集合、15→30及30→60）。这两个方向不矛盾：一个允许读取器与状态一起适配，一个要求旧读取器保持可用。任务范围也不同，不能将它们当成同一误差的两种算法。

保留control的best权重作为更强的联合重建研究参照；这不等于确认其通用表示更强。

## 2. 内容监督：局部有效，但并非全面超过起点

content相对同预算control：

| 固定源读取器下的指标 | best误差降低范围 |
|---|---:|
| 共同粗路径真实内容 | 46.53%～96.22% |
| 同周期A/B读出差异 | 73.48%～93.96% |
| 跨周期B/C读出差异 | 44.78%～88.44% |

真实内容的预定至少5%改善，48/48比较通过；在没有显式对齐梯度时，共同读出差异也明显缩小。因此内容监督本身已经解释了相当一部分“读得更一致”的收益。

但相对训练前源模型，content的实际宏观内容误差从改善31.93%到变差138.80%不等；旧接口并未全面恢复。宏观保留96项中30项未通过，均为相对源模型的检查。尤其当前细周期B的15→30读出仍有不足。不能只展示相对已经漂移的control的百分比。

原可训练查询头的收盘MAE相对control仅改善0.09%～0.60%；状态用途综合误差在改善0.16%至变差0.17%之间，未达到预定用途增益。

## 3. 再加对齐：未确认额外价值

aligned相对content的32项预定同／跨周期差异至少10%改善检查全部未通过。best点估计中，同周期差异变化从改善10.82%到变差31.26%，跨周期从改善7.18%到变差33.53%；方向随种子和集合变化，尤其s42的15→30更差。

真实宏观内容相对content的变化也不一致（改善15.53%至变差30.67%）。原查询头收盘MAE变化仅改善0.08%至变差0.17%；状态用途综合误差变化仅改善0.14%至变差0.06%。本轮不能为额外的一致性项提供稳定增益证据，不继续扫该权重或自动加训。

## 保留判据不能简单翻译成“全面退化”

原744项比较中，content有8项、aligned有4项信息保留未通过。**这12项点估计都在预定容许范围内，但区间上界越过门槛，因此无法确认保留达标；并不是12项都已证明实质退化。** 例如部分远处结构／近期读出和方向用途存在不确定性。

两分支的活动保留32/32各自全部通过。当前7个字段的原协议检查也全部通过。原完整用途协议仍仅cross_research的seed42通过，和来源覆盖相同，没有扩展到全部种子和集合；各新增用途增益检查均未通过。

宏观内容对零变化与错区间检查两分支各96/96通过，说明结果不是简单共同变平。它们依然不能替代原信息与用途保护。两分支正式结论都为`no_balanced_macro_upgrade`、`representation_candidate=false`。

## 复核做了什么

- 131份可用completion绑定文件和94份源码逐哈希通过；归档未附12份模型权重及`heads.npz`，其身份只能核对清单绑定，未作本地权重前向或重新拟合。
- 训练／研究宏观计划的原始来源哈希与先前下载的Cross Period训练源一致；逐条重建所有导出样本的年龄、mask、顺序分组和共同跨度，并核对队列身份。
- 600条历史的采样流、预算、学习率、epoch0候选与选模、最终summary及best/last锁复算一致；156个读取任务各自五候选的选参也一致，共780候选。
- 从导出的预测、真值、mask重新计算原用途分数、误差和完整原协议；重新计算12项准入、744项原比较及464项宏观配对区间与全部分支判定，80万余数值比较一致。
- 重算的是导出预测和评分链，不是重新训练／推理验证。研究数据曾多次使用，区间未作多重比较校正；通过比例不是准确率，未通过也不都表示反向效果成立。

## 阶段决定

这轮已经回答所声明的问题，**停止当前固定读取器内容／一致性配方，不再补跑、延长或扫权重**。保留源模型、普通续训best和完整研究记录；不自动替换交付版本。

阶段主线不变：因果bar状态要保存价量历史，且能服务后续用途；重建和一致性是检验手段。此次有价值的发现是读取接口稳定性与新用途提升并不等价。下一项核心改动必须优先解释如何改善状态本身的可复用信息，而不是再次靠增加辅助读头或同类一致性项拿到更小loss；先做目标／信息组织的设计论证及既有证据对照，本次不发布新训练矩阵。
