# Frozen Volatility Transfer768：停止追加重建，检查表示是否有迁移价值

## 研究问题与阶段边界

最近的Macro／Linear History实验没有确认全面用途升级。新的问题是：**仅使用当前已经观察到的行情，冻结的768维表示是否比简单波动特征和同维PCA更适合估计随后一段时间的波动分布，并保留完整输入的大部分用途？**

这是独立的下游探索，不修改旧重建／用途失败结论，不把未来不可预测作为历史重建失败的解释。旧冻结历史方向／波动Ridge评价与本轮不同：本轮标签来自端点之后，且同时检查线性及小非线性读取。不是第一次探索未来监督；早期representation阶段做过多字段未来分位数预训练，本轮**不更新编码器、不预测下一根OHLC、不模拟交易盈亏**。

默认固定`babel_macro_history768`的control_s42／control_s43验证best（已复核分别97／94轮），也就是上一轮线性实验的共同冻结来源。保留768维、4层、8头、FFN3072、28因果输入；原非线性历史解码器随来源恢复，但不参与新任务优化。没有根据新研究标签在所有历代模型中挑赢家，不采用有明显代价的linear_joint。

## 标签与时间边界

在同一合约、同一周期、已收盘端点t，定义：

`r[k] = log(C[t+k]/C[t+k-1]), k=1..h`

`y[h] = log(max(sqrt(mean(r[1:h]^2)), 1e-8)), h=16,64`

每个目标恰好包含16／64个**新的**收盘到收盘收益，第一项是下一根收盘相对当前收盘。输出0.1／0.5／0.9分位数；不是上涨概率，不把它叫完整联合分布。16／64是bar数量，15／30／60分钟周期对应不同物理时长；周末／休市间隔也保留，不插值、不年化、不拼接换月。全部输入采用原128×28因果缓存，绝不把未来目标拼入输入。

- 继承原train／val／test／cross_research端点和合约身份，先核验原始文件及来源指纹，并从原始行情重建所有输入。
- 每行128根输入及64根未来目标必须全部属于原session-date分区；不足未来长度或跨界的样本从**所有组共同**排除，同时报告原因和ID。不依未来收益大小、成交量或未来主力合约筛样本。
- 训练、验证、研究标签分别使用自己的分区；不把后一个分区行情用于前一个分区的标签。EMA因果特征可以带有窗口之前的历史摘要，沿用既有定义。
- 真数据每个合约做特征截断回放；两种子编码器做未来扰动／截断／批次独立性检查及状态哈希冻结检查。
- 数据仍是反复研究过的历史。新任务的标签未参与编码器梯度，但旧模型选择曾使用验证数据，研究集也多次被检查，因此不能称独立新数据泛化确认。

## 对照与预算

| 表示 | 提供给读取器的内容 |
|---|---|
| simple | 过去8／16／64／127个收益的log RMS，共4维 |
| raw | 原128×28标准化因果输入，3584维 |
| pca | 在本轮合格无标签训练输入上拟合的PCA768 |
| embedding | 固定来源的768维末端状态 |

每组额外获得相同的3维周期one-hot，因此实际读取输入分别是7、3587、771、771维。周期元信息不是新的行情旁路；不把771叫768维纯状态。

每种表示固定两个读取族：仿射线性6输出，或一层128宽GELU MLP后接6输出。训练三个独立分位数，评价时排序，避免分位数交叉；线性族准确含义是“仿射预测＋确定性单调重排”，不声称整个输出函数仍严格线性。

种子42／43分别与同种子预训练状态配对。它们共享大量预训练谱系，不冒称两个从零独立的大规模预训练复现。

- 标签预算：合格训练端点的分层10%与100%；按symbol／period分层、稳定哈希选取、向上取整，导出实际数量。所有表示／读取族／LR使用相同子集和顺序。
- 少标签组仍用完整**无标签训练输入**做标准化／PCA，原编码器也见过完整预训练数据；两个预算都用完整验证标签选模。因此结论只能是“减少下游训练标签”，不是只用10%总数据或10%全部监督。
- 目标均值尺度只从本组使用的训练标签拟合。训练使用标准化目标pinball，验证选模与研究评分统一还原到**原始log RMS单位**，两个h等权，避免不同预算的尺度让分数无法比较。
- 两个LR：1e-3、3e-4；每个候选80轮，batch512，AdamW weight_decay0.01，梯度范数上限1，无dropout／无自动延长。每轮相同样本顺序；相同预算内曝光和更新次数一致，参数量／算力不同，均报告。80轮是有限预算，不保证收敛。
- 合计4表示×2读取族×2种子×2标签预算×2LR＝**64个小读取器拟合**，不是64次编码器训练。状态只提取一次并缓存，读取器逐个运行，避免多个编码器进程争显存；读取阶段显存不高属正常，不以占满显存为目标。
- 每个候选按验证pinball选best，允许epoch0回退；再按验证选LR，平局优先1e-3。所有64候选完整结束并锁定后才提取研究状态、构造研究标签、评分。
- 每轮保存模型、Adam状态、步数和训练历史；样本顺序可由seed／epoch恢复。重复命令跳过完成的拟合并核验文件。提取失败只重做未完成split。

另有两个无需神经训练的固定基线：各周期训练标签经验分位数，以及“过去同h波动＋训练残差分位数”。对每个种子／标签预算／读取族，在验证集选这两者和simple读取器中最强的一项，锁定后作为简单基线。原始输入／PCA不享有额外调参机会；PCA、embedding各自771输入维时读取器参数数完全相同，raw和simple不同，不能声称整个矩阵等参数／等算力。

## 判据与停止规则

唯一主结果：**100%训练标签＋MLP读取**。两个种子、两个研究分区必须分别满足：

1. 平均pinball比验证选定的简单基线至少低5%。
2. 比同维PCA至少低5%。
3. 相对raw平均退化不超过5%，每个h退化不超过10%。

每项使用逐行配对差的月级聚类bootstrap，2000次，95%区间上界须≤0；至少100行／6个月才有正式支持。同一个月的合约与周期放在同一块，尽量不把高度相关样本当独立样本。月边界仍可能有目标跨度相关，区间为探索性、未校正多重比较，不冒称严格独立确认。

线性读取和10%标签完整报告，但不能事后换成主结果。报告各周期／品种、两个h的pinball、中位数绝对误差、80%分位区间实际覆盖率及宽度；0.1／0.9的名义区间不保证80%校准，不能仅靠加宽区间宣布进步。主判据通过也只叫`exploratory_transfer_gain`，不声称校准完成／交易可用／通用表示成功。

未通过时按结果区分：简单基线是否已足够、raw是否也没有收益、PCA是否足够、状态是否落后、预算是否仍受优化限制。**不自动加层、改权重、补训或另扫新头**。旧编码器没有改变，不需要重新训练历史保护任务；原历史实验失败不改判。
