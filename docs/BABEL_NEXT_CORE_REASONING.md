# 下一项核心改动：先明确结构问题，再允许较大的调整

2026-09-26。用户明确允许更大步子的核心改动，要求完整思考。本文件记录现有代码和实验支持的判断，不作为已锁定的训练方案，也不新增训练任务。

## 研究目的不变

让已收盘bar的状态保存截至此时的市场历史，支撑不同用途；重建是信息保留检查。没有理由把目标缩减为拟合几个趋势规则，也没有理由要求下一bar所有细节可预测。

## 目前证据能说明什么

1. 4层相对同预算2层有显著重建收益，不能断言容量够了。继续堆深也未被证明是下一步最有效的选择。
2. 同周期重叠历史一致性有实际稳定性收益，适合保留；完整向量不必相同，相邻窗口有新旧信息进出。
3. control600更强，但其相对500的变化同时包含追加预算和三视图监督，不能单独归因。
4. 原末端全局输出的近期裁切明显好于原局部头。因此，局部头弱不等于状态完全没有局部信息。
5. 原局部头warm-start只取得很小的中途位置改善，结束固定读出适配是合理的；尚不能证明任何更强解码器都无效。
6. 跨周期0.10约束牺牲原能力，只否决该实现和权重，不否决多周期数据潜力。
7. 所谓中途位置“失败”主要是相对既有基线/保留门槛未过；不能看原始误差值就声称中途绝对误差比末端大。前缀上下文长度也不同。

## 优先审视的结构矛盾

当前末端768维是固定128×7历史目标的PCA坐标，整个向量通过固定基底读回。中途状态却由另一个局部头学习16根历史；不同位置拥有不同上下文长度，目标坐标和解码通道也不同。

因此值得研究：是否让“每个bar表达过去”的监督与读回方式更统一，而不是长期只强化窗口末端的大重建任务。这个判断是待验证假设，不是从失败报告中证明出的唯一原因。

## 允许较大改动，但需要可归因

首选论证方向：**以bar为中心、用相对历史距离查询同一个状态的共享解码方式，并联合训练编码器。**

概念输入只允许`当前状态 + 请求的历史距离/范围`，不能给解码器原始历史、其它bar的完整状态或目标值作为捷径。希望状态内容与固定窗口绝对位置的绑定减弱；同一机制可读短范围细节和较长历史。仍是历史回读，不是未来生成。

在实现前必须解决：

- 价格锚点与目标尺度如何定义，保证不同前缀可比且不偷偷使用真实历史修正输出；保留绝对路径、重新锚定形状和单步变化三个分开的评分。
- 早期上下文不足与表示能力不足如何区分：训练/评价应记录真实可见历史长度；固定滚动128末端和不同前缀不能混成同一项性能。
- 新解码器收益与编码器新增信息如何区分：需要冻结编码器的同结构解码器对照，以及联合训练版本；读出预算不能比基线多却归因于表示提升。
- 如何保住现有成果：保留原control600冻结参照、同预算原训练续训对照、原模型及原读出第0轮；不得只有新方案与旧600轮横向比。
- 如何验证统一表达真的改善：以事先固定的局部/长程回读、重叠稳定性、冻结状态用途为不同问题，不把所有检查混成“通过率”。用途基线仍包含原始输入和PCA。

可以在一轮推送中同时安排必要对照，减少往返；不自动同时改变宽度、深度、输入通道、采样及损失，让结果不可解释。匹配样本曝光/更新次数，同时记录算力与运行时间；不能把同轮数说成同计算量。

## 本轮收束

先固定control600接口和能力图，不再训练局部头，也不重跑已关闭的跨周期权重。下一轮设计应提交有限对照、初始化/预算、价格坐标、选择与停止判据、显存/时长估算，再实现正式训练。架构可以改得更大，实验问题必须更少、更清楚。
