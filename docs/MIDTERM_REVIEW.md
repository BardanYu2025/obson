# 项目中期评审材料（2026-09-14，请教师模型把关）

## 一、用户需求（原始目标）

- 商品期货**盘中信号辅助**：模型喊"多/空/无"，用户人工判断是否下单
- 作战品种：p（棕榈）、sr（白糖）、m（豆粕）、y（豆油）、rb（螺纹）等低单价、有夜盘、活跃品种
- 只需要分类方向 + 可解释的置信度/边界（θ 轨道），不需要收益率预测
- 结算规则（实盘纪律）：信号开仓 → 顺向摸 0.8θ 止盈 / 逆向破 0.5θ 止损 / 否则当日收盘平仓
- 训练在 AutoDL GPU，本地 Mac 做开发，GitHub 同步代码（权重不上库）

## 二、系统现状（现役冠军 E3 v1.1）

### 配方

- 架构：KLineTransformer（hidden 512 / 6 层 / 单向 causal / last 读出），13 品种 × 60/30m 混训
- 输入：`[日K×20][外盘日K×20][分钟主窗口(一周)]`，close_path 锚定窗口前 3 根收盘均值
- 数据：**合约模式**——按 1/5/10 月主力轮转自建连续序列（脱离天勤主连复权），θ 校准按段独立
- 标签：当日收盘锚定 first-passage 三分类（先摸上轨=多 / 先破下轨=空 / 都没=无），
  θ = c×窗口σ×√剩余bar，θ_q=0.90
- 损失：0.5×硬CE(类权) + 0.5×软CE + 0.1×**路径状态辅助**（4 节点×3 态 masked CE，
  逐节点类别权重防塌缩；同根双触整行 mask）
- 选模：验证集 mean_edge 早停（但换模判决以生产口径为准）；s42+s7 双种子概率平均集成

### 我们归纳的规律（请教师模型检验）

1. **辅助头强度存在甜区**：太弱塌缩（E3 v1）、太强反噬主任务（E4 幅度头、E6' query 头），v1.1 恰好坐在甜区
2. **mean_edge（验证集）与生产资金曲线两次背离**（re 系、E5），验证指标不再单独作为换模依据
3. **种子敏感未根治**（同配置差距可达 3.8 个 mean_edge 点），目前靠双种子集成兜底
4. **早停常在 2~4 epoch 触发**：监督信号信息量小（三分类 ≈1.5bit/样本，90% 为"无"），模型容量过剩 → 早峰后过拟合
5. 双向 attention 在本任务两次失败，"近端 bar 权重被打散"假设未被推翻

## 四、未来计划（候选，请教师模型排雷/排序）

### E7：自监督对比预训练（我们最想做的新方向）

- CLIP 式双视图对齐：**分钟窗口表示 ↔ 同时段日K+外盘表示**互相预测（对比损失），
  内盘 ↔ 外盘对应品种（rb/i↔SGX 铁矿，p↔BMD 棕榈）作为第二对视图
- **全程无标签**，可用全部 5 年历史（几十万窗口 vs 现在仅 ~2 万信号样本）
- 预训练后冻结/半冻结主干，微调主任务头 + 路径头
- 目标：攻击"信息量天花板"（现象 4），而非继续堆结构

### E8：数据扩容

- 加品种（ru 橡胶、au 金已备数据）、合约历史拉满、可能的 15m 细粒度分支重启

### E9：交易层（不动模型）

- 置信度分桶 EV 表实盘化：按模型置信度分桶统计测试集期望收益，盘中按桶决定做不做/仓位
- 路径头输出作为"进行中状态"解释器（模型认为当前走到哪一步了）

### 已否决

- Gated DeltaNet / Mamba 类线性注意力：长处是超长上下文，我们窗口 ~100 bar 用不上，近端检索反而更弱
- fwd_ret 收益回归辅助：与 first-passage 主任务语义冲突（教师模型此前已指出）
- 双向 encoder：两次独立失败
