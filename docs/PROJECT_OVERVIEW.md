# Obson 项目总览（2026-09-17）

> 一份自包含的项目说明：关键需求、架构、数据、训练方式、评价体系、已证伪清单。
> 当前主线：**E12 K 线形态理解骨干**。旧的方向预测范式已封存（见 §五）。

## 〇、关键需求（用户原话的工程翻译，一切方案的验收尺）

1. **盘中辅助，人在环路**：模型在盘中给出对当前结构的判读，用户自己
   决定是否交易。不需要全自动信号，需要的是"模型喊 + 我判断"。
2. **先看懂，再谈用**：模型要真的理解 K 线——识别状态（上升/下降/盘整/
   蓄势待发）、识别形态（头肩顶、支撑压力等）——而不是拟合技术指标。
   **如果训练出来只是在逼近指标规则，那直接算指标 + 统计检验就行，
   模型没有意义**（这是最高优先级的反作弊约束）。
3. **标签即知识积累**：形态/状态的规则标签体系本身就是资产，即便模型
   最终不达预期，标签库也是可接受的产出（缠论因流派分歧大，谨慎保守，
   不引入）。
4. **数据与形态都要放开**：不限品种（期货不够就上股票/股指）、不限周期
   （60m/30m/15m/5m/1m 甚至 tick）、不限定固定窗口（长短期历史都应
   可编码）；持仓量、成交量都是一等输入。
5. **embedding 是可迁移资产**：训练出的 per-bar embedding 不只服务当前
   任务，还要能作为其他下游任务的预训练表示（检索、gate、未来的新任务）。
6. **纪律**：一次一变量；门禁线先承诺后跑数；改动前固化档案；
   诚实报告失败（证伪也是产出）。

## 一、项目目标（需求背景）

盘中国内期货（黑色系、白糖、棕榈油等 13 个品种），模型给出对当前 K 线
结构的"理解"，人来做最终交易决策。经历过两个阶段：

1. **旧范式（已证伪封存）**：用过去一周 K 线预测到当日收盘的方向/触轨，
   三分类信号 + 动态边界。十几组实验（E3–E11）证明：信号短时效、
   微调有害、条件方向 BA≈0.50——"用 K 线预测未来 K 线"不可行。
2. **当前范式（E12）**：不做点预测，训练一个**看懂 K 线的表示模型**——
   每根 bar 输出一个上下文化 embedding，稠密监督其结构身份
   （段方向/枢轴/坐标/成色），作为一切下游任务的预训练骨干。
   首个下游：形态检索（M4）。

## 二、架构（src/obson/）

```
pivot_labels.py   标签地基：多尺度因果 zigzag（k=0.75/1.5/3.0×ATR），
                  事件时刻与确认时刻分离；每根 bar 18 维结构标签
                  （3 尺度 × 段方向/枢轴类别/距枢轴时间/幅度/枢轴成色/确认延迟）
contract_series.py 合约段帧：按主力任期拼接单合约段（不用主连的复权价），
                  窗口不跨换月断点；夜盘归次一工作日的交易日口径
pattern_data.py   滑窗数据集：token=bar，特征=OHLCV+持仓+日内时刻（8维，
                  无任何技术指标——防捷径）；按交易日 70/15/15 切分
pattern_model.py  PatternEncoder：hidden 128 × 4 层因果 Transformer，
                  60 万参数；品种 embedding + 周期 embedding；
                  5 个稠密监督头（全部 per-bar）：
                  段方向(3尺度×3类) / 枢轴(3类) / 时间坐标(7桶) /
                  幅度坐标(7桶) / 枢轴成色回归 + 掩码重构
symbols.py        品种/周期 ID 映射
```

## 三、数据

- 来源：天勤量化（tqsdk），单合约 60m/30m K 线 + 主力日历
- 范围：rb hc i sr p j jm m y cu ag TA MA × 60m/30m，全量历史
  （合约段帧 1.1万~30万 bar/组合，主力任期 bar 占 9%~52%）
- 标签产物：`data/labels/*_contract_labels.pkl`（54 文件，逐段因果打标）
- 窗口：256 bar，stride 25（训练）/ 5（检索库）；仅主力任期 bar 可作窗口末根

## 四、训练方式

```bash
PYTHONPATH=src python -u scripts/train_pattern.py --contract \
  --symbols rb hc i sr p j jm m y cu ag TA MA --periods 60 30 \
  --window 256 --stride 25 --batch-size 64 --lr 3e-4 \
  --epochs 30 --patience 6 --seed 42 --save-dir checkpoints/e12r1_causal_s42
```

- 因果掩码（防未来泄露）；双向版仅作对照轨（实测倒挂，留研究项）
- 多任务稠密 loss：5 头加权和，分量记账可查
- 30 epoch 全程收敛（val_loss 4.28→3.958 进平台），17s/epoch（60 万参数）

## 五、评价体系（门禁文化：先承诺线，后跑数）

**E12-R1 毕业判决（已通过）**：
| 门禁 | 内容 | 结果 |
|---|---|---|
| A1 | 枢轴检测容差 F1 vs 规则基线 margin | 0.630，+0.084 ✅ |
| A2 | 段方向（仅已确认段）BA | 0.792~0.805 ✅ |
| U4 | 跨规则族泛化（族B zigzag 参数） | 6/6 组合 ✅ |
| U5 | 不变性（仿射变换/时间拉伸） | 0.99 / 0.97 ✅ |
| U6 | 无坍缩（表示 std） | ✅ |
| — | 坐标桶 BA（改进项） | 0.277（>乱猜 0.14，<0.4 线）|

**M4 形态检索（两轮判决：未过门禁）**：
- R1 自一致性 1.000 ✅；R3 打乱对照 Δ=+0.18 ✅
- **R2 段方向一致率 0.662/0.663 ❌（线 0.70，两轮稳定）**
- R5 后续走势分布 ≈ 全库先验（无区分度，报告项）
- 发现：embedding 窄锥（已修：均值中心化）、最近邻被品种锁住、
  重叠窗口假命中（已修）。结论：检索机制成立，**骨干容量是瓶颈**。
