# Depth768运行期间：离线核对与结果决策

2026-09-28。研究目标是可复用的因果bar状态：保存价格形态与市场活动信息，并能用于简单读出或后续任务。不是无限追求逐字段无损还原。本文不修改正在运行的训练、数据、权重、选模或正式判据，也不启动新实验。

## 已完成的损失口径核对

当前Depth768使用历史查询损失加1.0粗结构损失；总日志另含0.25旧局部头损失，后者只更新局部头，状态已detach。查询损失为0.4 path + 0.2 change1 + 0.1 body + 0.3 activity；activity是五项有效字段平均，不是每项各乘0.3。训练使用SmoothL1，查询评价使用平方误差。

训练日志保存合并后的query/structure/optimization_value，以及编码器、局部头、查询头三个参数组的合并梯度范数。没有各任务独立编码器梯度范数或夹角，因此无法从现有日志反推活动任务的梯度占比或证明梯度冲突。

## 深度报告回来后的固定处理顺序

1. 先核对12组完成、预算节点、采样/LR/优化步数、来源及权重哈希、验证选模和读出锁定。保留失败与第0轮回退，不用后验研究结果重选模型。
2. 原样执行[BABEL_DEPTH768.md](BABEL_DEPTH768.md)的五个正式比较，分别回答相同曝光与相近矩阵运算预算的问题；两种子、两研究集合、best/last完整列出。
3. 在正式结论之外列价格路径、相邻变化、实体、活动分项；检视综合分改善是否主要由活动项驱动。这是解释，不改原晋升门槛。
4. 同时查看近期/远处、冻结用途、当前字段保留、训练耗时与显存。综合loss下降不等于用途改善，best停留较早也不自动宣布训练失败。

## 后续核心改动的决策分支（尚未启动）

| 深度结果 | 下一优先问题 | 边界 |
|---|---|---|
| 更深在两个预算轴均有稳定收益，用途也保留 | 保留对应深度候选，收束本矩阵 | 不继续自动堆层；重复研究集不等于独立确认 |
| 同曝光更深有益，相近计算预算优势不成立 | 增益是否值得额外时间/显存 | 不宣称深度无效，也不默认采用最大模型 |
| 综合查询分改善而价格/用途没有改善 | 目标权重是否偏离研究目的 | 活动0/0.1/0.3仅为候选消融方案，需先固定协议 |
| 多种深度均无稳定收益，信息是否可读仍不清楚 | 固定编码器比较解码器，区分存储与读取限制 | 不同时改损失、输入、深度；失败不证明信息不存在 |

活动消融若启动，应保留相同量仓输入，仅改变活动监督；同一起点、预算、采样、对称优化机会和预设选模。将0.3降为0后总梯度尺度与裁剪行为也会变，需记录并考虑这一混杂因素，不能把所有差异归因于信息竞争。已有起点经历过活动监督，因此该消融检验的是后续适配取舍，不是从头训练的活动任务必要性。

多分辨率共同宏观内容仍保留。重新设计需基于共同物理时间区间，保留尺度细节，不拉齐完整状态；不能只证明两种输出更像。它暂不与深度、损失权重、解码器三项同时扩成新矩阵。

## 现在可以做与暂不做

- 可以：CPU报告重算、核对指标口径、准备结果比较表、整理真实数据固定样本和应用接口约定。
- 暂不：启动另一轮GPU试验、修改已绑定训练源码、重启当前任务、事后修改成功标准，或承诺尚未证实的趋势识别能力。
- 应用接口优先围绕已收盘bar、明确历史范围、特征/尺度版本和状态向量定义；趋势分类等结果要由经过验证的读出头提供，不能按embedding维度直接命名上涨/下跌。

本次仅进行了现有JSON解析和算术核对，没有真实神经模型推理、训练或下游拟合。当前Depth768的剩余时间仍以远端完整任务进度为准。
