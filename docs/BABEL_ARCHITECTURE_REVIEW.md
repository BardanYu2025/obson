## 阶段结论

12组训练完整完成。在本轮共同输入、窗口、解码器、目标及选模协议下，attention相对GRU在两个研究集、两个种子的综合误差及全部四个主分量均有周配对改善证据。综合MSE平均下降26.46%/26.52%。这给出更换短历史编码器候选的实质依据，不能继续将GRU当成已经验证最优的架构。

但本轮没有完成严格的“有效512维信息容量”比较。代码审查发现：attention和multiscale末端内部宽度256，再投影成512；共同decoder又在位置展开前把512投影为256。名义输出维数与重建通路的有效维数不一致。此前将PCA512称为足以代表相同信息预算的对照，口径不完整，须更正。这是本次设计审查遗漏，不能归咎于训练时长或模型本身。

保留本轮配置间的端到端结果；不据此宣称Transformer普遍最优，也不以PCA差距否定512维神经表示。不直接替换原长历史/流式主模型，不立即扩大模型，下一步先补齐有效瓶颈对照。

## 512维口径：必须明确更正

实现的实际路径为：

- GRU：512维末端隐状态 → 512维LayerNorm状态 → decoder的512→256线性投影 → 位置展开 → 历史轨迹。
- attention/multiscale：256维末端隐状态 → 256→512投影与LayerNorm → decoder的512→256投影 → 位置展开 → 历史轨迹。
- PCA512：已观察历史轨迹 → 512个FP32系数 → 固定线性重建；没有额外256维入口。

从256维末端状态作确定性升维，并不会创造512个独立的连续信息维度；decoder中所有窗口相关信息又统一经过一个256维向量，之后添加固定位置和层数不能恢复被该入口丢掉的自由度。因此本轮神经重建通路的连续维数上限至多256，而非名义512。GRU输出的512维状态可供其他头使用，不能把这一结论扩大为“它本身只能保留256维信息”。

原协议公开了内部宽度，但没有把它对信息预算比较的影响审查清楚。应将本轮标为“约317万～332万编码器参数、共同256维解码入口下的三配置对照”。其端到端排名仍有用；不能同时宣称参数量和512维有效容量都已严格控制。

PCA512明显更好是实际结果，各主分量的配对差距也存在，应保留。PCA对同一已观察历史做变换不属于读取未来；但它直接编码待恢复轨迹，神经编码器输入为28维特征，训练目标/优化也不同，且现在发现入口有效容量不匹配。不能将全部差距归因于编码器，也不能断言消除256瓶颈就能追平PCA。

报告没有PCA256结果。即使将PCA补成256，也只能补一个重要容量基线，不能自动排除神经解码优化、输入参数化或样本量的影响。

## 训练曲线不支持一刀切“继续加轮数”

六个选择全部来自lr3e-4：GRU选149/143轮，attention184/173，multiscale193/187。对应末轮验证分数略回升，未出现全部最优都卡第200轮的现象。

lr1e-4的attention选200/199，multiscale200/200，仍有下降；GRU选196/196且基本平缓。固定预算并未证明每个trial都收敛，不否定继续训练低学习率候选的潜力；但当前验证已选择更好的高学习率候选，不能把延长全部训练作为解决PCA差距的首要行动。

全部lr3e-4的固定末轮平均MSE仍保留排序：旧test GRU0.43311、attention0.31608、multiscale0.32507；cross0.27540、0.20438、0.20871。优势不只由某一偶然best epoch造成。

## 下一阶段建议

1. 原模型继续保留；将attention列为共同128根历史任务的优先候选。先解决有效瓶颈对照，不立即扩大长历史架构、层数或拼接分支。
2. 优先补PCA256及旧模型实际入口的审计：现有PCA文件已保存前512个主成分，可复用前256个，不需神经训练或使用研究集重新拟合。它能约束“全部差距只是维数不同”的解释，但不是完整架构结论。
3. 真正512容量对照需要两端同时修正：attention/卷积末端本身要能提供至少512宽状态，decoder在扩展成多个查询位置前也不能先把状态压成256。不能只扩大最终Linear输出，也不能仅加宽decoder就宣称修好了编码侧容量。若参数量随之改变，要明确区分固定预算对照与容量扩展，不把两个问题混在一起。
4. 可先用既有状态配匹配解码头定位可读性，再做必要的编码器联合适配；冻结头对照只能检验已存信息，不能代表原端到端训练曾学会保留所有512维信息。任何追加训练须共同预算和验证选模，不根据test选择组合。
5. 今后实验审查同时记录内部末端宽度、名义输出维数、投影秩上界、序列压缩后到decoder的位置展开路径。输出shape一致不等于有效容量一致。此要求已加入实验审查规范。
