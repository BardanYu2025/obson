# Context Transfer768：将完整历史监督迁移到已训练主模型

2026-10-03。执行协议，真实CUDA结果待AutoDL。主目标保持为可复用的因果价量状态。上一轮完整滚动监督改善重建，但计算更多、用途没有一致提升；局部相对注意力配方结束。本轮不改架构、状态维度、特征或历史读取器，不训练未来预测。

## 本轮只问一个问题

从同一已训练Macro control出发，把被监督的bar从部分前缀补到完整128根历史，能否保住原读取能力并改善表示？为排除“只是多训练了”的解释，同时比较相同更新数和近似相同训练时间。

来源固定Macro control s42/s43 best97/94，原768维、4层全局因果Transformer、8头、原输入适配器及原查询解码器。完整保留原参数和状态尺度；不使用上轮从头训练的任何权重。附原模型冻结参考。原独立局部诊断头不参与此次优化，其输入原本detach，不能影响编码器梯度；不为它再维护训练任务。

## 三个预算位置，实际只需四条训练轨迹

每个种子先运行rolling，再运行prefix，全程单GPU单worker：

| 结果组 | 初始化 | 训练和停止条件 |
|---|---|---|
| rolling/update | 原Macro对应种子 | 完整128历史监督，固定60轮 |
| prefix/update | 同一原Macro | 原部分前缀监督，取prefix轨迹的前60轮及此范围内验证best |
| prefix/time | prefix/update的同一条轨迹继续 | 至少60轮，累计训练用时达到rolling的实际训练用时；最多300轮 |

两种子共四条轨迹，最多720 worker-epoch，常见情况会少于上限。不是六条独立重复训练。每组保存best/last；prefix的60轮快照固定保留，后续轮不能倒灌进它的选模。

**时间对照的准确含义**：在GPU同步边界内测整个训练epoch，包括CPU供数、目标构造、前向、反向、裁剪和优化器，排除验证、写checkpoint、导出；不是FLOPs或纯GPU内核时间。以训练时间而不是损失决定停止，预算不读取研究集。时间比需处于0.95～1.05才能作为匹配成功；达到300轮上限或整轮粒度超出范围时，明确记为未匹配，相关升级结论不通过，不自动补跑。

单worker避免本实验内部GPU争抢；请在同一GPU没有其他训练任务时运行。外部负载、温度和系统调度仍可能影响用时，不能把这种近似预算当作精确算力定律。保存每轮训练秒数、完整epoch秒数、次数及最终比值。不会根据上一轮2.1倍的总耗时粗略假定本轮也恰好需要2.1倍轮数。

## 数据、训练和公平性

- 复用已完成`babel_uniform_context768`的不可变255×28输入缓存，核验其完成状态、102项源码、缓存文件和原Macro谱系。只复制输入/清单/资格审计，不继承其新模型或读取器。
- 共同端点为train4789、val978、test984、cross439；整个255特征块位于同合约/同原分区。原28维特征、训练统计量、因果EMA和缺失活动mask保持不变。EMA可能包含窗口前已知历史；128指特征条数，不声称原始信息严格截断128根。
- 每个原端点抽4个中间位置加末端，前60轮两组的顺序、位置、batch和更新数完全相同。不是全128位置同时等权。prefix只编码最后128块内部前缀；rolling对同一物理端点逐个编码最近128根。
- 本轮对照继承原前缀监督规则，但使用共同端点单视图采样池；不声称完整复刻旧Macro的三视图课程。补历史也增加目标可用范围，结论针对整个训练配方。
- 同一原查询头从768状态读取历史年龄1～127，当前和未来不作为历史复制标签。查询损失0.4路径+0.2相邻变化+0.1实体+0.3成交/持仓活动，再加远处结构损失1；训练Huber，评分MSE，五个状态等权。
- batch128、默认micro8，使用梯度累积与整编码器activation checkpoint；不改变原模块结构或state_dict键。两组均重置AdamW，编码器LR3e-5/weight decay0.01，查询头LR3e-4/weight decay1e-4，clip1，无AMP/TF32。保持eval模式、原dropout0，梯度正常开启。
- **学习率全程固定**，因此prefix前60轮与独立60轮任务具有同样的更新日程，不会因为计划跑得更长而改变前60轮LR。没有额外学习率网格；有限续训不等于充分收敛。

## 同时保护两种读取方式

验证固定位置32/64/96/128，分别评价：

1. full：每个物理端点拥有完整128条历史输入；部署滚动编码的方式。
2. native：保留原固定窗口中的部分前缀读取；原接口的方式。

两种方式都分末端/中途、价格/近中远/活动/粗结构，共24项保护。每项验证误差不超过同种子原Macro初始值的110%，才有资格成为best；通过后以full末端/中途价格相对初始值的最坏比值选模。epoch0保留，严格改善才更新。不能靠完整历史平均分掩盖原短前缀能力退化。

缓存、模型快照和全部读取器在研究评分前锁定。冻结用途在原样本末端状态上，沿用13个目标与五档Ridge；train拟合、val选alpha。比较原Macro、新模型各budget的best/last、raw3584、PCA768、current28；同一机会，不新增神经用途头。描述量仍是诊断，不当作预训练规则标签或未来交易成绩。

## 两层判定，不能混称升级

预定主候选rolling/update best，同时对prefix/update best、prefix/time best和原Macro：

- **重建进展**：full平衡价格至少改善5%；full/native、末端/中途的六类历史指标保留10%。先要求时间匹配有效，再要求两种子/两研究集的月级配对95%区间都支持（至少100窗口、6月）。
- **表示升级证据**：在上述重建条件之上，冻结用途综合至少改善5%，方向/波动各保留10%，同样对三个参考、两种子和两个研究集成立。当前7字段的R²、支持和误差另报，不能用缺失标签充当0。

即使通过，仍无自动部署或主模型替换。所有best/last、分品种/周期和逐行误差都导出。研究集反复使用，不称独立新留出；失败不改门槛，不自动加层、扩宽或续训。

## 工程与恢复

启动前验证旧来源和缓存，实测CUDA前后向、梯度和显存，复放原端点输出；优化器额外内存留30%余量。首次训练预留10GiB空闲磁盘；续跑只计算剩余写入量，并始终保留2GiB原子保存余量，避免恢复时重复要求已经占用的空间。全部训练完成后的评价阶段需2GiB。源模型与旧缓存只读。

每epoch原子保存last作为恢复日志，包含优化器、累计训练时间、最佳权重及第60轮预算快照；衍生best/last/history可从日志恢复。时间累计只计入已提交epoch；中途失败的重跑浪费时间不加入模型的有效训练预算。支持相同命令续跑，完整会计核对训练轮数、成对初始化、从seed/epoch独立重算的全部采样与更新、前60轮两组匹配、实际停止点及验证选择。源码或micro改变需新目录，避免混合实验。

研究包包含全部JSON/history、指标、逐行误差/用途预测、读取器权重、固定示例、PNG与HTML。大模型权重和输入/状态缓存留远端，报告登记其哈希；不能只凭小包完成所有神经权重推理回放。
