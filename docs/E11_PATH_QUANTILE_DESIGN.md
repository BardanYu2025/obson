# E11 设计稿 v1：路径分位数模型（"看懂 K 线"主线）

> 状态：**v2，教师终审修正案已全量吸收（2026-09-15），批准做机制实验**。
> 教师核心判语：E11 比 E10 更有实质性，方向值得做；但"幅度分布预测"与
> "首触方向预测"必须拆成两个可验证模块——分位数边际分布恢复不了首触顺序。
> 起源：用户的核心愿景——"尽可能利用全部数据，训一个看得懂 K 线、能做交易的模型"。
> 与所有已死实验的界限：**这是主任务改革，不是给三分类冠军打辅助**。
> 判决线预先承诺：推导信号 val mean_edge > 冠军 **+0.1003**，且单仓回测不劣于冠军口径，才算有效。

## 一、需求背景

**用户愿景**：模型先学会"看懂 K 线"（价格如何演化），交易信号是理解的自然产物，
而不是围绕一个 1.5 bit 薄标签打转。

**已证伪的替代路线（全部档案见 docs/PRODUCTION.md / MIDTERM_REVIEW.md §7）**：

| 路线 | 死因 |
|---|---|
| E7-A 对比预训练 | 噪声不变性抹掉方向信号（probe 0.350 < 随机 0.385） |
| E7-B 自回归预训练 | 微调有害（+0.0661 vs 冠军 +0.1003） |
| E10 z-dynamics 辅助 | E10-0 诊断：未来表示标签质心 cos 0.98+，无标签结构可学 |
| T+1 视野拉长 | +0.0749 vs 冠军 +0.1003，信号短时效 |
| E4/E6' 辅助头 | 与主任务语义冲突反噬 |

**共同教训**：凡是"围绕三分类冠军输血"的设计都死了。E11 反过来——
**密集预测任务直接当主干，三分类信号降级为推导产物**。

**信号画像（P1 + T+1 + E10-0 联合归纳）**：薄、短时效、非线性、近端集中。
E11 不假设信号变多，只改变采集方式：从"每样本 1.5 bit"改成"每样本几百个连续监督值"。

## 二、任务定义

**输入**：与冠军完全相同（合约模式 13 品种 × 60/30m，日K×20 + 外盘日K×20 + 分钟周窗口）。
数据、切分、θ 校准、泄露防护（锚日双闸）全部复用，零改动。

**输出（双头，首发 E11-A）**：对每个样本（窗口末 bar = T0），预测未来路径
（T0 → 当日收盘，与冠军标签同锚点）的两组量：

**头① 路径幅度分位数头**（本实验的创新点）：
- 2 个路径节点（剩余 bar 的 50% / 100%；教师裁决：首发不铺满 4 节点，有效再扩）
- × 2 个方向（m_up(h)=截至节点 h 的最大上穿偏移；m_dn(h)=最大下穿偏移）
- × 5 个分位数（τ ∈ {0.1, 0.25, 0.5, 0.75, 0.9}）
- = 20 个输出/样本
- **口径（教师修正案 §五）**：m = M/θ **θ 归一化**（非百分比，跨品种/频率尺度一致）；
  非负单侧（m = max(M, 0)/θ）；只含 T0 之后的 bar；尾盘剔除规则与冠军完全一致；
  同根双触**不 mask**（幅度目标不需要先后语义）

**头② 首触顺序分类头**（教师裁决保留，解决"分位数恢复不了先后"）：
- 原 first-passage 三分类（先上/先下/无），与冠军标签逐项相同
- 职责划分：头①管"幅度分布"，头②管"哪边先"——生产信号初期只认头②，
  头①推导的概率仅作对照分析（教师三层门禁的信号层）

**为什么选偏移量而不是价格/收益**：
- M_up/M_dn 就是 first-passage 标签的"原料"——摸轨概率可以**直接从分位数曲线读出**
  （见 §三），不需要 MC 采样、不需要路径相关性假设
- 标签天然存在：每个样本的未来路径免费给出 8 个精确监督值（4 节点 × 2 方向），
  监督密度 ~10 bit/样本 vs 三分类 1.5 bit
- 有界、平稳、跨品种可比（相对 T0 收盘的百分比偏移）

**损失**：L = CE(头②，冠军同配方类权) + λ_q · [pinball(头①) + 交叉惩罚 + 时间排序惩罚]
- λ_q = 0.1（与 path_aux 同量级，防 E4 式反噬）
- 交叉惩罚：同节点同方向 q10≤q25≤q50≤q75≤q90（soft）
- 时间排序惩罚：relu(q_h − q_{h+1} + margin)——真实 M 随节点单调递增，有理论依据
  （教师裁决：v1 的"节点间放任"不成立，两种单调性是不同约束）
- **E3 路径状态头从首发剔除**（教师裁决：否则收益无法归因，违背单变量纪律）

**架构**：主干 KLineTransformer 一行不改（causal、readout=last）。
**从零训练**——愿景就是"从零长出一个懂 K 线的模型"，不从冠军初始化（避免把三分类的表示偏见带进来；这也保持单变量：任务形式是唯一差异）。

## 三、交易信号（教师三层门禁下的三轨对照）

生产信号**不替换**——头②就是冠军同款 first-passage 三分类，信号接口零改动。
同时报告三种信号做对照（教师裁决 §二）：

- A：头②分类信号（= 生产候选）
- B：头①边际触轨概率 + 顺序近似（仅分析，不进生产；教师已证"边际≠先后"，
  v1 的 25% 概率比修正废弃）
- C：A + 头①分位数曲线作为人工看盘解释器（"模型认为这波能走多远"）

信号层门禁：B 的 Brier/ECE 在 val 段测量备案；A 与冠军比 val mean_edge。

## 四、训练与判决协议

**机制门禁（教师重写版）**：
1. 每节点每分位数覆盖率 ≈ 名义值（0.1 档 8%~12%）
2. 分位数交叉率 < 1%
3. 时间单调违规率 < 1%
4. pinball 损失显著优于**经验分位数基线**（按品种×周期×节点在训练集算各 τ 经验分位数；
   教师裁决：全零不是正经基线）
5. 多空分离（预注册指标）：按真实标签分组，q50(m_up) 的 long-minus-none 与
   q50(m_dn) 的 short-minus-none 方向正确；至少 p、sr 两个生产品种；
   交易日 block bootstrap 95% CI 不跨 0；每组 ≥50 样本
6. 预测分布不全量收缩到均值

**信号门禁**：头②信号 val mean_edge > +0.1003（冠军基准，seed 42 单跑首发）；
头①推导概率的 Brier/ECE 备案。

**生产判决（过两层后）**：双种子 + 单仓 v2 + 成本加倍 + 白名单（同冠军协议）。
任一不过 → 封存进族谱，不情怀加分。

**warm-start 对照（条件触发，我方对教师 §七 的微调）**：E11-zero 机制门禁不过时
才补 E11-warm（冠军主干初始化）定位死因是"目标弱"还是"从零难"；过了则永久搁置。

**预算**：seed 42 单跑，配方（lr/batch/epoch/patience）与冠军一致；训练成本 ≈ 一次冠军训练。

## 五、风险与诚实声明

1. **败率不低**：E7-B 证明下一根可预测性有限；整路径分位数更难。不同处：这里不要求
   点预测精度，只要求分布形状校准 + 多空分离，门禁第 4 条是硬指标。
2. **首触"先后"是近似**：v1 信号推导对 joint first-passage 用了简化假设，
   误差方向在审计中量化；若门禁过但生产判决差一点，这是第一个要升级的点。
3. **不复活预训练路线**：E11 是端到端监督（标签免费≠无监督），与 E7 系无归因关系。
4. **冠军不动**：E11 训练期间生产信号继续用 v1.1 双种子，实盘记录不断档。

## 六、请教师判断的问题

1. **分位数节点选 4 个（25/50/75/100%）够不够**？触轨概率主要读 100% 节点，
   中间节点是正则还是必需？减少到 2 节点（50/100%）会不会反而更稳？
2. **首触先后的 v1 近似**（25% 节点概率比修正）有没有明显更优的轻量替代，
   又不引入完整路径模型？
3. **pinball + 交叉惩罚的损失组合**有没有更稳的现成选择（如 expectile / interval score）？
   我们不发明新损失。
4. **从零训练 vs 冠军初始化**：我们选从零（愿景纯洁性 + 单变量），教师是否认为
   这浪费了一个已知有效的表示起点？
5. **门禁第 4 条（多空分位数曲线分离）的量化阈值**怎么定才不算事后宽松？
