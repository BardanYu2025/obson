# 共同历史回读一致性：同源同预算续训对照

2026-09-25，用户批准后的单变量试验。依据[冻结重叠诊断](BABEL_OVERLAP768_REVIEW.md)：1根位移的共同历史回读差异明显超过数值误差，但较晚窗口有时更准，因此不能直接拉近整段embedding或抹平新信息。研究目标仍是可复用的因果历史表示，不改为拟合方向规则。

## 初始化与公平预算

四组：control_s42/43与consistent_s42/43。各种子两组共同从babel_path768/control_s*/last.pt的总300轮状态开始，完整恢复权重、两个AdamW的参数组/动量/步数和RNG，不重置。42此前best为300，43为298；best只作为冻结能力参考，不将298权重与300优化器混配。相对旧best的保持与同起点两组间的损失归因分别报告。

固定再训练100轮，batch128对窗口，micro64对，两组都前向两个128窗口并接受两个窗口的原真实历史监督。每轮4789对、9578个窗口曝光、38次encoder与head更新；每组总3800次更新、478900对、957800窗口曝光。四组默认两个并行worker，先42的两组再43的两组；不存在只给辅助组更多数据/算力/选参的路径。两组均计算一致性图，control权重0，candidate固定0.10，无网格搜索。

延续各父模型最后学习率encoder3e-6、head1e-5，以100轮余弦衰减至其0.1倍。两组日程完全相同，不回升LR，100轮是本次固定比较预算，不声称充分收敛。所有组完成预算，不因best不再改进自动提前停止。

沿用已锁定的稠密训练池，与同合约packed连续特征索引相交：B必须能由原bank完整提供，B提前64根的A也需留在同一分区、完整128历史及原始行号≥511。所有位移共用这一资格边界；未匹配合约、超出bank尾部、边界不足均记录计数，不按模型表现过滤。逐候选重建B的x/y/mask并与原稠密缓存回放校验，先于训练。均值/尺度、PCA、原特征和所有缓存只读，不增加未来行情。

已用真实报告索引核对：38,549个原稠密候选中36,106个可用；排除155个边界候选、2,276个超出原packed尾部的候选、12个无原packed合约候选。正式执行还会逐数组回放全部可用B，不只相信元数据。

每个epoch按seed与绝对301..400轮无放回抽4789个eligible B，确定性打乱小批次；训练shift为1或16，数量相差最多1；两组候选ID、shift、四个局部前缀及顺序相同并记录hash。64位移只在所有检查点锁定后评价，不参与辅助损失。不同窗口A/B共同历史分别A[d:127]与B[:127-d]，双方当前bar都不评分。

## 唯一损失改动

基础损失为A/B的原global SmoothL1+0.25×local SmoothL1的均值；两个窗口均保持原四随机前缀的局部16根监督。辅助项在共同已发生历史上比较：

1. 相邻收盘变化，用原训练delta_scale[0]标准化。
2. 实体，用原训练y_scale标准化。
3. 五项活动特征，各通道只在共同可用bar上计算，再对有支持通道等权。

三族等权SmoothL1；若活动族全部缺失则只平均其余两族。双方mask必须一致，原缺失逻辑不改，不用缺失0参与损失。辅助项对两分支均反传，无stop-gradient、真值锚点跳接、额外头或完整向量匹配。主损失继续监督绝对窗口路径，辅助价格项只约束逐根变化，不把首个共同预测点的误差传播为整段训练目标。

这是训练期两个已观察样本的历史监督；A编码器输入始终只含截至A结束的特征。B的更晚bar不进入A前向，不预测未知价格，不把B状态当作A在线可用状态。因果性仍在初始化与选中best/last权重上检查。

## 选模与评价一次完成

选模只用原完整验证集global MSE+0.25 local MSE，不用一致性研究指标或用途读出挑权重，epoch0可回退。四组必须完整结束并锁定best/last哈希，才读取研究成绩；best为主结果，固定last作确认，两者不择优。恢复以last完整状态为准，预算/采样hash/选模复核，原验证回放匹配后续跑。

一次评价同时输出：

- 原984/453研究窗口的全局、原局部训练/未训练前缀、近期回读、路径偏移/漂移分解，附固定样例和逐窗口误差。
- 相同984/443配对队列的1/16/64位移差异和真实误差，总体/品种/周期分布及逐对有效mask。保持10条跨品种边界排除，不按种子或位移变队列。
- 前轮utility768_v2训练好的control各自种子Ridge头与缩放器直接读取新状态，13目标全报告，完全不重新拟合。原输入顺序、真值与mask核验；冻结原best同样评分并回放前轮用途结果。这测既有读出接口兼容性，失败不能单独证明信息消失。

## 预声明完整条件

候选须两个种子、两个研究集、best和last均满足；均值变好不能覆盖某项失败。使用原交易日所属周配对bootstrap，至少50窗口/5周、区间上界≤0，未作多重比较校正，现有数据依旧是反复使用的研究集。

1. **一致性增量**：三个shift的change1/body/activity族等权MSE差异综合量，相对同预算control至少降低10%。对应相对路径形状差最多增加5%。
2. **不靠共同变坏取巧**：每个位移A/B各自三族综合真实误差、原锚点路径MAE相对control最多增加5%。差异综合量与真实误差使用相同mask/分母。
3. **原重建能力保留**：原全局primary、held local和recent primary相对同预算control和旧冻结best最多增加5%；全局path/changes/body/activity各最多增加10%。原512晋升失败不因本轮更改，也不直接宣称替换512。
4. **冻结读出保留**：主要四目标用途NMSE相对同预算control与旧冻结best最多增加5%，候选四目标R²均≥0.5。当前七字段每项R²≥0.8，训练方差标准化NMSE周区间上界≤0.1；有效支持条件相同。两项趋势形状诊断仍报告，不混入主指标。

全部通过只标candidate_for_review；否则no_full_upgrade。没有自动部署或扩网格。若只是降低预测间差异却使真实重建或固定接口变差，明确记录取舍，不视作成功。若选模回退epoch0则如实报告，不暗换last；固定100轮后按训练曲线与验证结果解释预算局限，不宣称所有一致性方法无效。

```bash
cd /root/autodl-tmp/obson
git switch features/babel
git pull --ff-only origin features/babel
mkdir -p logs /root/autodl-tmp/download
nohup bash scripts/babel_consistency768_autodl.sh all \
  > logs/babel_consistency768.log 2>&1 &
tail -f logs/babel_consistency768.log
```
