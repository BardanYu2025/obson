# 固定768跨周期共同历史对照

研究目标仍是：每根已收盘bar的状态保留可复用的历史行情信息。此次只检验跨周期共同历史约束的增量，不改成未来预测，不要求向量相等，也不解释潜变量为真实买卖盘。

## 固定实验

| 项目 | 约定 |
|---|---|
| 起点 | growth768的deep_s42/deep_s43验证best，总500轮；原编码器＋原局部头 |
| 架构 | 768维、4层、8头、FFN3072，固定PCA解码器 |
| 四组 | 两种子，各control / cross权重0.10 |
| 预算 | 各追加100轮；每轮4789个三视图样本，38次编码器和局部头更新 |
| 曝光 | 每组478900个三视图样本、1436700窗口视图、5746800局部位置曝光；两组顺序和位置完全相同 |
| batch | 有效128个三视图样本；默认micro64（一次192个窗口），两进程并行 |
| 优化器 | 两组均重置两个AdamW；5轮预热，编码器峰值1e-5、局部头3e-5，余下余弦下降至峰值0.1倍 |
| 选模 | 原完整验证集global MSE＋0.25local MSE，第0轮可回退；只用32/64/96/128选模 |
| 收尾 | 四组预算全部完成，锁定8份best/last，再统一校准用途读出及研究评分 |

100轮是本次配对预算，不宣称充分收敛。原500轮冻结模型也评分，区分追加训练与辅助约束的作用；不是拿新100轮模型与旧500轮冷启动比较。保留旧容量、用途未全面通过的历史记录，不自动替换交付模型。

## 三个视图与公平性

每条样本为同一合约的三个窗口：A是较早1/16根的15分钟窗口，B是当前15分钟窗口，C是与B同一时刻收盘的30或60分钟窗口。各窗口128根，分别有自己的因果输入和真实历史目标。

两组都计算三个视图的真实历史重建与共享局部头监督，也都保留A/B的0.10同周期共同历史一致性。只有实验组额外启用B/C的0.10共同历史收盘变化约束。control也计算相同辅助图但乘0；没有多给实验组数据或更新次数。

- 三视图原监督取均值，保持每组损失尺度一致。
- B/C只比较同一时间区间两端的预测收盘变化。不同窗口的加性价格基准自动抵消，不拿真实价格修正预测。
- 用原训练集固定的`delta_scale[0]`将变化换到共同尺度，采用SmoothL1；不重新拟合缩放、不聚合标准化成交量或EMA。
- 每个区间的两端必须来自完整且原始OHLCV/OI严格匹配的相邻粗bar；端点均在双方0..126位置，当前第127位置不参与。
- 至少8个共同变化区间才能成对。成交量、影线和完整embedding不做跨周期相等约束。
- 15→30、15→60参与训练；30→60只评价，表示未直接训练的配对关系，不代表其周期或行情从未被模型见过。

训练在合格候选中以种子确定顺序，每轮无放回取4789条；如果合格池小于预算，按固定置乱循环重复并记录唯一条数，不降低更新预算。当前CPU预检池9909条，无需重复。同一行情可能出现在多个高度重叠窗口或周期配对中，曝光条数不当作独立样本数。

## 数据与配对锁定

先验证已完成的跨周期原始审计、1251个文件哈希、growth全部祖先与所选检查点。复用已绑定的28维时间顺序特征bank和原归一化/PCA，不在本轮重算或改写训练特征缓存。原始数据只用于确定时间对应、复验口径和原主力/划分条件。

B来自原合格密集训练池；C按时间寻找同一合约、同一收盘时刻的粗周期bar，不要求C恰好落在旧stride16网格。双方必须满足上一交易日成交量决定的原主力选择，以及原划分内至少512根历史。A也须保留划分内512根历史。C不能越过已绑定bank的分区终点。

不跨合约拼接，不包含未收盘的粗bar。因果特征可能读取窗口前的历史，沿用原定义。训练前逐对核验从既有特征得到的共同价格变化，物理log-percent绝对容差2e-5、相对2e-5；不能仅因CSV匹配就默认训练目标一致。原始审计没有解决供应商时间语义或历史修订的全部问题，本轮沿用已核对的名义bar开始时间。

## 评价与预声明判据

旧重建、局部回读、同周期重叠、用途及当前字段保护全部使用原评价窗口、原指标及原分组。仅新增的跨周期指标使用固定stride16、原研究分区、主力和512根预热筛选后的密集配对清单，parent/control/cross统一比较。该清单在训练前按数据几何固定，没有按模型误差筛选。

原因：原稀疏窗口中15→60只剩20/11对，先天不足50对门槛；不降低门槛或用训练后结果决定采样。CPU几何预检如下，最终以远端实际bank核对为准：

| 配对 | 训练池 | 原品种研究 | 跨品种研究 |
|---|---:|---:|---:|
| 15→30 | 9277 | 1794 | 767 |
| 15→60 | 632 | 123 | 93 |
| 30→60 | 0 | 1268 | 449 |

三个评价组均须至少50对、5个交易周，训练前不足则停止并导出诊断。更多重叠窗口并不等于更多独立周，配对区间仍按交易周估计；这些是反复使用的研究集，不冒充新留出。

四组完成且best/last锁定以后，8份状态各13目标×原5档Ridge，合计520个闭式候选。只使用原4789训练窗口和978验证窗口，104个头全部选定后才提取研究状态。原deep500及其读出冻结回放，原raw/PCA/current基线精确复用，不扩网格。

判据在两个种子、两个研究集、best及last上同时检查：

1. 对15→30、15→60各组，跨周期变化差异相对同预算control至少降低10%，配对周级差异区间上界≤0。
2. 双方相对真实历史的变化误差不得增加超过5%，相对control及冻结500轮均检查。共同变平但一起变错不算成功。
3. 未直接训练的30→60，差异及双方真实误差保留5%；其他配对对冻结500轮差异也保留5%。
4. 原全局综合、留出局部、末端近期重建保留5%，价格路径/变化/实体/活动各族保留10%；同周期1/16/64错位差异与真实误差保留5%。
5. 同预算校准后的主用途保留5%，方向/波动族10%，保持可读性条件；七项当前字段沿用R²≥0.8和NMSE≤0.1要求。

全部通过只保留跨周期稳定性研究候选；否则记录哪些收益/代价成立，停止此固定配置，不自动加训、调权重或扩大架构。旧完整用途绝对协议另报，不因新辅助指标成功而抹去旧失败。

```bash
cd /root/autodl-tmp/obson

mkdir -p logs
nohup bash scripts/babel_cross_period768_autodl.sh all > logs/babel_cross_period768.log 2>&1 &

```

开始先核对文件和准备配对，CPU阶段GPU空闲正常。每轮记录原监督、同周期和跨周期损失、验证、最佳轮、时间、采样指纹及曝光。进程日志在各组`run.log`，主日志每次进度改变即显示轮次。每组固定100轮，不会只跑前两轮就停。

中断后用相同命令续跑，恢复最后完整轮的模型、两个优化器和随机状态；已完成组校验后跳过。不要同时启动两个管理进程。配置和来源受锁定，修改micro或jobs以外的实验定义必须新目录；micro也写入manifest，不能中途更改micro后直接覆盖续训。可以用`BABEL_CROSS_PERIOD_JOBS=1`以同一micro串行恢复，jobs不改变训练协议。

默认两进程、micro64适配此前32GB机器；若首轮显存不足，尚未正式训练时使用新目录和`BABEL_CROSS_PERIOD_MICRO=32`重新启动，不改变有效batch128及更新数，不忽略失败。不要为了占满显存任意改有效batch或学习率。
