# History Query768复核：有新任务收益，停止当前重建配置

2026-09-26。来源 `babel_history_query768_reports.tar.gz`。完整复核数据及归档SHA256见 [机器可读记录](BABEL_HISTORY_QUERY768_REVIEW.json)。

## 阶段结论

正常完成，正式结论 `no_joint_query_gain` 保持不变。这个标签表示预注册的联合增益与保护组合未通过，不表示所有指标都没有改善。

联合历史查询监督确实改善新查询头的中途历史回读，但尚未取得原局部头已有的综合质量；相对同预算control，原末端近期能力和共同历史回读一致性出现代价，校准用途也没有跨种子一致增益。本配置收尾，不自动延长轮次或扩大新头，不替换原control600研究接口。保留本轮所有权重，尤其原目标续训的control700，作为后续固定用途比较的候选；未据本次联合组判据授予control700全面升级或接口认证。

停止的理由是预算内的增量价值与代价，不是要求历史逐点无损，也不是证明已充分收敛。本轮没有建立共享宏观状态或进行跨分辨率表示对齐，不能用它否决用户关于同一市场内容应有一致表达的设想。

- 逐轮重新生成原9909候选池的抽样、位移、原局部前缀和新查询前缀哈希，核对更新次数、学习率、共享预热末态摘要、分支第0轮验证及选模规则。两种子每组三分支共享各自相同预热来源。
- 8个worker的最好epoch：warm均50；frozen/control种子42均100、种子43均99；joint均100。best与last在部分分支相同，不能视为独立复现。

- 本地只进行报告解析和评分复算，没有真实模型推理、神经训练或读出重拟合。

## 新任务上的增益与代价

以下采用各组验证best；范围覆盖两种子×两研究集的四种组合。last仍完整进入正式判定。

| 指标：joint相对同预算control | 变化范围 | 解释 |
|---|---:|---|
| 新查询中途原生综合误差 | −6.28%～−7.77% | 新监督有效改善它直接训练的任务 |
| 新查询中途最近16根综合误差 | −5.13%～−18.81% | 点估计改善；seed42两集合的至少5%周级证据均不足 |
| 原全局综合误差 | +3.18%～+9.24% | 相比继续原目标训练，牺牲部分原回读能力 |
| 原末端近期综合误差 | +9.20%～+14.39% | 四组合均有点估计代价 |
| 新查询重叠共同历史回读差异 | +13.07%～+42.14% | 位移1/16/64，不能把单窗更准等同于跨窗口更一致 |
| 校准历史用途综合误差 | −2.95%～+1.97% | seed42改善、seed43退步，没有一致用途增量 |

原生查询至少5%增益的周级检查全部通过；最近16根对control的seed42检查在两个研究集均跨过门槛，两份best/last共4项未通过。这不是“已证明没有改善”，而是不能确认达到了事先要求的至少5%。

其余88项未通过为保留检查，其中48项是新查询在三种位移相对frozen/control的共同历史差异。回读差异反映输出一致性，不等于直接测量了embedding距离；不能据此断言状态向量本身出现了何种抖动机制。

joint相对原600轮模型的全局误差仍下降5.03%～9.61%；但control700下降7.95%～17.26%。因此，不能只对旧600轮比较，就将追加训练的共同收益归因于新目标。

## 比“胜过新头对照”更重要的检查

将新头的最近16根输出用其**自身预测的age17**重新锚定，并转换到原局部目标尺度后，可与同一模型原局部头在相同held位置48/80/112评分。两者都不能借真实历史锚点修正输出。

| 两种子均值，held最近16根综合误差 | 原品种 | 跨品种 |
|---|---:|---:|
| frozen新查询头 | 0.054200 | 0.015210 |
| frozen原局部头 | 0.026658 | 0.005535 |
| control新查询头 | 0.052974 | 0.014201 |
| control原局部头 | 0.024605 | 0.004468 |
| joint新查询头 | 0.048380 | 0.012501 |
| joint原局部头 | 0.024963 | 0.004642 |

joint的新头相对自身原局部头，四组合综合误差高85.55%～227.46%。并不是所有分项都更差：单步变化有些组合改善、有些退步；但路径位置、实体和活动的整体质量尚未追上现有头。

这是同一评价目标下的当前可用质量比较，不是新旧架构的从头同预算竞赛：旧头经历更长训练，新头还承担不同距离、不同损失权重的任务。因此可据此决定暂不替换，也可说明冻结原状态的现有读出仍有价值；不能据此证明强解码器无效、信息完全缺失，或统一查询永远不行。更不能只因joint胜过frozen新头，就声称解决了原局部读出问题。

## 用途与训练尾部

- 14份父模型/选定状态在两研究集的当前字段保护均通过，历史用途完整raw3584/PCA768/current28协议均未通过。该协议测的是有限历史方向/波动可读性，不是通用语义和未来预测。
- 主分支最后20轮新查询验证误差仍下降：frozen/control约0.80%～0.90%，joint约1.42%～1.48%。不能宣布充分收敛；也不能仅因仍在下降就要求继续跑。
- PyTorch峰值allocated：warm/frozen约0.74GiB，control/joint约2.29GiB。每轮约18.4～18.5秒与36.2～36.3秒；实际总耗时还包含保存、预检和正式评价。它不是整机显存总占用。

## 收束与下一核心问题

结束本次固定配置，同时停止默认追加以逐点重建为主要目标的实验。保持已验证control600接口，保存control700/joint等权重，不要求用户再运行训练、重新导出或做同类复验。

用户提出的“同一市场历史在不同分辨率下应有共同表达”是另一个明确问题。若开展下一项核心研究，应先固定：

1. 共同的合约、已收盘物理时间区间与信息边界；128根15分钟对应完整聚合区间的64根30分钟/32根60分钟，不能等同于同端点的三个128窗口。EMA及其它因果预处理上下文的物理尺度也须说明。
2. 共享宏观内容与尺度细节的职责：允许细周期保留粗周期不可见的内部顺序，不强拉齐完整状态；共享投影一致必须体现为可用内容，不能靠常量塌缩或仅拟合投影头达标。
3. 表示用途与停止条件预先声明。用跨视图内容识别、冻结状态的不同用途及合理细节保留判断价值，重建作为辅助；当前实验判据和失败结论不事后修改。

这只是下一研究问题的范围，不是已经实现/验证的架构，也不在本次复核后自动启动新训练矩阵。有限用途的验收、停止追重建、全面替换旧模型是三种不同决定；本轮决定停止当前投入，暂不替换旧接口；没有宣布通用表示成功。
