# 768路径输入与配对续训复核

2026-09-25。来源`babel_path768_reports.tar.gz`，SHA256 `50946bafd2426f8634342c900ba50ea35756b4a67cf20e5d082b825ca2cb813c`。预先协议见[BABEL_PATH768.md](BABEL_PATH768.md)。本次只复核报告与更新研究决定，没有本地神经训练、真实模型推理或新的AutoDL任务。

## 结论

**续训有明确的数值收益；显式累计路径输入是小幅修正，未完成完整升级。** 相对原768_joint，两种子best均值的综合重建误差因control续训下降4.89%/5.04%；新增路径输入在相同续训预算上再下降0.47%/0.06%。两项收益必须分开归因。

新增输入的路径MSE在两种子、两研究集的best均改善，普通配对周区间也均支持方向上的改善。这些区间未经多重比较校正，属于反复使用研究集的探索证据。但预声明要求的是稳定达到至少5%改善，8项best/last检查全部未过；不能将“门槛未过”解释成毫无效果，也不能用事后取消5%要求宣布成功。

control/path的旧512保留检查均为50/56通过，剩余6项均为路径区间未确认保留。path的点估计已全部进入旧10%代价范围，但配对区间仍不满足门槛。旧完整升级结论不改，512也不能因此被称为综合最优。

## 新定位：整体偏移和长程漂移

本轮按同一个历史mask把路径MSE正交分解为：误差均值平方（整体偏移）、误差沿bar位置的线性漂移、剩余形状误差。三者之和与原路径MSE一致；只用于定位，不替换原评分，也不在推理时用真实目标校正。

新增路径输入相对control的路径MSE下降，原品种约99.64%、跨品种约97.12%来自整体偏移与线性漂移的合计减少；它对其余形状误差的影响很小。这里说的是“本轮改善量”的构成，不是全部误差的构成。

典型窗口：种子43、`au/60/SHFE.au2606`、2026-02-25 00:00，path路径MSE为0.763223，其中整体偏移为0.747259，约97.9%；去掉偏移和线性漂移后的剩余误差为0.014866，低于512的0.026027，但总路径误差仍高于512的0.274463。含义是这段重建的局部轮廓已有改进，却整体放错了相对于窗口基准的位置。它不是“绝对金价没有输入”的问题，也不能据一个窗口概括所有失败。

种子43的ag60大窗口还存在明显线性漂移：path总误差11.3095，整体偏移8.55185、线性漂移1.88918、剩余0.86847。单纯平移一条曲线并不能消除所有问题。所有大幅窗口继续保留，没有删除、改mask、改训练统计或重选研究集端点。

这是错误类型定位，不唯一证明错误来自编码器还是固定PCA解码器。不能直接把真实历史均值或终点送到解码器“修正”，否则改变了单向量保留信息的任务。

## 阶段收束

1. 本轮四组和全部验收已完成，不再为这条输入分支追加训练轮次或搜索投影强度。保留续训后的768 control作为追加预算参考、path作为小幅修正候选；二者均未自动替代512已交付接口。
2. 验证选择分数从追加第90到100轮仅再下降约0.10%～0.16%，明显小于整轮追加训练的5.23%～6.76%收益。日程也在降学习率，不能宣称已证明充分收敛；但当前证据不足以默认再追加100轮。
3. 若继续改模型，问题应缩小为“同一个768状态能否同时保住曲线整体位置/幅度与形态”，而非再加EMA、堆维数或转做涨跌规则分类。优先审查解码端把低频位置与形态分开表达的单变量方案，并与已有残差解码实验核对差异；维数、信息通路、输出容量和同预算对照需事前写清。目前没有实现或运行这项新方案，不承诺一定解决。
4. 总目标仍是因果bar状态的可复用信息压缩。此轮仅改善128根历史回读，原目标仍排除当前bar；通用bar保留、可变历史和未来预测不能从这些分数直接推出。补新数据不阻塞当前研究；现有研究集反复使用，最终独立确认仍需单独安排。

本次为代码与报告自查，不冒称独立同行评审。
