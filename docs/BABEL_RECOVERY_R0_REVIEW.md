# R0 v2复核：原结果可复现，允许准备有限稳定性诊断

2026-10-04。来源`babel_recovery_r0_v2_reports.tar.gz`，SHA256：`8105a5f361252d45054458f2bb37bbe7fa56ec5d5aa191064160044be3206c40`。机器可读记录见[BABEL_RECOVERY_R0_REVIEW.json](BABEL_RECOVERY_R0_REVIEW.json)，后续预算仍按[BABEL_RECOVERY_PLAN.md](BABEL_RECOVERY_PLAN.md)。

## 决定

R0完成约307.5秒（5分08秒）、零优化器更新。六份真实权重在其原执行口径下复放通过，可以准备R1的两个5轮低学习率prefix诊断，不直接进入R2、不新增整套历史重跑，也不升级模型。原Macro control97/94仍是研究参照。

R0程序中的`r1_authorized=false`是禁止自动训练的保护状态，不是审计失败。本次评审允许下一步准备有限诊断；R1/R2训练入口尚未实现，不能用旧Context命令代跑。

## 独立复核了什么

- 完成记录绑定的25份文件全部可用、SHA256一致；106份原源码和R0自身源码共107份匹配。
- 与前次原始报告交叉核对31份来源文件的哈希，复核六份选中权重哈希和轮次。
- 两份Macro原接口、两份Shared原接口、两份rolling末轮，以及两个Macro的Context初始接口，共140个验证数值，**actual、expected、原归档history/completion三者完全一致，最大差异0**。
- 报告1592个检查记录全部通过；其中48项神经因果/查询独立性检查最大绝对差异约2.53e−5，在原定状态阈值内。它们是固定样本检查，不是全输入空间因果性证明。
- 四集合共7190个可用255条输入窗口从原始合约重建，输入最大差异0；跨品种14个不满足完整跨度条件的端点按原规则排除。独立目标管线最大差异7.27e−6，小于预定1e−5绝对容差；共同目标mask与A/B标签检查通过。
- 原prefix前5轮的采样哈希、更新数和源模型学习率证据与原归档一致。未在本地训练或重新执行真实神经前向；本地复核的是远端报告、原始归档及其记录的一致性。

## 第一次报错的结论

第一次Macro s42 Context接口24项中18项超过严格数值复放阈值，最大相对差异约0.16858%。v2恢复各实验原入口的后端配置后，24项全部与原记录完全一致，验收阈值未放宽。

因此，首次审计差异已由真实复放验证消除。已确认R0遗漏运行口径，而非这次报告证明源权重错误。修复同时对齐了后端策略和恢复时的梯度标志等执行条件，没有单因素实验，不能把每一点差异都精确分摊给某个后端开关。

这不撤销旧Context训练退化：rolling末轮不良指标本次同样被精确复现。修好审计入口不是训练收益，也不是原长期续训已经稳定。

## 梯度：哪些有证据，哪些尚不能说

近端价格损失对编码器有非零梯度；旧局部头的真实detach路径对编码器没有梯度。不能说模型从未被训练恢复近端，也不能把局部头改善当作编码器受到保护。

固定前两个train窗口、32/64/96/128四位置的小批次中，结构梯度范数约为近端价格梯度的1.63～4.07倍，但结构与近端的夹角余弦约为+0.023～+0.073；近远价格余弦约−0.0075～+0.0596。没有观察到一致强烈的反向冲突，不能据此断言“结构目标必然压坏近端”。范数不是因果贡献比例，小批次也不代表实际batch128或整个训练轨迹。

额外交叉核对发现：由导出的范数/夹角推算，按价格家族与按年龄段分解所得的编码器平方梯度范数相对差异分别约−0.00683%、−0.00130%、+0.10831%、+0.02451%（42prefix、42rolling、43prefix、43rolling）。这不满足严格加法恒等复核；现有包没有原始梯度向量，不能确定是CUDA反向数值差异、归约精度还是诊断实现的问题。保留为**未完全验证的梯度诊断**，不调阈值宣布通过，不用其精确比值选损失系数。训练前的实际合成loss梯度与分项梯度关系，可并入下一次短诊断的零更新预检；本项不改变已经精确复现的原验证数值，也没有证据要求重训旧模型。

## 后续仍按原预算

1. R1只改固定学习率幅度：s42编码器约3.06638e−6、查询头约3.06638e−5；s43约3.26487e−6、3.26487e−5。上次Context相对源选中轮次分别放大约9.78倍和9.19倍，值得隔离验证，但尚未证明它是唯一原因。
2. 其余沿原Context prefix协议，两个种子各5轮，从原Macro选中权重、新Adam开始；原高LR前5轮作绑定参考。保留分项诊断，不把其结果用于临时调权。
3. 两个实际第5轮检查点都必须满足原24项保护，epoch0回退不能过关；失败停止并报告，不加LR网格。
4. 只有R1符合预定条件才考虑三组×双种子的R2。R0没有证明60轮稳定，也没有补上新的独立泛化验证。

## 未覆盖的范围

原scaler的train-only来源、数值和绑定代码已核对，但其原始拟合没有独立完整再现；不是所有祖先训练、中间更新或全部历史实验都被复放。更早仅有清单的实验仍不能标为已审通过。研究目标和从头全位置、跨分辨率、更深架构、两种外推分支继续保留。
