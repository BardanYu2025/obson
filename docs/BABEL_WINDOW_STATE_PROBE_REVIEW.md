这里“趋势强度读出R²”是对强度目标预测效果的评分；目标本身也是历史路径拟合R²，二者不同。低评分表示该标量未被当前线性读出可靠恢复，不表示价格路径不存在趋势。

方向标签由固定方向效率阈值±0.2定义为下行/混合/上行，不是人工交易师的唯一趋势标注。“混合”不等于价格绝对横盘。尤其64根标签中混合占原品种74.39%、跨品种69.32%，只报约92%的普通准确率会掩盖类别不均衡，因此主文使用平衡准确率。八个种子/尺度/研究集混淆矩阵中，仅原品种种子43的16根出现1次上行误判下行，其余没有直接反向误判；多数错误在混合与单向之间。这是当前研究样本的描述，不构成极低错误率的独立置信保证。

相对current28，历史方向读出明显更强，尤其64根平衡准确率由约55%–56%升到约86%–88%。但64根波动current28本身R²已约0.978/0.958，不能把该量的高可读性全部归功于长历史压缩。短尺度波动的相对改善更值得保留。

## 为什么完整判据失败

| 六目标综合NMSE，越低越好 | 原品种研究 | 跨品种研究 |
|---|---:|---:|
| embedding，两种子均值 | 0.43534 | 0.34880 |
| PCA512 | 0.47616 | 0.43070 |
| 完整输入raw3584 | 0.45660 | 0.40743 |
| 当前current28 | 0.54562 | 0.46833 |

综合误差相对PCA下降8.57%/19.01%，相对完整输入下降4.66%/14.39%，相对当前输入下降20.21%/25.52%。这些均值不能覆盖以下失败：

1. 原品种64根趋势强度读出两个种子R²分别-0.0149/-0.0717，违反六目标均须正R²。16根也仅0.0651/0.0713。PCA与完整输入的强度读出同样很弱，说明本轮线性诊断对该非线性量普遍受限，不能单凭此断言编码器丢失形态信息；具体成因仍未识别。
2. 方向效率任务族相对完整输入的NMSE，原品种种子42/43为0.07543/0.06679，而完整输入0.05666；跨品种为0.07285/0.05882，而完整输入0.05040。所有四组均超出允许5%退化。方向可读不等于方向信息优于未压缩输入；PCA方向表现也较强。
3. 原品种相对PCA、完整输入的5%综合改善周区间均未通过。跨品种综合收益更明确，但仍不能通过上述所有任务族条件。
4. 分组并非普遍改善：原品种60分钟综合误差，种子42/43为0.4075/0.4698，完整输入0.3751、PCA0.4121；原品种ag的综合差值相对完整输入为+0.0464/+0.1612。这些是未校正的分组诊断，不能据此选择性排除样本或切换种子。

通过的三项仅为跨品种两个种子相对current28，以及跨品种种子43相对PCA；不以这些局部通过晋升整体模型。

## 阶段取舍

保持原512窗口表示基线和两个种子，接受有限结论：压缩表示中有可线性读取的当前历史方向与波动信息；近期重建细节、趋势强度可读性与全面增量价值仍有限。研究集多轮复用，尚未取得新独立数据确认，不宣称通用bar表示目标已经完成。

本轮停止，不补开MLP、改阈值、扩正则网格或放大模型。建议下一项工作是只读的离线状态展示：并排呈现原始行情、已有历史重建、16/64根方向效率/混合标签和波动读出，保留尺度、种子与来源；趋势强度标为当前读出未验证，不包装为可靠信号，不以选择好看的样例或刷新门槛替代评价。该展示不再训练模型，尚未在本次实现。随后真正的泛化确认应使用未参与选参的新时间段，而不是继续复用旧研究集。
