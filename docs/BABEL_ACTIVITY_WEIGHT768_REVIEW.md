# Activity Weight768复核：价格收益成立，用途升级未成立

2026-09-30。六组各100轮完整完成，实际5小时53分19秒；两组并行、micro16、RTX3080Ti。降低历史活动监督使价格重建更准确，但未取得跨种子／研究集合一致的用途提升；权重0的历史活动回读明显失效。正式两候选均为`no_confirmed_utility_upgrade`，不改判据、不自动晋升。

## 完整性与对照

本地核验92份报告文件、80份绑定源码及142份可用来源报告；600条epoch的采样／LR／预算、验证选模和起点一致性复算通过。每组1,436,700视图、3,800步；两种子分别从四层281预算的第279/281轮best开始，同种子的三组来源和第0轮验证结果一致。选择轮次a000为98/96，a010为100/90，a030为100/99。

156个读出选择／780个正则候选复核，317,577个已保存用途预测值对应误差与评分重新计算，184,170项重建报告算术检查通过，736项周配对判据及完整用途协议重算匹配。四组来源数值回放、预检和训练后因果报告通过。单worker训练阶段峰值allocated约3.24GiB，不等于nvidia-smi进程总显存。

报告省略12份权重与heads.npz，共13个二进制文件。本地核对它们的选择／哈希绑定，未加载真实模型再次推理、训练或拟合读出。原研究集已反复使用、周级区间未作多重比较校正，两种子共享预训练来源；本次报告自查不冒称独立同行评审。

## 为什么不把0.1或0换成主线

| 候选 | 用途≥5%改善 | 近期价格≥5%改善 | 能力保留 | 活动保留 |
|---|---:|---:|---:|---:|
| 0 | 0/8 | 4/8 | 276/320 | 0/32 |
| 0.1 | 0/8 | 4/8 | 307/320 | 16/32 |

这些是判据计数，不是准确率。部分均值改善、区间却未确认达到阈值，不能把每个失败都说成实际退步。0.1的四项价格改善通过都在跨品种集合；原品种未共同确认。0的价格收益也未覆盖所有种子／best+last。两者用途≥5%改善均未确认，不能因为降低了价格loss就宣布表示更好。

所有候选当前bar七字段保留均通过，历史方向／波动目标也都可线性读出。完整raw/PCA/current用途协议仅跨品种seed42通过，原品种与跨品种seed43未通过，和起点的通过分布一致。这不等于模型没有信息，而是尚未取得规定范围内稳定的增量。

共同历史combined_gap包含价格变化、实体和活动三部分。权重0的24项共同历史保留均失败，0.1的shift1有6项失败；报告没有逐族的共同历史预测数组，因此不能将综合稳定性失败单独归因于价格。保留检查中的用途／远处分项和区间失败也应分别看待，不用一个总分替代。

## 活动代价和梯度证据的边界

活动权重0仍输入全部28个通道，原表示也已经学习过活动；这里只移除后续主查询的历史活动监督。共享查询头仍随价格目标更新，其历史活动输出可能漂移。因此“历史活动回读变差”不证明embedding完全丢失活动，更不证明成交／持仓输入没有价值。当前活动字段保留通过正好要求我们保持这个区分。

两个种子的固定训练小批起点，活动原始梯度范数约0.196/0.200，乘0.3后约0.059/0.060；价格＋结构范数约0.103/0.114。夹角余弦约0.027/−0.028，末轮各组约−0.027～0.121，没有持续强反向冲突的直接证据。不能据此断言活动梯度“压倒”价格，也不能把一批样本推广到全训练分布。

查询头梯度裁剪比例确有变化：0.3两种子约12.47%/24.24%，0.1为2.37%/4.13%，0为1.47%/1.97%；编码器各组约0.71%～1.45%。系数变化也改变优化幅度与裁剪，现有结果不能唯一归因于768维容量竞争，更不自动支持拆分状态或新增梯度手术。

## 阶段决定

1. 固定矩阵收束，不再扫0.05/0.2等中间权重，也不因末20轮价格验证仍下降而自动续训。末20轮价格查询下降约2.76%～8.16%，停止投入不等于宣布数学收敛。
2. 保留来源四层模型及本轮0.3作为联合重建参照；0与0.1保留作价格／活动取舍研究证据，不替换已交付接口或修改原验收结论。0.3也不是被证明全局最优。
3. 本轮已经回答：调权能改变重建保真分配，但尚不能解决用途增量。下一核心设计应以表示稳定性和可复用性为中心，先复盘已有共同历史与跨分辨率结果，明确仍未检验的假设，避免重新包装已失败的辅助损失或解码网格。
4. 不以直接训练编码器拟合当前趋势规则来“刷过”独立用途评价；同样不能因这些规则不是全部市场语义，就丢弃已有失败标准。新核心方案须独立论证、事前固定成功与停止条件，再准备有限实验。
