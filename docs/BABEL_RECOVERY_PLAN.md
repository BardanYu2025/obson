# Babel决策影响与补证计划

2026-10-04。针对用户要求的“多少需要重跑、对应哪条主线、影响范围和完整计划”。这是补证计划，未启动新训练。R0零更新入口已实现，见[BABEL_RECOVERY_R0.md](BABEL_RECOVERY_R0.md)；首次R0的执行口径遗漏已修复；[v2报告复核](BABEL_RECOVERY_R0_REVIEW.md)确认六份权重140验证值与原记录完全一致。允许准备R1有限诊断，R1/R2仍未实现和启动；梯度诊断的精确加法性尚有限制，不能据此调权。

## 明确数量与计数单位

**按已确认问题，当前安排：1项核心实验替代重做（Context Transfer的完整历史归因对照），先加1项短程稳定性诊断。没有证据要求任何旧实验整套原样重跑，也没有证据要求从512维起点全链重训。**

“实验”是一套回答同一问题的对照；“训练任务”是一种配置×一个种子。当前计划上限如下，不把种子、预算节点或报告包重复计为实验：

| 工作包 | 实际新增训练 | 上限 | 是否立即运行 |
|---|---:|---:|---|
| R0：谱系/数据/目标/数值/可恢复性核查 | 0 | 无优化器更新 | 先实现和执行只读核查 |
| R1：稳定性筛查 | 2个任务（两个种子） | 各5轮，共10轮 | R0通过后 |
| R2：完整历史归因对照 | 3组×2种子＝6个任务 | 各60轮，共360轮 | 两个种子R1均通过后 |
| 合计 | **最多8个新增训练任务** | **最多370轮、14060次更新** | 不自动增加LR、权重或结构网格 |

R1的高LR参考复用上轮prefix前5轮记录；本轮新训练只做预定低LR，前提是R0证明其他条件一致。不能证明一致时停止并更正计划，不暗中再添加高LR任务。R2所有组重新从同一原Macro best开始，不继承R1的训练产物。

这个上限是**当前已发现问题的补证预算**，不是对尚未检查的历史实验作“永远无须重跑”的保证。若R0发现新的数据、标签、权重绑定或因果性缺陷，必须先给出具体受影响比较及后代清单，修订数量；不能在执行中无声扩成全量重训。

## 盘点覆盖，避免虚报已审完

已盘点Downloads中的61份Babel报告包，对应60个运行根目录（alignment100的两份包为同一目录不同导出）。其中58份包含标准manifest，另3份是coverage审计和两份time-confirmation报告，已按其实际根目录登记。报告包括训练、零训练诊断、交付和失败重检，**61份包不等于61次训练实验**。

第一批源码/协议细查覆盖9个关键阶段；其余51个运行根目录仅完成清单及来源入口盘点，未获得“已验证有效”状态。本轮不重跑它们，也不将其判为全部正确；优先核查其中主模型的实际权重祖先和影响下一决策的结论。详细清单见[BABEL_RECOVERY_PLAN.json](BABEL_RECOVERY_PLAN.json)。

早期散装metrics、128/256目录以及没有现存报告的任务不在61包统计里。后续若发现缺失证据，列明具体任务，不用缺失文件倒推出必须重训。

## 保留主线和实际权重依赖

目标不变：每个已收盘bar的因果价量/持仓状态，先检验其历史信息保留和可读性，再独立验证真实新bar刷新后的一步预测、或无新行情的自由外推。

当前保留768维、4层、8头的Macro control s42/s43 best97/94作为研究参照；“保留参照”不是全局最优、最终产品合格或预测有效的声明。

已核对构造代码与manifest的关键权重主干：

```text
control600 + 已有查询头预热
  → Bar Semantics 的 uniform
  → History Structure 的 control
  → Causal Pool 的 plain（这一阶段统一加入结构目标）
  → Depth 的4层扩展预算 best279/281
  → Activity Weight 的0.3组 best100/99
  → Shared History 的control best100/99
  → Macro History 的control best97/94  ← 当前冻结参照
      ├─ 位置监督（后续研究分支）
      ├─ 状态外推/用途（后续研究分支）
      └─ Context Transfer（后续研究分支，未晋升）
```

Uniform Context另做随机初始化模型，复用原Macro的数据谱系；其新权重没有进入Context Transfer。Context Transfer直接恢复原Macro，仅借用Uniform的输入缓存。

失败的Shared within/cross辅助对齐、Macro content/aligned和Context Transfer rolling候选，没有进入上述保留权重主干。因此，本轮问题不会沿时间顺序反向改坏旧权重，不能据“后来实验失败”推导“全部祖先模型失效”。同时，主干确实继承了远处结构目标与detach局部诊断的设计选择；这会限制能力解释，需在R0和统一评价中明确，不用“未继承失败分支”证明全链正确。

## 九个已查阶段的处置与决策影响

| 阶段 | 当前处置 | 受影响的判断/下一决策 |
|---|---|---|
| History Structure | 保留配方内实测结果；不重跑 | 只支持远处收益及近端代价，不证明近远任务已均衡 |
| Causal Pool | 保留同轮pool对照；不重跑 | plain相对旧源改善包含续训和结构目标；不能归功于pool或断言汇聚无效 |
| Depth | 保留同100轮与扩展预算两种结果；不重跑 | “4层全局最优”“深层没有价值”不成立；深层充分训练仍是开放问题 |
| Activity Weight | 保留0/0.1/0.3的适配取舍；不重跑 | 不能否定活动输入价值、也不能证明0.3从零训练最优 |
| Shared History | 保留失败与退化事实；旧自由辅助头不再重跑 | 查询语义不可识别；不得据此关闭所有共同历史/跨周期方向 |
| Macro History | 保留control研究权重、冻结接口漂移结果；不重跑 | 相对漂移对照的改进不等于新增宏观记忆，control也不是已达标通用模型 |
| Position Supervision | 保留warm-start密集/等权结果；不重跑 | 不能排除从头全位置训练；同时改变位置覆盖和权重的效应不能拆开归因 |
| Uniform Context | 保留整个配方结果；不整套再跑 | full增加输入、标签、权重和算力，不能作为纯输入历史长度证据；由R2补归因 |
| Context Transfer | **R1定位后由R2替代补证**；旧报告原样保留 | 旧续训配方失败不能否定完整历史编码；固定高LR是否造成初期损伤须单独定位 |

“需收窄解释”与“原始数值失真”是不同级别。当前没有从上述九项中确认必须抹掉全部结果的数据污染证据；这也不是全链数据隔离已审完的保证。

## R0：无训练准入，先找到最早的实质错误

输出必须是逐项事实和受影响节点，而不是一个总分“pass”。

1. **祖先与资产**：按真实加载路径、选模记录和SHA建立权重依赖闭包，区分权重来源、缓存来源、辅助诊断引用。检查远端现存权重/缓存/优化器，保护原产物。缺文件先尝试从现有交付包/保留权重恢复，不把缺文件自动升级为重训。
2. **真实权重复放**：优先Macro best42/43、其直接父Shared control42/43、Context rolling last42/43共6份权重。用其各自声明的同一输入和读取器复放已有指标、因果检查及缓存与原始输入路径；它们不是6次训练。不在不同decoder或不同时标上作伪等价比较。
3. **数据与目标**：确认train-only尺度、窗口/标签整个跨度的分区、同合约边界、未来截断不变性；对三组拟议训练的同一物理端点逐张量比对共同标签及mask。核对路径/单步变化/实体/活动和17+结构损失的有效权重。
4. **梯度与更新契约**：对固定训练批无更新反向，记录每损失的编码器/查询头梯度、夹角及拟裁剪因子；区分local.detach无编码器梯度、正常的目标取舍和意外断梯度。训练批诊断不使用val或research来调整单步更新。
5. **恢复定义**：Macro best如不含同一步的Adam状态，不能称精确恢复旧训练。后续R1/R2统一采用新Adam作受控适配；若完整optimizer恰好存在，另留作只读证据，不在不同组混用。
6. **固定准入**：源文件身份、共同目标/mask、因果性任一不符则停止。浮点复放沿既有预定数值口径，失败保留诊断，不事后放宽到通过。模型/代码/协议/源选择在训练前锁定。

R0还须形成结论→实验对照→保留权重→后续决策表。若发现早期数据/实现错误，只沿真正依赖该错误的权重、缓存或指标传播；独立对照分支不自动重跑。仅发现论证越界时，修正论证，不产生训练任务。

## R1：2个5轮任务，只回答续训是否稳定

- 同Macro best97/94，原架构、查询头、scaler、当前prefix单视图数据池、batch128/micro8、五位置、梯度裁剪、权重衰减、目标和采样流均保持与Context Transfer prefix相同；两个种子都从新Adam开始。
- **唯一训练改动是LR幅度**：固定为各自源选中epoch的LR。s42编码器约3.06638e−6、查询头约3.06638e−5；s43约3.26487e−6、3.26487e−5。不加新warmup、scheduler、蒸馏或附加损失，避免又混入多个修复因素。
- 高LR参考使用上轮同种子prefix前5轮原记录；共同输入、采样hash、损失定义和初始化必须通过R0。这个对照估计指定配方的LR效应，不解释所有采样/裁剪变化。
- 两组各固定5轮，不按某个好看的中间点入选。第5轮必须是实际有更新的模型，所有24项full/native端点/中途保留指标相对源不超过110%，且训练无非有限值，才允许R2。epoch0回退不能让R1过关。
- 不要求5轮取得新用途增益；这只是排除明显迁移损伤。短期通过不保证60轮稳定，R2继续监测。
- 任一种子未过，或高LR参考无法核对：输出结果并停止当前计划。不开R2，不自动试第三档LR，不增加结构/权重网格。届时先报告具体失败，再修订诊断方案。

这不是恢复原Macro三视图课程，不能称“已经证明原训练可精确续跑”。它验证的是R2拟使用的新基础适配流程能否短期守住源能力。

## R2：6个60轮任务，分开上下文与目标变化

全部重新从原Macro best开始，使用R1已预定的各自低LR；同种子三组初始化、Adam重置、输入端点、随机顺序、位置、更新数、batch、裁剪和loss算法相同。R1产物不做起点，不为某组额外预热。

| 组 | 给编码器的输入 | 历史标签和mask | 能回答的问题 |
|---|---|---|---|
| A 前缀对照 | 原窗口内部分前缀 | 原可见历史 | 基础适配结果 |
| B 完整上下文、共同目标 | 每个端点最近128条 | **逐张量等同A的目标mask/年龄支持** | 在相同被监督内容下，完整上下文编码策略有无作用 |
| C 完整上下文、完整目标 | 与B完全相同 | 全部历史1..127，沿原full配方 | 扩展历史标签并改变有效段权重后，相对B有何增益/代价 |

B的输入策略也改变窗口内绝对位置和累计路径锚点，因此B−A准确称“完整上下文编码策略”的效应，不声称只隔离了物理历史长度或位置编码。A/B监督同一物理端点、同一相对价格坐标、同一mask和同一loss权重；共同mask不能作为解码器额外输入。

C−B把新增历史标签和其支持导致的段级权重变化视为一个明确的目标扩展配方；本轮不再宣称能分别识别这两部分。若要拆开，必须先有值得追踪的差异并另立有限计划，不能事后增加第四组。

每组60轮、每轮38次更新，两种子合计13680次更新。**本轮只做相同更新数对照，不宣称等FLOPs、等GPU小时或计算效率最优。** 记录实测时间和曝光；不再额外延长A做时间匹配，避免增加预算，也不拿上轮不同LR的时间对照充当本轮对照。

## 统一评价与有限决策

- 保留既有full/native、端点/中途、近中远价格/活动/结构指标、24项验证保护、epoch0回退和minimax选模；训练优化loss与模型验收分别报告。每组best和last都保存。
- 增加纯诊断：实际价格单位的近段MAE、单步变化RMSE、分周期/品种、P50/P90/P99及大误差占比。派生报告不改变旧决定或用来研究集挑权重。
- A/B必须报告共同目标上的同口径误差；full读取完整127历史的误差另列，不能把不同可见历史长度混成一项胜负。
- 冻结状态用途沿原13目标/5档alpha机会，统计只由train拟合，val选参，研究评分之前锁定全部模型和读取器；历史方向/波动不是未来交易收益。
- B或C要成为新候选，必须相对A和原Macro均有预定full价格至少5%改善，full/native保护均在10%内；要称表示升级，还需用途至少5%改善及方向/波动保护，两种子/两研究集合配对区间共同支持。B/C各自结论全部披露，不按研究结果挑一个隐藏另一个；即使通过也不自动部署。
- B改善而C退化：支持目标扩展存在代价，不宣称上下文方向无效。B/C都不合格：关闭这个低LR warm-start配方，不推翻从头训练、其他结构或其他目标的可能。A也明显退化：该适配流程仍不稳定，禁止把后续差异说成历史长度单因果结论。
- 达到固定预算即结束；loss仍降不触发追加epoch。没有新有效留出时仍称研究集证据；最终独立验收需在方案冻结后另设数据，不能用反复使用的研究集代替。

## 时间、磁盘和运行方式

依据本次3080Ti实测（prefix约27秒训练/轮，rolling约64秒训练/轮，另加验证/加载/读取器），R1暂估10～25分钟；R2暂估6～8小时；R0暂估不超过1小时的零更新核查，实际以资产齐全和实测吞吐为准。这是规划估计，不是保证时长。

预定R0到R2整套运行最多占用10小时GPU会话。实现需有独立监督超时并输出未完成状态；到限不放宽条件或延长预算，不用未完成组的结果宣称公平胜负。不将失败重试无限排队。

默认单worker、batch128/micro8；源/cache只读复用，保留恢复日志和独立输出目录，启动前按实际checkpoint及缓存大小测算磁盘（预计需约10GiB新空间，以预检为准）。所有阶段自动导出成功/失败/停止状态、源与配置哈希、分项与梯度诊断到`/root/autodl-tmp/download`。当前只发布R0零更新核查脚本；R1/R2训练入口未实现，不能用旧命令开跑新方案。

## 不放进这次补证的任务

- 不重跑旧512、PCA、全部深度/头数、旧活动权重网格或旧自由共同历史头。
- 不重开20组状态外推任务；原失败仅限定原表示与原预测配方。
- 从头全128位置、跨分辨率语义对齐和更深架构继续保留为未来研究分支，既未被当前失败否定，也不是本次必须补跑的债务。

若之后重新选择主表示，依赖该表示的用途/预测分支需要重新验证，数量必须在新来源确定后单列；那属于新基线的迁移验证，不把所有旧试验自动加入本次重跑清单。
