# 原局部头继续适配：固定control600，检验中途bar回读

2026-09-26。用户同意暂停当前跨周期约束实现、回到主线。本轮仅训练两份已有局部头，不新增架构、技术指标或未来预测任务；跨周期方向保留，0.10一致性配置不继续搜索。

## 要回答的问题

当前control600是更强的末端重建研究候选，但不能由末端128根回读推断所有中途bar的状态都充分可读。之前随机新局部头失败，连原位置都未追上原头，不能据此断言状态缺少信息。

本轮从每个模型各自的原局部头出发、冻结编码器，检验固定预算的局部优化能否带来可重复的留出位置改善。比较对象是同一个冻结编码器和原头的epoch0，不把不同种子的头强行重置为相同随机参数，也不把前一轮随机头结果当作同条件对照。

## 固定设计

| 项目 | 约定 |
|---|---|
| 来源 | 完成的`babel_cross_period768_v2_recheck`及其指向的原训练目录 |
| 模型 | control_s42/control_s43原验证best100，总600轮，768维/4层/8头/FFN3072 |
| 可训练部分 | 原768→256→16×7共享局部头，225648参数；逐张量原样载入 |
| 保持冻结 | 编码器、全局PCA解码器、已校准历史用途头；不增加输入或状态维度 |
| 状态处理 | 原始状态；恒等缩放mean=0、scale=1，无新统计拟合，不改变原头函数 |
| 目标 | 原past16七通道目标、原归一化与缺失mask，排除当前bar；局部SmoothL1 |
| 训练 | 每种子100轮，4789训练窗口/轮，每窗四个不同非留出位置；batch128，3800次局部头更新，1915600位置曝光 |
| 优化器 | AdamW重新建立，峰值3e-5、5轮预热、余弦降至0.1峰值，weight decay1e-4、梯度裁剪1；不搜参数 |
| 选模 | 978验证窗口，只用32/64/96/128的局部MSE；原头epoch0可回退 |
| 留出位置 | 48/80/112不参与本轮训练和选模；它们是已反复使用的研究位置，不是全新最终留出 |
| 评价 | 原984/453研究窗口，两个种子各original/best/last，共12份研究记录；不重新拟合Ridge |

该头在前序阶段已有联合训练，故100轮指本次适配预算，不是冷启动总训练时长。新阶段固定4789窗口覆盖不同于父模型的密集三视图抽样，结论只针对这次适配，不能将所有变化归因于“优化器重置”或“原头初始化”。不同种子分别比较各自原头，数据顺序与位置按原固定种子计划生成。

每根中途bar只能编码其之前及当前已观察前缀。这里的局部头读回该bar之前16根，不是让第32根bar重建其后的128根，也不是128根全部压缩的普遍证明。较长全局回读与逐bar局部可读性仍是两个任务。

## 事前判据与停止条件

两个种子、两个研究集、best和last同时满足：

1. 留出48/80/112位置综合误差相对原头至少下降5%，按原交易周配对区间的上界≤0确认。
2. 训练位置组32/64/96/128综合误差增加不超过5%。
3. 留出位置path/body/activity/change1各分项保留10%。
4. 七个评价位置逐位置综合误差各保留10%，防止平均值掩盖某一个位置明显退化。

共104条检查，使用原1000次周级bootstrap、固定seed42、至少50窗口/5周，不多重校正。通过记`warm_local_readout_gain`，否则`no_warm_local_readout_gain`；epoch0完全不变不满足5%改善，不能包装成突破。best与last重复时不当作独立证据。

通过仅支持这组冻结状态在该局部头下可改善回读，不宣称信息全保留或未来可预测。失败也不能证明信息不存在或已充分收敛。原全局重建/历史用途输出通过权重、缓存和原证书绑定保持；不复训这些能力，也不改写完整用途未通过的结论。一次固定100轮，不自动扩头、调LR、增加规则标签或延长预算。

## 工程和恢复

先校验完成的补评价报告、原训练检查点、读出锁和祖先数据。原56个绑定模块（含补评价入口）保持不变。缓存冻结状态后，小头训练阶段不加载编码器；训练位置94个、验证4个、研究7个，目标在CPU按原定义构造。约3.5GB缓存，建议保留至少5GB空闲磁盘。

原头以单独文件复制到新缓存并校验哈希，训练前复现完整父验证和截断因果性，缓存末端状态与原报告所绑定的状态数组逐批复验。原头在新缓存上的验证局部误差须复现。每次更新只作用于新输出目录内的小头，源检查点不覆盖。

两组全部完成预算并锁定best/last后，才提取研究位置和评分。评价batch64与此次源报告一致，严格复验原局部头的各位置/聚合指标，失败写出实际差值，不盲目放宽容差。

默认一个小头进程，适合当前12GB机器；可用`BABEL_LOCAL_WARMSTART_JOBS=2`并行两个头，任务定义和预算不变，但本地未实测实际GPU显存。缓存阶段与小头训练阶段显存/利用率不同、轮次较快均属预期；不会在两轮后停止。启动训练前释放管理进程的无用CUDA缓存，记录GPU空闲容量。失败时主日志包含子进程异常。

相同命令恢复最后完整轮的头、AdamW状态和随机状态，已完成组核验后跳过。任何来源、缓存、初始头或配置变化均拒绝原目录续跑。训练100轮后最后一轮即使仍下降，也按事前预算结束。
