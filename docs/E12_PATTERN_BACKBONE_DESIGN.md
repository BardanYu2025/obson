# E12 设计稿：K 线形态理解骨干网络（Pattern Backbone）

> v1 · 2026-09-17 · 供用户与教师模型评审
> 状态：标签地基已完成（docs/BAR_LABELS.md），本稿定义架构、训练任务与毕业门禁。

## 〇、需求背景（用户原话的工程翻译）

放弃"用 K 线预测未来 K 线"的点预测范式（已被我们十几组实验与 klm 分支独立证伪，
且逻辑上接近零和博弈）。转向：**训练一个"看懂 K 线"的表示模型**——
识别状态（上升/下降/盘整/蓄势）、识别形态（头肩顶、支撑压力、缠论结构）、
输出每根 bar 的上下文化 embedding，作为一切下游任务（含交易）的预训练骨干。
即便最终交易价值有限，标签体系与规则库本身是知识积累，可接受。

## 一、已证伪档案（本设计的约束条件）

| 证据 | 结论 |
|---|---|
| E4/E5/E6 结构变体（exc-aux/双向/调参） | 对三分类信号无增益 |
| E7-A 对比预训练（α=0.1 噪声视图） | probe 0.350 < 随机 0.385，坍缩 |
| E7-B 自回归预训练 | 微调有害（+0.0661 vs 冠军 +0.1003） |
| E10 隐空间动力学 | 未来表示无标签结构（质心 cos 0.98+） |
| klm 层级 gate/方向（H1–H7） | 条件方向 BA≈0.500；机会 gate 弱–中等排序信号 |
| T+1 锚点 | +0.0749，信号短时效 |

约束：**方向分类不得作为训练目标**；自监督任务必须防坍缩；
评价必须先过机制门禁，再谈下游价值。

## 二、标签宪法（已实施，docs/BAR_LABELS.md）

1. 形态本体用**几何**定义（枢轴/摆动/时间比例），指标只做陪审团确认；
2. 每根 bar 携带 3 尺度 × 6 字段结构身份（18 维），切窗不丢历史；
3. 事件时刻（训练标签）与确认时刻（实盘可知性）显式分离；
4. 本标签为**规则族 A**（zigzag/ATR 阈值）；族 B（独立定义）留作跨族泛化测试；
5. 缠论保守化：首发不引入笔/段，待枢轴解析稳定后选单一可复现流派作为 v2。

## 三、架构

### 3.1 骨干：per-bar 因果 Transformer（BERT 同构，token=bar）

```
输入: OHLCV(+持仓) bar 序列（原始量价，不含任何指标特征——防捷径第一闸）
嵌入: bar 特征线性映射 + 品种 embedding + 频率 embedding + 日内时刻 embedding
骨干: L 层 Transformer，输出 [B, T, H]，h_t = 第 t 根 bar 的上下文表示
```

- **每根 bar 一个 embedding**，监督信号密度从"每窗 1 标签"升至"每 bar 18 字段"；
- 品种/频率 embedding 可学习，新品种新周期只需微调；
- 首发固定窗口（如 256 bar），变长与多周期拼接留 v2（patch 化是 v2 候选，见 §七）。

### 3.2 因果/双向双模式（现在定死，防未来泄露事故）

- **因果版**（因果掩码）：任何实盘下游的唯一合法接入点；
- **双向版**（全注意力）：只用于离线分析、标签质量研究、表示 probe；
- 两个版本分别训练、分别存档，命名强制区分（`*_causal` / `*_bidir`）。

### 3.3 稠密监督头（全部 per-bar，无整窗 logit）

| 头 | 任务 | 输出 |
|---|---|---|
| 段方向头 | 3 尺度 × 3 分类（升/降/未定） | [B,T,3,3] |
| 时间坐标头 | 3 尺度回归 bars_since_piv | [B,T,3] |
| 空间坐标头 | 3 尺度回归 amp_since_piv | [B,T,3] |
| 枢轴检测头 | 3 尺度 × 2 分类（是高点/是低点） | [B,T,3,2] |
| 成色头 | 枢轴 bar 上回归 piv_amp | [B,T,3]（非枢轴 mask） |

另加自监督任务：**掩码 bar 重构**（随机遮 15% bar 的输入特征，从上下文重建）——
借鉴 E7 教训：必须有遮蔽难度，否则对比/重构任务太易坍缩。

## 四、训练课程

```
阶段 1（ backbone 形成）：掩码重构 + 全部稠密头联合训练
阶段 2（ probe 毕业考）：冻结骨干，线性 probe 检验（见 §五门禁）
阶段 3（下游接入，另行立项）：gate / 形态分类 / 检索，冻结骨干 + 小头
```

损失：L = L_recon + Σ_s w_s · (L_dir + λ1 L_time + λ2 L_amp + λ3 L_piv + λ4 L_quality)
（权重首发全 1，可调；每分量单独记账，教师纪律）

## 五、毕业门禁（预先承诺，全过才算"看懂"）

> v1.1 修正（2026-09-17）：初版把事后口径标签直接套在因果版上，
> 等于要求"拐点发生当下即识别"——这是变相预测未来，违背本项目前提
> （人也是事后才确认头肩顶的）。门禁改为**双轨**：理解轨测"看懂"（严格），
> 前瞻轨只评"当时可知"（容差）；拍脑袋的绝对线改为基线对比。

### 理解轨（双向版，事后标签合法）

- **U1 枢轴解析 F1 ≥ 0.6**（双向看见全窗，事后重建枢轴序列）
- **U2 段方向 BA ≥ 0.7**；**U3 坐标回归 R² > 0.5**
- **U4 跨规则族泛化（杀手锏）**：冻结骨干+线性 probe，在独立规则族 B
  （分形/滚动极值序数定义，对单调变换不变）标签上 F1 ≥ 族 A 的 70%
- **U5 不变性一致性**：价格仿射 + 时间伸缩 ±20% 后 h_t 余弦 ≥ 0.9
- **U6 无坍缩**：h_t 逐维 std 中位 ≥ 0.1，且显著超过随机初始化骨干

### 前瞻轨（因果版，只评当时可知）

- **A1 枢轴检测按容差事件评估**：预测落在真实枢轴 ±3 bar 内算命中；
  基线 = 实时 zigzag 规则检测器（确认才报）与随机骨干，
  要求显著超过基线（margin 首轮训完看分布后预注册，不拍脑袋）
- **A2 段方向/坐标回归只在"已确认段"样本上评估**（未确认段不惩罚模型）

**明确不做**：任何方向/涨跌分类不作为训练目标，不作为门禁。
（方向 probe 可作参考指标记录，但不过线不否决。）

## 六、数据

- 首发：现有 13 品种 × 5m/15m/30m/60m（本地 36 文件为近期子集；
  训练用 AutoDL 全量数据重跑 build_bar_labels.py 生成标签）；
- v2 候选：股票/股指日线与分钟线（akshare/天勤），检验跨资产迁移；
- 量仓字段：首发输入含 volume/open_interest（原始量仓是形态陪审团的信息源，
  不构成指标泄露——它们是原始数据不是派生指标）。

## 七、风险与 v2 方向（记录在案，本轮不做）

1. **固定窗口的 receptive field 限制**：长尺度枢轴的历史可能超出窗口；
   per-bar 标签设计（历史已烘进标签）部分缓解；v2 走 patch 化多周期（Moirai 式）。
2. **缠论笔/段**：单一可复现流派，歧义率全程记录，v2 候选。
3. **形态分类（头肩顶等）**：作为枢轴序列上的规则匹配 + probe，v2；
   模型学会枢轴语法后，形态库是纯规则资产，无需重训。
4. **tick/1m 数据**：天勤账号可下，v2 补。

## 八、里程碑

```
M1 数据管道：AutoDL 全量标签生成 + 训练/val/test 按交易日切分
M2 骨干训练：因果版首发（生产合法），双向版对照
M3 毕业门禁：G1–G6 全过 / 不过则按门禁分项定位死因，记录封存
M4（另立项）：下游接入评审——才轮到"对交易有什么用"
```

判决承诺：G1–G6 任一不过，不进入 M4，不声称模型"看懂 K 线"。
