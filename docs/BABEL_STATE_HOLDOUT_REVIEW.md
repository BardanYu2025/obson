报告：`babel_state_holdout512_reports.tar.gz`。SHA256：`bd2834d93b6ef398f68102d7c9296e1e9262b37c8a994bb7ab8932ab32f87c01`。
实现版本：`7c721c9`；协议见[BABEL_STATE_HOLDOUT.md](BABEL_STATE_HOLDOUT.md)。

## 结论

本轮完整完成。原量仓历史线性读出的收益在可审计来源范围内的五个新评价品种上保留；新12描述任务的综合迁移和统计增量没有达到两个编码器种子、三种读出均成立的预声明标准。两个种子的价格保留都失败。

因此，上轮旧研究集的正向证据不能升级为稳定、全面的跨品种增益。量仓增强候选有明确的信息保留价值，但不是可直接替换价格control的通用升级。无法据此断言512维不足、共享状态必然无效或量仓毫无价值。

## 阶段决策与下一步建议

1. 不用aux全面替换control，不丢弃量仓增强候选。现有证据支持二者有不同的信息保留取舍，尚未定位到容量不足或确定的梯度冲突机制。
2. 下一小步优先复用现成冻结状态：保留价格control状态及原价格头，另保留aux作为量仓补充；先检验两个状态拼接是否提供有用增量，不立即再训练更大的编码器。价格头继续读取原control部分，其输出不变是设计保证，不是新实验学会了价格保留。
3. 组合短状态会从512变成1024维、需要两路编码推理，不能称同容量提升。对照至少包括单独control、单独aux、统计及control+统计，并加入等维双价格状态对照；读出预算/参数量明确报告。两种子共用预训练及部分对照，不夸大独立重复数。
4. 任何新读出只在原train/val拟合和选择，先判断组合是否值得部署或进一步蒸馏。若没有超过透明统计对照的稳定增量，不默认扩展分支或追逐最低loss。组合有用后才考虑压缩/联合训练，不能预写成功。
5. 本轮五品种结果已打开，后续设计使用其结果就使其进入研究集。重复回放可检验实现与取舍，但不得再次称为未打开的确认集；未来定型仍需新的可审计数据。

本提交只完成报告复核和计划更新，没有新增训练入口、训练权重或未来预测结论。
