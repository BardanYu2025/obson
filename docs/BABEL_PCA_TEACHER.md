# PCA教师引导的因果历史表示

## 阶段目标与边界

用户提出使用PCA重建帮助模型学习。本轮优先把PCA当作训练老师：让编码器预测一套已知有效的压缩坐标，通过固定PCA逆变换验证其历史信息保留，再允许仅依赖预测状态的残差解码。

最终主评价必须是 `已观察特征→因果编码器→自己预测的512维状态→重建`。PCA真坐标、真实历史和重建结果不进入学生前向，也不存在把真实PCA重建直接加到学生输出的旁路。评价中的PCA基线与真坐标诊断明确单列。

本轮依据：capacity512的512通路有帮助，但相对旧attention价格退化、综合误差仍高于PCA256；95–131轮后验证恶化。现在定位表示学习与读取问题，不再扩大三架构矩阵。原计划的冻结旧状态读出/旧交叉注意力解码校准暂后置；已知PCA逆变换的数值闭环取代本轮另训一个校准解码器。既有模型不自动替换。

## 数据和因果性

只读复用 `checkpoints/babel_architecture512` 的完整缓存和训练集拟合PCA512。源代码、完成记录、来源指纹、缓存、PCA及原始选模锁启动/结束时核验。不会改动上一轮的实现或权重。

输入仍为每个128bar窗口的28维特征，目标仍为排除最后一根的有序收盘路径、实体及5个量仓量；缺失目标用原训练均值填补供PCA编码，主重建损失继续使用原mask。train4789/val978/test984/cross453，原归一化、端点及分区不变。教师系数均值和标准差只在训练窗口计算，std下限1e-4；验证/研究数据不参与拟合。

每个教师向量只描述该端点可观察历史。不能把完整128窗口重建出的第50根当作第50根当时可用输入。本模型输入始终是原因果特征，编码器严格前缀注意力；仅窗口端点受坐标监督，不宣称窗口内每个较短前缀都已充分训练，也不新增长历史流式能力。

## 模型

使用原生512维、2层、8头、FFN512的因果attention。末端线性映射512→512预测标准化PCA坐标，无末端降维或全状态LayerNorm。

固定解码器先按训练统计还原坐标，再乘固定512×896的PCA基底并加目标均值，输出128×7历史。PCA均值、基底和坐标统计全部是不可训练buffer。初始与残差分支的单向量入口都保持512维。

所有学生包含同一残差MLP（512→256→896），最后一层严格零初始化。基础组冻结并关闭它；续训残差组开启。较窄残差分支不限制固定PCA主通路；新增输出仍只来自同一个预测状态。编码器有3,433,472个参数，残差头361,600个参数；基础组可训练3,433,472个，残差组3,795,072个。固定/残差组储存参数一致，但可训练参数和算力有意不同，不能声称等可训练参数。

## 固定矩阵与归因

seed42/43各一套，基础训练共4组，各200轮：

| 组 | 解码器 | 坐标辅助监督λ |
|---|---|---:|
| plain | 固定PCA逆变换 | 0 |
| teacher | 固定PCA逆变换 | 0.25 |

两个基础组在同一种子下所有初始参数相同。都具有PCA解码先验，因此teacher−plain才能隔离坐标监督收益；不能把它们相对旧可学习解码器的差异全部归因于教师。

全部基础组完成，按原验证综合MSE锁定各自最佳检查点，然后分叉以下5种续训，每种2个种子，共10组，各100轮：

| 组 | 继承 | 解码器 | λ策略 | 核心对照 |
|---|---|---|---|---|
| plain_fixed | plain最佳 | 固定 | 0 | 等预算继续训练 |
| plain_residual | 同一个plain最佳 | 固定+残差 | 0 | 对plain_fixed，测残差适应 |
| teacher_fixed | teacher最佳 | 固定 | 0.25 | 等预算继续训练 |
| teacher_residual | 同一个teacher最佳 | 固定+残差 | 0.25 | 对teacher_fixed，测残差适应 |
| teacher_release | 同一个teacher最佳 | 固定+残差 | 前50轮从0.25线性降到0，此后0 | 对teacher_residual，测减弱教师约束 |

兄弟分支有相同的父检查点、初始预测、数据顺序、优化器重置和学习率；激活的残差初始为零。启动分支先逐项复验父模型验证指标。teacher/plain的父模型最优epoch可能不同，这是同预算验证选模的结果，记录实际继承轮次及指纹，不称为相同有效预训练步数。

基础组lr3e-4，续训统一lr1e-4；AdamW、weight_decay0.01、clip1、5轮预热及余弦下降，FP32/关闭TF32。有效batch128、micro64，默认2worker并行。14组共分配1800轮计算，每条谱系预算200+100；被继承权重实际上来自父组所选epoch，不能说所有最终检查点都经历了300轮更新。100轮是匹配的续训筛选预算，不预设收敛或用未改善否定方法。

## 损失和选模

`L = 原历史SmoothL1综合损失 + λ × 标准化PCA坐标SmoothL1均值`。

原主损失权重保持路径0.4、多尺度变化0.2、实体0.1、量仓0.3；变化跨度1/4/16/32。真实历史始终是主目标，绝不只拟合教师重建。减弱辅助约束后，状态允许偏离PCA坐标，因此应称PCA引导的状态，而不是宣称它始终是严格的PCA编码。λ0.25是预先声明的探索设置，不称最优权重。标准化坐标辅助项使低方差方向也得到监督；它也可能强化无用细节，因此必须设无教师对照并检查主指标退化。

仅原验证集综合MSE决定checkpoint，坐标误差、研究集及画图不得参与选模。epoch0也可保留：基础epoch0代表无训练候选；分支epoch0可能是已训练父模型，必须区分“父模型已训练”和“续训取得改善”。所有14组锁定后才读取研究集数组做神经评价。两研究集早已开放，不称新留出。

报告每组最佳和固定末轮、完整曲线、实际教师权重、PCA坐标整体/分段误差、目标族及年龄段、PCA256/PCA512和coarse112、逐窗口误差及品种/周期/月/周配对。残差组额外报告关闭残差以及输入真实PCA系数的诊断结果，后者不能冒充学生成绩，也不是保证更好的理论上界。坐标接近PCA不保证主指标最好，因为PCA拟合准则和带mask/多尺度权重的主目标并不相同。

阶段判断：教师−plain、残差−同父固定头、release−同父残差保持组，分别检查两个种子/两个研究集的主指标配对证据以及价格/变化/实体/活动退化。区间未做多重比较校正，只是探索性；没有显著退化不等于等效，不自动晋升。

## AutoDL启动和导出

```bash
cd /root/autodl-tmp/obson
git fetch origin
git switch features/babel
git pull --ff-only origin features/babel
mkdir -p logs /root/autodl-tmp/download
nohup env BABEL_TEACHER_JOBS=2 BABEL_TEACHER_MICRO=64 \
  bash scripts/babel_pca_teacher_autodl.sh all \
  > logs/babel_pca_teacher512.log 2>&1 &
tail -f logs/babel_pca_teacher512.log
```

默认只读源为 `checkpoints/babel_architecture512`，新目录 `checkpoints/babel_pca_teacher512`。不要删除源缓存或pca.npz。脚本完成预检、4组基础训练、父选模锁定、10组续训、完整评价，结束或报错都自动导出：

`/root/autodl-tmp/download/babel_pca_teacher512_reports.tar.gz`

包括指标、全部历史、父/子谱系、配置、PCA坐标统计、预检、固定示例HTML和日志；不包括权重/缓存二进制。手动导出：

```bash
cd /root/autodl-tmp/obson
bash scripts/babel_pca_teacher_autodl.sh export
```

相同命令可恢复中断组并跳过完成组；恢复优化器/RNG并复验验证分数。只补评价用evaluate，只运行合成GPU前后向与PCA逆变换数值闭环用preflight。变更预算/有效batch/micro需要新run目录，不能覆盖已有manifest。父/子训练分别记录每轮耗时及本组剩余时间；旧实验耗时不能直接套用此解码器。
