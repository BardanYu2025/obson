## 二、本轮完成的实验与判决

### P1 诊断（此前已完成）
lr（1e-3 vs 3e-4）/ batch / OneCycle 三嫌疑全排除 → **早停 2~4 轮 = 标签信息量稀薄**，此为一切后续实验的动机。

### E7-A（对比学习预训练，协议 v3 经教师批准）
- 实现：同窗口双视图收益率抖动（α=0.10）+ 排除版 NT-Xent（τ=0.1，同品种 30 天负样本保护区）
- 结果：InfoNCE 0.70→0.038，第 11 轮平台期自停（任务太易，非训练不足）
- probe：label BA = 0.350 < 随机初始化 0.385 → **未过门禁，未进微调**

### probe 仪器修复与最终作废
- v1 失灵（冠军=随机=0.333）；v2 修复（标准化 + 类加权 + 500 轮 + 训练集 BA 自检 + 仪器警报线）
- **两次独立复现同一结论：监督冠军 label BA 0.383 ≈ 随机 0.385（<2%）**——冠军回测赚钱但其表示线性读不出标签
- 判决：**linear probe 对本任务结构性失效**（标签信息高度非线性），路线作废；此后预训练判决一律走直接微调看 val mean_edge

### E7-B（自回归预训练：前 t 根 → 预测第 t+1 根 OHLC 对数收益，σ 缩放）
- 训练：Huber 0.330→0.093（20 轮未平台），训练段 dir_acc 55.7%→80.6%
- 微调对照 e7bft_s42（与冠军逐项同配方，唯一变量=主干初始化）：
  - best val mean_edge = **+0.0661** vs 冠军 +0.1003 vs 判决线 +0.110
  - **差冠军 34%，判决：有害而非无效**（预训练把主干拉进更差盆地，dir_acc 高 = 记训练集特化）
- **结论：预训练方向两次独立失败（对比 + AR），路线封存**

## 三、T+1 锚点（next_close）——已有结果，判决：❌ 证伪（2026-09-15 补记）

**假设**：瓶颈是标签信息量 → 标签视野从"当日收盘"延到"次日收盘"，平均观测时长 ~3 倍。

**实现**（commit 62aadb1）：
- `--label-anchor next_close`：anchor_days_ahead 参数化锚日；θ = c·σ_w·√rem 随视野自动放大，校准逻辑零改动
- 泄露双闸：① 构造时锚日超出本段自然剔除；② contract 模式按"锚日 ∈ 切分日集"二次过滤
- 冒烟：rb_60m 有效样本 +15%（尾盘样本不再剔除），"无"占比仍 ~89%（θ 随 √rem 同步放大，预期内）

**结果（t1_s42，与冠军逐项同配方唯一变量=锚日）**：
- best val mean_edge = **+0.0749** vs 冠军 +0.1003（**-25%**），11 轮早停
- **判决：证伪**。信息量不随视野增加——信号短时效、集中近端；拉长视野只稀释噪声比
- 未探方向只剩：更短锚（horizon 120min，画可预测性-视野曲线第三段）、标签形式改革（路径分位数回归）
