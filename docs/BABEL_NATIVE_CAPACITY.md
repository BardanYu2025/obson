# 原生状态维度与解码通路容量对照

## 阶段目标

保留可观察价量历史的因果压缩表示。先纠正上一轮名义512维、实际解码通路至多256维的比较问题，再判断扩大信息通路是否改善历史细节。历史重建不是预测；本轮不替换既有长短状态主模型，也不新增交易信号规则。

保留旧 architecture 模块及源运行不变。新脚本只读 `checkpoints/babel_architecture512` 的完成记录、权重指纹、缓存、原始PCA和选择记录。缺少源缓存或PCA时直接报错，不重新抽样或重拟合冒充复现。源数据与权重应留在AutoDL服务器。

## 先审计，再执行固定矩阵

运行开始锁定全部配置，然后复算旧PCA512的逐窗口误差及总指标。只截取同一训练集拟合基底的前256个成分，补报PCA256及旧六个神经模型相对PCA256的周配对差异。结果不改变随后预先固定的神经实验配置。

旧attention/卷积端点内部256维后投影512；旧全部解码器在位置展开前512→256。旧GRU的512维状态本身可能保有更多信息，不能说它只有256维。PCA256只匹配维度预算上界，不保证编码器输入、非线性或优化难度等价。

## 新模型与控制变量

三个编码器全程原生512维端点，无末端全状态LayerNorm或降维投影：

| 编码器 | 配置 | 上下文 |
|---|---|---|
| GRU | 512维、2层 | 每个窗口重置 |
| 因果Transformer | 512维、2层、8头、FFN512 | 严格前缀掩码 |
| 因果多尺度卷积 | 512维、6块、分支宽320，膨胀1/2/4/8/16/32 | 第一层核4，其余核3，感受野正好128 |

注意力FFN和卷积分支可以较窄，但残差主通路保留512维。编码器参数分别3,167,744、3,170,816、2,985,024；公共解码器2,371,335。近似匹配、不宣称参数或算力完全相等。每个窗口仍为128根；EMA输入可携带共同的更早上下文，不宣称完全没有窗口外信息。

公共解码器：端点状态→固定秩约束→可训练512×512线性映射（单位阵初始化）→两个256维记忆token；128个固定位置查询经过2层、8头交叉注意力解码，输出7个历史量。没有原始输入、标签、逐窗口mask等旁路。不是自回归解码。

同一编码器/种子比较：

- rank256：固定随机正交旋转，显式把后256个坐标置零，再逆旋转；乘√2以保持各向同性输入的期望能量。
- rank512：相同旋转和逆旋转，保留全部坐标，不缩放（浮点精度内等价于恒等映射）。

显式置零避免把预计算的FP32低秩矩阵中的舍入误差当作额外信息通道。两者使用同形状512×512乘法，模型参数数量、初始权重完全相同；有效函数自由度有意不同。投影独立于数据，固定seed7001。两个token的合计容量才是入口维数，不能拿单个token宽度冒充全部容量。记录端点到展平记忆的数值秩和奇异值；结构上允许512维不代表训练后真的利用了512个独立信息方向。

新旧编码器深度、归一化、解码器均有变化，不能把新旧分数差全部归因于瓶颈。主因果对照是新实验内部同编码器/种子的rank256与rank512。

## 训练和评价

3架构×2容量×2种子=12组，均从头训练200轮，有效batch128、micro64，默认两个worker并行。FP32、关闭TF32；AdamW、weight_decay0.01、梯度裁剪1；前5轮预热后余弦下降。固定LR3e-4来自旧实验六个验证集LR选择，不按研究集重新调参。本轮是共同LR预算下比较，不宣称找到每种架构的最优超参或已完全收敛。

直接复用原train4789、val978、test984、cross_research453窗口、顺序、mask与训练集标准化。目标为有序收盘路径、实体、五个量仓历史量，排除最后一根，原损失权重/1、4、16、32根变化尺度不变。训练可打乱train窗口；不混入验证/研究集。所有12组完成并锁定验证最优epoch后才评价神经模型研究集；另报每组固定第200轮结果和epoch0/预算末尾标志。

同时报告PCA256/PCA512、coarse112等基线、目标族及时段分层、1/4/16/32变化相关性和标准差比、逐窗口误差、按周配对区间、品种/周期/月份分组、固定示例图。研究集已经被使用，不称独立留出；多重比较未校正，结果为探索性。容量改善要求两种子、两研究集均有主要指标改善证据，并单独列出价格/变化/实体/活动退化；没有显著退化不等于等效。无自动晋升。
