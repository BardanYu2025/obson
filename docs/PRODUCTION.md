## 1. 生产模型（候选冠军 = E3 v1.1，2026-09-14 过判决协议，前向实盘确认中）

**配置**（train_multi_symbol.py）：

```
--task classify --label-anchor day_close --theta-mode dynamic --theta-q 0.90 \
--soft-label --close-path --periods 60 30 --daily-bars 20 --foreign-bars 20 \
--contract-mode --path-aux --path-aux-weight 0.1 \
--batch-size 256 --lr 1e-3 --epochs 40 --patience 8
```

- 架构：KLineTransformer，13 品种 × 60/30m 混训，**单向 causal attention**（双向已两次证伪），last 读出
- 输入结构：`[日K×20][外盘日K×20][分钟主窗口(一周)]`，close_path 锚定窗口前3根收盘均值
- **数据：合约模式**——按 1/5/10 月主力轮转规则自建连续序列（`data/contracts/`），不依赖主连复权
- 标签：当日收盘锚定 first-passage 三分类（先摸上轨=多/先破下轨=空/都没=无），θ 动态 = c×窗口σ×√剩余bar，**θ 校准按段独立**（跨段污染已修）
- 损失：0.5×硬CE(类别权重) + 0.5×软CE + 0.1×**路径状态辅助**（4节点×3态 masked CE，逐节点类别权重）
- **路径辅助头**（E3）：pooled + node_emb(4) → 逐节点 3 态；验证集 BA 0.38~0.42（基线 0.333）
- 选模/早停：验证集 mean_edge（信号命中率超基准的幅度，信号数<50 时 shrinkage）
- **成绩**：验证 mean_edge s42 +0.1003 / s7 +0.1262；**生产口径：单仓 v2 +10.06%（58 笔胜率 58.6% 回撤 1.70%）、成本加倍 +7.24%（历代最佳）**

## 2. 数据

### 内盘（天勤 tqsdk，账号走环境变量 TQ_USER/TQ_PASS）

- 13 品种：rb hc i sr p j jm m y cu ag TA MA
- 文件：`data/{code}_{60,30}m.csv`，8 列 `datetime,open,high,low,close,volume,open_oi,close_oi`
- 覆盖（免费版窗口上限 8964 条）：60m 自 2021-05 起（cu/ag 稍短）、30m 自 2023-08 起
- **增量快路径（2026-09-14 修复）**：一页（8964 根）覆盖旧末尾时直接合并，
  不再翻私有锚定页——根除了 nightly 的"锚定页等待超时"；断档超一页才兜底翻页
- 刷新/重下：

```bash
TQ_USER=<账号> TQ_PASS=<密码> PYTHONPATH=src python -u scripts/download_tqsdk_v2.py \
  --periods 60 30 --incremental && cp data/raw_tqsdk/*.csv data/
```

- **跑下载前必须关 VPN/代理**，天勤连代理会超时
- 5m/15m 也有（窗口更短：5m≈7 个月，15m≈20 个月），仅供 fine 分支用，生产不用

### 外盘（Wind EDB，两列 `yyyymmdd,close`，活跃合约收盘价）

存 `data/foreign/{name}_1d.csv`，品种映射：sr→ice_sugar, p→bmd_palm, y→cbot_beanoil, m→cbot_soybean, rb/i→sgx_iron, ag→comex_silver。
因果闸：基准 bar 日历日 c → 只用 ≤ c−1 的外盘收盘。
当前状态（2026-09-11 实查）：棕榈/银/铁矿 至 9/10，大豆/豆油 至 9/8，白糖 至 9/7，全部在 5 天新鲜度窗口内；数据可手工往 CSV 追加两行格式的新行。

**新鲜度三态（fail-closed，2026-09-11 起生效）**：`src/obson/foreign_freshness.py`，
`signal_live.py` 每次跑信号前自动检查有外盘映射的品种（sr/p/y/m/rb/i/ag）：
- `fresh`：最新日期滞后 ≤ 5 个日历日（覆盖周末+海外小长假，不按固定 1~2 天，防节假日误锁）
- `stale`：滞后 > 5 天 → **该品种本次禁止出信号**（手册判定被强制覆盖为观望）
- `unavailable`：文件缺失/为空/无法解析/close 非正/日期乱序 → 同样禁止出信号
- 无外盘映射品种（hc/j/jm/cu/TA/MA）不受影响
不做零特征降级（ckpt 按 foreign_bars=20 训练，置零行为无证据支撑）。测试 `test_foreign_freshness_states` 锁定。

## 3. 训练

标准训练命令（生产配方；改任何一项即为实验，需走判决协议）：

```bash
PYTHONPATH=src python -u scripts/train_multi_symbol.py --task classify \
  --label-anchor day_close --theta-mode dynamic --theta-q 0.90 --soft-label \
  --close-path --periods 60 30 --daily-bars 20 --foreign-bars 20 \
  --contract-mode --path-aux --path-aux-weight 0.1 \
  --batch-size 256 --lr 1e-3 --epochs 40 --patience 8 --seed 42 \
  --save-dir checkpoints/<实验名> > train_<实验名>.log 2>&1
```

**判决协议**（换模唯一标准，2026-09-14 修订：mean_edge 两次与生产背离，生产口径升为第一裁判）：
1. 新配方跑配对种子 s42 + s7
2. **生产口径三项全过**：单仓 v2 不劣于冠军、成本加倍不转负、p 品种不拖后腿
3. 验证 mean_edge 双 seed 不塌（参考线，不再单独作为换模依据）
4. 信号数不塌缩（<冠军的 50% 视为塌缩）
5. 全部通过才换；否则冠军继续上岗

### 训练数据明细（2026-09-09 重下后口径）

**输入结构**（每个样本）：
- 分钟主窗口：一周 bar 数（60m=35 根 / 30m=60 根；cu 45/80、ag 55/95，因交易时段数不同），OHLC 经 close_path 锚定 + 窗口波动率 RevIN 定标
- 日线金字塔前缀：20 根已收盘日K（由分钟线聚合，严格不含当日）
- 外盘日线前缀：20 根外盘收盘特征（仅 sr/p/y/m/rb/i/ag 有锚品种；其余品种该通道置零）
- 技术指标 7 维（MA位置/波动regime/区间位置/RSI/MACD代理/布林挤压/ROC20，全因果）
- 时间特征 9 维（月份sin-cos/时段onehot/日内位置sin-cos/剩余时间比例）

**标签**：当日收盘锚定 first-passage 三分类。从当前 bar 收盘起，先摸 +θ=多(2)、先破 −θ=空(0)、到收盘都没摸=无(1)；同根双触记无。θ 动态 = c × 窗口σ × √剩余bar（c 按训练段 90% 分位校准，下表）。尾盘 30min 内样本、截断日、断链日均剔除。

**切分**：时间硬切 70/15/15，切分点吸附到交易日边界（防止同一交易日的样本和收盘锚被切进两个集合）。

## 4. 预测（每日信号）

**AutoDL 一键脚本**（下载数据 + 跑信号）：`./night_signal_autodl.sh`
最佳时机：夜盘 21:05 之后（第一根 60m bar 收盘）；23:00 后收盘无数据更新意义不大。

**手动等价命令**：

```bash
PYTHONPATH=src python -u scripts/signal_live.py \
  --ckpt checkpoints/q90_softfix_s42/best.pt,checkpoints/q90_softfix_s7/best.pt \
  --symbols rb hc i sr p j jm m y cu ag TA MA --periods 60 30 --theta-q 0.90
```

**输出读法**：
- `自适应阈值`：验证集上按"每 100 根 K 线各喊 5 次"校准出的多/空信心线
- `自检(测试集)`：喊多/喊空命中率 vs 基准（基准 = 乱喊的命中率），倍数越高越值钱
- `半成品bar衰减`：盘中信号的可信度随当根 bar 走完比例变化
- `实盘信号`：🔺喊多 / 🔻喊空 / 观望；`信心 多x%/无y%/空z%` 是三分类概率；`上轨/下轨` 是 θ 通道边界（摸轨参考，不是死命令）
- `手册判定`：作战手册 v2 规则（`src/obson/playbook.py` 唯一权威）对该信号的裁决与理由

**信号 bar 口径（2026-09-11 修复，老师审查 #1）**：模型输入的最后一根 bar = 展示的信号 bar = 最近一根**已收盘** bar。
修复前：模型输入截止到倒数第二根 bar，而展示的现价/时间/θ 用的是正在进行中的末根 bar（错位一根）。
现在脚本会打印 `数据截至 / 当前时刻 / bar时长`，末根未收盘时会标注"（末根bar仍在走，已剔除）"。
θ_q 等口径参数从 ckpt 自动恢复，命令行传了不一致的值会直接报错（防止口径漂移）。

## 6. 作战手册（实盘纪律）

**v2 白名单（2026-09-11 起生效；依据 = 置信度分桶 EV 表 + 路径回测，旧手册规则已被证伪/降级）**：

| 出手条件 | 动作 | 依据 |
|---|---|---|
| p_60m 喊多，信心 0.35~0.50 | 开多 | 摸轨率 22.9%，E[收盘]+0.295%（甜区 0.40~0.45，n=48） |
| p_60m 喊空，信心 ≥0.50 | 开空（轻仓） | 摸轨率 21.4%，+0.084%（n=14，勉强成立，中间档全负） |
| sr_60m 喊多，信心 0.40~0.50 | 开多 | 摸轨率 26~29%，+0.07~0.17% |
| **m_60m 喊空，信心 0.40~0.50**（9/11 转正） | 开空 | **测试集一次性独立评估**：n=78，摸轨率 15.4%（基准 4.6%，3.3x），E=+0.106% |
| **m_30m 喊空，信心 0.40~0.45**（9/11 转正） | 开空 | **测试集一次性独立评估**：n=45，摸轨率 13.3%（基准 3.0%，4.4x），E=+0.183% |
| 持仓 p 空单中，下一根"无"概率再涨 ≥15pt | 持有/可加仓 | 轨迹桶：摸轨率 35.7%，+0.404% |
| 其他一切（含 rb、y 及手册外品种） | 观望 | rb/y 无任何信心桶单调性；y_30m 空、sr_60m 多在路径回测中为负 |

> m 的两条规则是手册首次走完整"验证集选出 → 候选区冻结 → 测试集一次性评估 → 转正"流程的规则，
> 无前表规则的选择偏差问题。流程实现：`playbook.py CANDIDATE_RULES` + `confidence_ev_table.py` 候选评估段。

**旧手册作废项**：p_30m 仅空（路径回测 argmax −16.6%/auto −8.5%）、y_30m 仅空（auto −7.2%~−7.6%）、
m_60m 仅空（样本个位数，不构成证据）。黑名单 i_30m、j_30m、MA_30m、ag_30m 维持。

**通则**：夜盘信号强于日盘；不是信心越高越好——p_60m 多 ≥0.50 档收益回落，0.4x 的"有把握但不过度"是甜区；
高信心桶样本少（8~48 笔），白名单带乐观偏差（验证集参与阈值标定），执行时仓位打折；
信号稀疏是特性不是缺陷，不喊=不动。

**v1 vs v2（2026-09-11 统一后）**：
- **v1（`--playbook`）**：只过滤品种×方向（如 p_60m 双向、y_30m 仅空），不看置信度。是早期粗筛，保留仅用于对照实验。
- **v2（`--playbook-v2`）**：品种×周期×方向×**置信度区间**（上表白名单），由 `playbook.py` 的 `signal_mask()/decide()` 实现，是生产唯一口径；`backtest_signals.py`、`backtest_playbook.py`、`signal_live.py` 三个脚本都已接入，v2 优先于 v1。
- 实盘以 `signal_live` 输出的"手册判定"一行（v2）为准；回测复现一律加 `--playbook-v2`。

**方法学声明（2026-09-11 老师审查后冻结）**：
- 上表 v2 白名单**是由 val+test 合并的 EV 表选出的（选择偏差）**，自 `playbook.py` 落地起规则冻结；
  此后重跑 `confidence_ev_table.py` 会在测试集上单独出 `confidence_ev_frozen_test.csv`，
