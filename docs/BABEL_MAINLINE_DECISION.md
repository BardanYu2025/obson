## 1. 我们到底在解决什么

阶段终点补充（2026-09-25）：用户明确不希望无限追逐无损重建。[退出标准与工作顺序](BABEL_RECONSTRUCTION_EXIT.md)将“冻结表示能保留预先声明的用途”作为重建阶段的实用终点；不是只比较各重建模型的排名。允许当前768进入用途验证，先判断已知失真的实际影响，再决定是否值得做低频解码改动。尚无新的用途验收结果，也没有更改已有门槛。

目标是：在每根bar收盘时，把截至这一刻可观察的价格形态和交易活动压缩成可复用状态。历史回读检查信息有没有保留；不同用途的冻结读出检查信息是否容易使用。未来预测是后续独立问题。

“能压缩”“能读出某几个量”“值得使用神经模型”是三个不同结论。可视化好看、规则标签读出准确、接口运行正确，都不能单独证明最后一个结论。

## 2. 已经得到的实质收益

- 同一历史重建协议下，attention候选相对GRU综合误差降低约26.5%，见[架构复核](BABEL_ARCHITECTURE_REVIEW.md)。它是该预算和候选集合内的结果，不是全局架构最优证明。
- 保持固定PCA解码架构和200轮更新预算，改变训练窗口采样后，综合误差在原品种/跨品种研究集下降39.86%/29.01%，两种子都有支持。这是明确的模型质量进展，见[采样复核](BABEL_WINDOW_SAMPLING_REVIEW.md)。不能把收益全归因于唯一bar覆盖或窗口位置中的某一项。
- 已交付的512维状态能回读较完整的价格轮廓，也能线性读出历史方向。16/64根方向三分类的平衡准确率约86%–88%。这是对截至当前历史的描述，不是下一根涨跌准确率，见[状态读出复核](BABEL_WINDOW_STATE_PROBE_REVIEW.md)。
- 滚动窗口、因果特征、合约边界和恢复接口已有实测一致性证据，见[交付复核](BABEL_WINDOW_STATE_REVIEW.md)。它解决可调用性，不增加表示能力。

因此不能说这些训练没有成果。但最近几轮主要是诊断与交付，没有产生新的主模型突破。

## 3. 当前方案是什么，又缺什么

实际路径是：单合约持续计算的28维因果特征 → 滚动128根 → 因果Transformer → 末端512维坐标 → 固定PCA逆变换 → 历史重建。最新窗口基线不是之前所有长短状态分支的叠加，也不是无限历史记忆模型。

固定PCA解码器只输出其512维仿射子空间内的结果。编码器是非线性的，但输出空间受限。普通PCA坐标是这个空间中对给定目标进行**不加权欧氏重建**的最优坐标；当前主指标却有缺失掩码、多尺度变化和不同分项权重，因此不能把PCA分数说成当前主指标不可突破的理论下界。学生已有部分价格指标超过PCA。

这也不是“只要换成非线性解码器就解决”的证据：原生512学习式解码器、残差解码和教师日程已经做过对照，未取得稳定全面收益。见[容量复核](BABEL_NATIVE_CAPACITY_REVIEW.md)、[教师复核](BABEL_PCA_TEACHER_REVIEW.md)、[退火复核](BABEL_PCA_ANNEAL_REVIEW.md)。

还有一个目标边界必须明确：输入包含当前已收盘bar，但历史重建主损失排除了当前bar。原意是避免当前输入复制，结果是“当前bar本身被充分保留”未被该损失直接监督。滚动128根输出解决了端点定义一致性，不能由此宣称已得到每个时刻完整、可变长度的历史压缩。未来修改训练目标时必须显式处理这一边界，不能悄悄改mask后沿用旧分数。

## 4. 简单方案的比较，究竟告诉了我们什么

下面均为已有研究集结果，神经模型数值是两种子指标均值，不是集成。当前交付模型的重建来自[交付报告](BABEL_WINDOW_STATE_REVIEW.md)，目标PCA参考来自[采样报告](BABEL_WINDOW_SAMPLING_REVIEW.md)，目标定义及研究端点相同。

| 重建指标，越低越好 | 当前512状态：原品种 / 跨品种 | 目标历史PCA512：原品种 / 跨品种 |
|---|---:|---:|
| 综合标准化误差 | 0.14018 / 0.08738 | 0.04067 / 0.01672 |
| 收盘路径MAE，近似bp | 17.87 / 11.51 | 18.59 / 13.80 |

含义是：价格轮廓已可用作研究原型，但整体历史保真仍有明显缺口，尤其实体和交易活动。不能写成神经模型全部落后，也不能用收盘路径一项取代完整目标。综合误差比值不是“丢失信息的倍数”。

必须区分两种PCA：

1. **目标历史PCA**压缩从已观察历史构造的七通道回读目标，是历史压缩的实际参考。它在窗口端点不使用未来，但采用不同的解析预处理，不等于与神经编码器拥有相同优化过程。
2. **输入PCA**压缩同一128×28输入，用于最近六个状态量的统一Ridge读出。它与目标历史PCA是不同任务，分数不能混用。

最近输入PCA对照中，神经表示的六目标综合读出误差均值更低，但两个种子、两个研究集的完整预声明条件未通过，方向任务族还落后于未压缩输入。故结论是**有局部增量证据，尚无稳定全面优势**。线性读出失败不能证明信息不存在；直接计算历史规则也不需要先训练神经模型。

## 5. 本阶段决定

### 768候选不能从阶段结论中省略

512是沿用原保留门槛的交付基线，不是所有指标上的最优模型。已完成同200轮预算的768_joint，在两种子best均值上，全局综合误差为0.104560/0.062616，相对512_endpoint的0.140181/0.087380改善25.41%/28.34%；采用同样全局解码后裁取近期的读取方式，近期综合误差为0.271646/0.183149，对应512的0.344625/0.230524。见[逐bar对齐复核](BABEL_BAR_ALIGNMENT_REVIEW.md)和[末端读取复核](BABEL_ENDPOINT_READOUT_REVIEW.md)。768有明确的综合与近期重建优势，不能用“未晋升”抹掉这些收益。

未替换的原因是原全局路径保留条件：768_joint种子43的best路径MSE在两个研究集分别增加13.91%/15.35%，超过预声明10%边界；其他部分检查属于区间无法确认非劣，并非全部已经证实退化。这是工程取舍，不证明512总体更优。768同时改变宽度、PCA rank，joint还改变监督方式，全部收益不能归因于维数。最近方向/波动读出和接口交付只验证了512，不是新的512胜过768证据。

后续若有合格新时间段，须同时冻结保留512_endpoint与768_joint两种子作重建确认，不能只测512而遗忘更强候选；仅有512完成的用途读出不得冒称已覆盖768。增加768用途读出需另行事前固定协议，不能在新数据上调参。原晋升失败结论不作事后更改。

保留512_endpoint两种子及其冻结接口作为研究基线；不晋升为通用bar表示，不宣布主线成功，也不否定整个表示学习方向。当前证据足够结束这批窗口重建、容量与读出诊断，不必追加实验才能做此判断。

停止把下列工作默认排为下一轮：增加维度/层数/EMA，继续搜教师权重或残差组合，为通过失败门槛而扩读出网格，以及用展示页面代替研究进展。现有模型未被证明充分收敛；停止的理由是证据与研究收益不足以支持继续无边界投入，而不是声称继续训练不可能改善。

下一优先事项是**冻结现有结果，在来源可核实的新时间段作一次确认**，而非再在旧研究集挑配置。它只回答现有进展能否保持，不能凭此制造“新架构突破”。实施前需锁定：

- 两种子原权重、归一化、PCA、读出参数和已有评分定义；不得用新时间段重新拟合或选择。若旧读出参数未保存，须先在旧来源恢复并核验，再接触新评分。
- 核实新数据未参与训练、验证和此前研究决策，按合约/周期处理；预热只能读取当时已存在的历史，既有输入与目标的重叠边界需明确记录。
- 一次并列报告历史回读与原六目标读出，保留目标PCA、输入PCA、完整输入和当前特征在各自任务中的位置；新时间段不是另一个“cross_research”名称。
- 沿用已冻结判据，逐种子报告价量分项、总体与有足够样本的分组及配对不确定性。仅平均值变好或部分指标通过，不改写成全面突破。

目前未核实存在合格新时间段，未实现或运行这次确认，因此不提供可直接开跑的命令、不宣称具备新留出。没有新数据时保持现有结论，不用继续复用旧测试集替代确认。

若确认失败，停止对当前配方的扩大投入；若确认保留有限收益，也只按有限用途保留。任何新的预训练方案都必须另立一个可证伪的问题，说明相对已做实验的新信息，并重新对齐“当前bar + 多尺度历史”的保留目标。不能把历史重建任务悄悄换成规则分类，更不能先承诺模型升级再寻找支持指标。
