# 冻结768重叠窗口诊断

2026-09-25。承接[用途验收](BABEL_UTILITY768_REVIEW.md)，检验用户提出的问题：同一历史片段换到另一个窗口位置后，现有单向量能否稳定地回读它。**不训练、不拟合新头、不改已有权重或模型绑定源码。** 本次不是用途验收重跑，也不重开path输入支线。

## 问题与边界

主要候选control种子42/43固定使用path768来源已选best（总300/298轮），回读只经过窗口末端768向量与既有固定PCA decoder；没有其他bar向量或真实价格跳接。四来源权重身份依旧完整校验，实际仅推理两份主要候选。原验证与最终权重因果检查先行。

同一单合约内，B为原研究128窗口，A为比B提前d根结束的128窗口，d固定为1/16/64。B拥有A之后已经发生的d根行情，双方重叠部分均属于历史；不能将B的输出当成A结束时可获得的实时结果。本诊断不测预测未来。

窗口移动同时改变上下文和相对位置；本轮不将差异单独归因于位置编码、注意力或信息丢失。完整向量可描述不同历史，不能要求它们一致。只报告末端状态的cosine/RMS变化，不设随时间单调增大的距离目标，也不把向量相减视为区间编码。用户提出的两端状态联合解码尚未实现。

## 数据与固定队列

复用已锁定的原始28维连续特征bank与sequence索引，无需补行情或重算EMA。原品种bank来自activity_alignment100，其x文件可能软链接到activity512；用解析后的实际路径匹配原architecture manifest指纹。跨品种bank与index保持原来源校验，不按目录名猜文件身份。

先按旧索引重新生成所有984/453个原研究输入、目标和mask，逐数组对照现有缓存，再产生位移。每对保持同合约、同packed分区，至少128根完整输入，提前端点全局行号≥511以维持已有512根原始预热要求。提前端点不必满足原主力端点筛选，报告限于所选同合约历史，不宣称新的主力策略。

所有位移用共同可用队列，完整保留排除名单与原因。已用用户真实sequence/coverage报告验证计划：原品种984对、跨品种443对；跨品种10个原端点因前移后分区/512预热边界不足排除。这里仅检查真实元数据，没有本地神经推理。正式运行仍需核验银行文件并回放原缓存。

每个输入窗口末端bar都不在旧重建监督内，所以共同评分位置严格为A[d:127]与B[:127-d]，分别126/111/63根。输入交集中的A当前bar不纳入评分。mask必须逐位置相同，缺失活动字段不当零值评分。周区间使用原coverage的交易日所属周，避免上轮自然周/夜盘错误。选原端点和同一队列，不按误差挑样本；展示样例固定均匀6个索引。

## 锁定评分，不掩盖偏移

- **原锚点路径误差**：分别对A/B自己的原目标计算共同部分MAE与有符号平均偏移，单位log-percent×100（近似bp）。这一项保留整体位置错误。
- **共同段形状**：A/B分别减去自己第一个共同位置的预测收盘值，真值也各自相对同一位置；计算两预测的形状RMS差异，以及各自对真实形状的RMS误差。只移除一个常数，不按真值修正预测、不拟合斜率或振幅。它不代表原锚点路径已经正确，须与上一项并列。
- **逐根变化**：共同段相邻差分，用原训练delta_scale[0]标准化；报告两预测差异及各自真实MSE。
- **实体/活动**：使用原训练y_scale，在共同可用字段上报告差异及真实MSE。活动先对每通道有效bar平均，再对有支持通道等权；全部缺失时标为无支持，均值为null，不填0纳入统计。
- **同窗口数值对照**：8个固定B窗口分别按主batch与batch1提取；记录状态/预测差异，按既有FP32 atol5e-5、rtol2e-4检查（预测在原标准化单位）。不合格时保存数值失败并停，不把数值漂移混作上下文差异。
- **真值几何对照**：把两份真值代入相同对齐流程，重叠差异应只剩缓存浮点舍入，用于排除索引/锚点实现错误，不充当学习式竞争基线。

每项报告总体、品种、周期的均值、中位、p90、p99、最大值，以及逐对分数/有效性。A与B真实误差做配对B−A周bootstrap区间，至少50对/5周才标supported，未经多重比较校正。不同位移共有片段长度不同，不把它们的原始误差大小直接解释成随位移退化的因果证据。

## 预声明判读与停止规则

这是诊断，不设人为“相似度大于多少就成功”的阈值，也不从表格自动触发训练。判读同时看：差异相对同窗口数值参考是否实质明显；A/B各自误差和尾部是否较大；是否两种子、两个研究集均有相同现象；差异属于整体位置还是区间变化/实体活动。两预测一致但共同出错不算成功，B更准也不能据此要求A实时利用B才看到的后续信息。

若稳定性没有明显缺口，关闭这个假设；若确有缺口，再制定同预算原训练/加入一致性的单变量实验。冻结回读失败仍不能证明向量内部完全没有信息。当前用途完整验收失败、有限能力保留和研究集复用边界都不变。本次不拟合规则、不再加100轮。
