# 共同历史下一步：先使“读取哪段内容”可检验

2026-09-30。设计审查和可执行合成反例；不是新一轮GPU训练协议。已有Shared History768的失败结论、选模、门槛和绑定源码不变。

## 审查结论

当前自由64维辅助内容，缺少对“究竟读了哪段历史”的识别约束。原实验确实改善了定义的一致性距离，但这种距离、方差和有效秩的组合不能单独识别区间语义。之前的正式协议保留了原状态用途与信息保护，所以最终没有误晋升；这不代表辅助任务的构造已经充分。

下一核心候选优先采用**与真实区间内容绑定的辅助表示，先固定编码器验证读取语义，再有限联合适配**。先解决目标含义，不能将降低权重、增加头数、随机头预热或梯度投影单独当作修复。此处确定设计方向与必须通过的检查，尚未锁定真实数据目标尺度、预算和训练入口，不提供开跑命令。

## 现有模块的确切能力边界

记状态内容变换为 `u(z)=GELU(Wz+b)`，查询区间集合为Q，门控为`g(q)`。现有模块严格等价于：

```
r(z,Q) = Wout [ u(z) × mean(g(q), q∈Q) ]
```

因输出投影是线性的，“每区间投影后平均”可移动为“先平均门控再投影”。它是查询条件下对同一个内容向量重加权；不能仅凭模块名称就断言它已经定位并抽出了Q中的历史。该结构仍可能学到区间依赖，公式不证明它必然无效或不能学习。集合无序聚合本来就是上一协议的定义，不是意外排列错误。

特别地，门控网络参数全为0时sigmoid恒为0.5，模块完全不再依赖查询。原防塌缩约束不能排除这一情形，因为输出仍然可以随样本变化。

## 可复现反例，不使用真实模型

新增`shared_history_identifiability.py`使用现有模块与评分函数，构造128个768维状态。三个视图共享一个任意编码，每个同合约／几何时间对取相反编码；它不含K线或目标历史。利用64阶正交符号矩阵构造各维变化，设置固定内容／输出权重和常数门控，不进行拟合或优化器更新。

实测合成反例：

| 检查 | 结果 |
|---|---:|
| 同周期与跨周期辅助总loss | 约4.77×10⁻³⁵ |
| 正确配对／交换距离比 | 0 |
| 配对去均值标准差 | 1 |
| 有效秩 | 64 |
| 将查询整体移8根，输出最大变化 | 0 |

因此完全不识别“回看哪段”的模块，可以同时满足零一致性误差、方差和协方差要求，以及辅助非塌缩／配对区分的绝对下限。此反例**不声称通过真实实验的全部相对增益、原状态用途和信息保留判据**；它也不证明真实训练模型使用了同样捷径，更不能被当作本轮失败的唯一根因。它明确证明了辅助指标本身的证据边界。

同一个状态下比较不同真实区间是缺失的检查。只有问不同内容、目标也确实不同，且输出能匹配各自内容，才排除了完全忽略查询这一反例。不能强行要求所有不同区间输出不同：两段行情内容可能相似。

## 梯度保护也不能只看一个夹角

原实验分别裁剪编码器和辅助头，但编码器内部仍接收重建与辅助梯度之和；分组裁剪不保证各任务不受损。上一报告只有合计范数，没有分离一致性、方差、协方差梯度，因而无法断言是哪一项主导退化。

[PCGrad](https://arxiv.org/abs/2001.06782)提供处理冲突任务梯度的参考；[GEM](https://arxiv.org/abs/1706.08840)提供以记忆任务约束更新的参考。它们不是本实验已验证的解决方案。原VICReg的方差／去相关机制用于避免常数输出等塌缩，不提供本项目“指定区间语义”的保证。[VICReg原论文](https://arxiv.org/abs/2105.04906)

另附精确线性例子：主梯度(1,1)，辅助梯度(4,−2)，欧氏点积为2；正对角预条件(0.1,10)下，辅助方向与主梯度的点积却为−19.8。单位步长时，单主梯度使线性主损失变化−10.1，组合更新使其变化+9.5。这只是预条件方向的代数反例，不是Adam轨迹模拟或否定PCGrad原论文。在Adam动量、预条件、裁剪与有限步长存在时，不能把“原始梯度点积非负”宣称为原能力不退化的保证。

后续若研究保护更新，至少记录按价格、活动、远程结构分解的编码器梯度、各辅助分量、夹角、裁剪和实际参数位移；采用独立训练保护批检查实际更新影响。验证集只做选模／事先约定的停止，不用于逐batch投影或线搜索；已有研究集不参与控制。有限训练批保护仍不是分布外能力保证。

## 推荐的下一核心设计

维持原768维／4层／8头状态与价量联合重建。新辅助接口为：

```
单个状态z + 明确的共同区间Q → 内容表示r
内容表示r → 该区间的实际历史内容
```

第二个读取头只能接收r；不能再旁路输入z、原bars、目标值、查询位置或目标缺失mask。如果r忽略Q，就无法为同一个z内实际内容不同的Q1/Q2同时恢复各自目标。目标来自已经发生、经原始对齐核验的物理区间；是行情内容自监督，不是上涨／下跌规则标签，也不使用未来。

首选绑定内容为共同区间的价格变化序列及可核验的成交／持仓变化，沿用真实链接、合约边界和缺失处理。具体维数、价格锚点、活动尺度、离散槽位与损失权重须在实现时核验，不能直接假定粗周期活动归一化等于细周期特征相加。先用实际合成／原始链接检查标签等价性，所有统计只由训练数据确定。

训练流程的关键不是单纯多训一个头，而是先让“内容表示→实际目标”的绑定成立：

1. 编码器固定，辅助读取／内容解码在训练数据上适配。用固定验证方案检查内容误差及同状态错区间对照；包含仅查询、忽略查询的状态读取对照。完全忽略Q的本次反例必须被判失败。达不到前置要求就停止，不能进入联合训练后期待编码器替随机任务收拾问题。
2. 通过后，各分支共享同一个辅助起点及同样原模型起点。三组分别为原重建继续、仅内容绑定梯度进入编码器、内容绑定再加共同内容对齐。辅助模块在各组都受相同内容监督，梯度路由明确，区分额外重建监督与对齐本身的收益。
3. 保留原768状态评价、同期普通续训对照及起点保护，报告全部best与last。辅助损失小或读取更一致不单独晋升。若内容绑定本身已造成不可接受退化，结束本方案，不自动追加对齐权重搜索。

这和已做实验的区别必须保留：旧解码一致性比较恢复出来的曲线；本设计先检验受限内容表示能否独立恢复Q的内容，再考察该表示的一致性。当前control已经训练过自由辅助头，简单再冻结编码器训同一头不是新实验。原history-query也做过查询头预热，预热本身不是创新；新增的证据要求是同状态不同区间的内容绑定、无解码旁路及对应反例检查。

这是比继续自由相似度更可证伪的候选，不是成功保证。内容监督可能重复原重建能力、低维瓶颈可能损失信息、额外任务仍可能冲突。正式训练预算、读取质量门槛、同预算对照和资源测算必须先落地；本次不拿不完整设计消耗一次AutoDL长训练。
