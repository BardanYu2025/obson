# 冻结两层/四层编码器，同预算适配共享局部头

2026-09-25，用户批准。上轮四层综合重建与共同历史稳定性有明确收益，但seed42原品种中途局部回读增加6.61%。本轮只检验冻结状态中的局部历史能否被同规格读出恢复，不继续扩层数、头数或历史用途读出网格。

## 固定设计

使用growth768的base/deep各两个种子，固定原验证选定的best编码器及全局解码器。新局部头仍768→256→16×7，GELU，225648参数；同种子的base/deep随机初始化权重完全相同，原配套局部头作为冻结参照，不能参与新头选模。四组均独立拟合训练集状态归一化，统计只取训练窗口非留出位置；目标归一化及缺失掩码精确沿用原协议。固定仿射归一化不增加神经参数或状态容量。

只训练局部头，不更新编码器、全局解码器或原方向/波动读出。训练局部past16历史SmoothL1，不含当前bar；四组AdamW学习率峰值1e-3、5轮预热、余弦降至0.1峰值，weight decay1e-4，梯度裁剪1，无学习率/头宽网格。

固定原4789训练窗口、978验证窗口。这与上轮编码器续训使用36106资格池和双视图抽样不同，属于冻结读出诊断，不声称与上轮编码器训练预算等价。四组之间严格同预算：每轮所有4789训练窗口各一次、每窗四个不同的训练前缀，100轮、batch128窗口、3800次局部头更新、1,915,600个局部目标曝光。原32～128位置中排除48/80/112，后者从不参与训练、输入统计或选模。验证只用32/64/96/128，按局部MSE选best，允许epoch0回退。

为减少重复计算，冻结编码器一次性缓存94个训练位置及四个验证位置；训练阶段没有编码器实例或优化器。训练前检查原验证与因果性，每个缓存批次把末端状态和上轮已绑定缓存回放比较。约6GB新状态/目标缓存，建议保留至少10GB磁盘空间。默认同时训练两个小头，显存利用率低、每轮快是预期行为，不代表没有执行训练。

## 评价及结论边界

四组全部完成并锁定best/last后才提取研究集。原984/453研究窗口不变。每组分别评价原局部头、新best头、新last头，回放原局部评分；报告每个32/48/64/80/96/112/128位置，以及训练位置/留出位置汇总、逐窗口误差和固定例子。

预定恢复判据：两个种子、两个研究集、新best及last都满足。deep相对同预算base新头、原deep头、原base头：留出位置综合误差及训练位置综合误差最多增加5%；留出位置path/body/activity分别最多增加10%。使用原交易周配对1000次bootstrap、seed42、至少50窗口/5周，置信上界≤0；未多重校正。不按平均通过率晋升，不事后选择较好的best或last。

通过仅记`local_readout_retention_recovered`，说明这组冻结表示在该共享头容量/预算下可以恢复局部保留；失败记`local_readout_retention_unresolved`，不能证明embedding绝对没有信息。初始/末段验证、原头和两种子必须一并审视，不能以随机新头尚未适应误判信息损失。

原全局重建/重叠/方向波动读出均冻结，通过文件身份、状态回放和原证书绑定确认保留；不是重复拟合或宣称这些指标有新改善。原growth768的`no_capacity_upgrade`及原完整用途失败结论不改；本轮通过也不自动成为完整升级。一次100轮固定诊断，不自动扩网格或延长预算。
