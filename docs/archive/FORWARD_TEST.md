# 前向实盘记录规程（P0：候选冠军 v1.1 转正考核）

## 目的

回测成绩（+10.06% / 成本加倍 +7.24%）已经是过去式。v1.1 能不能转正，
只看一件事：**前向实盘是否复现正期望**。本规程规定每晚记什么、怎么判。

## 每晚流程（约 5 分钟）

1. **21:00 前后** 在 AutoDL 跑 `./night_signal_autodl.sh`
   （补数据 → 补外盘 → 出信号）。
2. 把每条信号抄进 `live/forward_log.csv`，一行一条。字段：

   | 字段 | 含义 | 来源 |
   |---|---|---|
   | date / signal_time | 信号日期与时刻 | 脚本输出 |
   | symbol / period / contract | 品种 / 周期 / 合约号 | 脚本输出 |
   | direction | long / short | 脚本输出 |
   | p_up / p_down / p_none | 三类概率（0~1） | 脚本输出 |
   | path_state | 路径头状态（若打印） | 脚本输出，可空 |
   | theta | 当时动态轨道宽度 % | 脚本输出 |
   | foreign_freshness | 外盘数据最新日期（如 20260913） | 脚本输出 |
   | acted | 是否真开仓：yes / no | 你填 |
   | entry_price / exit_price | 实际成交价 | 你填（没开仓留空） |
   | exit_reason | tp80 / stop50 / close / opposite_signal / manual | 你填 |
   | slippage_ticks | 滑点（跳数） | 你填 |
   | pnl_pct | 这笔盈亏 %（含手续费） | 平仓后补 |
   | notes | 异常情况（跳空、流动性、心态） | 你填 |

3. **没信号也要记一行**（direction 填 none，acted=no），
   否则事后无法区分"模型没喊"和"忘了记"。

## 判决规则（预先承诺，2~4 周后执行）

攒够 **≥30 笔实际成交** 或 **满 4 周（2026-10-12）**，取先到者：

- ✅ **转正**：单笔期望 > 0 且最大回撤 < 5%，且与回测口径同向
- 🔶 **延长观察**：期望在 0 附近（±0.02%）或样本不足
- ❌ **降级**：期望 < -0.02% 或回撤 > 5% → 回到实验流程，v1.1 摘冠

辅助观察（不做判决，用于诊断）：

- 信号频率是否漂移（回测 ~58 笔/测试期 ≈ 每周 3~4 笔）
- p_up/p_down 的分布是否和验证集一致
- 外盘数据迟到/缺失的晚上，信号质量是否明显变差

## 纪律

- 记录先于记忆：**当晚记，不补记**。漏记的晚上在 notes 写"漏记"。
- 不用前向结果反过来调模型——那是新一轮过拟合。调参只认验证集 + 测试集。
- 每周日把 CSV 发我，我做一次周度对照（信号命中率 vs 回测基准）。
