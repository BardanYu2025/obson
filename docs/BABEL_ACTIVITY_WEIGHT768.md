# Activity Weight768：固定输入的历史活动监督权重对照

2026-09-29。研究主线仍是能复用的因果bar表示。Depth768已证明重建继续改善，但尚未共同通过完整用途协议。此轮回答：减少历史成交／持仓活动的重建监督，能否让同一状态更好保留价格结构并改善用途；同时量化活动信息的代价。不是删除活动输入、证明活动无用或追求无损重建。

## 固定六组与停止条件

|---|---:|---|---:|
| a000 | 0 | 42、43 | 100 |

从完成的`babel_depth768`模型选择锁中读取每种子`d4_c12`的best。当前来源为`d4_lr3_s42/e281_best.pt`与`d4_lr3_s43/e281_best.pt`，验证选中279/281轮；程序复算源验证选模及LR选择、核对报告与权重指纹，不根据研究集选起点。每个种子的三组起点逐张量相同，固定768维、4层、8头、FFN3072、28个输入通道和因果路径输入包装。原相对历史查询头保持4个192维内部槽位、两层4头交叉注意力；没有新增编码分支或解码器。

共享来源已经受过活动监督，两个种子不是独立预训练复现。因此只能判断本阶段续训的权重取舍，不能据此证明从零训练不需要活动。全部六组100轮结束即收束；无自动续训、自动调权或扩网格。没有稳定用途增益就保留原研究参照，不因为训练曲线下降而再开一轮相同矩阵。

## 数据与训练

沿用已锁定合约、训练／验证／原品种研究／跨品种研究划分、因果特征和训练集统计，不补数据、不改标准化或交易日边界。每轮4789组三视图、14367视图、38次更新；有效batch128组。三组同种子采样、前缀、优化步数和LR完全相同，新采样从旧深度实验末轮之后的stream782开始。每视图四个随机可见前缀加128末端；48/80/112不作训练查询位置，仍留作研究位置。

各组重置Adam和RNG，编码器峰值3e-5、查询头3e-4、局部诊断头3e-5，100轮内同样5轮warmup及cosine。主目标为：

```
0.4 × 收盘路径 + 0.2 × 单步变化 + 0.1 × 实体
+ w × 历史活动 + 1.0 × 远处粗价格结构
+ 0.25 × 断开编码器梯度的局部诊断
```

活动仍是原查询目标的第2..6通道，使用原缺失mask和分项尺度；影线没有变成强重建目标。粗结构仍按4/16根分组监督17根以前的价格位置／变化。局部诊断头仍可重建活动，但其输入状态detach，不影响编码器或主查询头。旧PCA解码器冻结；当前bar保留检查仍单独评价。权重0仍输入成交／持仓等全部通道，也仍输出并评分历史活动。

0.3组保持旧structure目标的数值和梯度算术；另两组仅改该活动系数，不重新归一化其他系数。因而总梯度幅度和裁剪也可能变化，不能将差异单独归因于语义竞争。逐轮记录各损失分项、三个参数组裁剪前范数和裁剪比例；起点与末轮用同一小批训练样本测量编码器价格＋结构梯度、原始／加权活动梯度及夹角。该诊断无优化更新、不用于选模／调权，不能代表全部训练分布。

## 统一选模，防止总loss造成不公平

三组采用相同、与w无关的验证评分。共同价格查询分数为`(.4 path + .2 change1 + .1 body) / .7`；近期为64/128相同末端、相同过去16根目标的收盘路径误差，远处为65..127距离的粗价格结构误差。价格查询／近期／远处相对第0轮最多退化5%，同末端路径差异最多10%；合格候选按近期／远处相对误差的较差者、均值、较早轮次排序。第0轮可回退。

本轮近期选模采用path而非旧的价格与活动混合primary，这是三组共同的预声明协议改变；不会将本轮分数直接冒充旧深度选模分数。活动验证误差持续报告，但不按它挑模型；不对不同w的训练总loss排优劣。48/80/112、研究集、用途拟合均不参与每轮选模。

六组best和last全部锁定后，12份状态用相同训练／验证集拟合13个用途目标、每目标原五档正则，共780候选。编码器冻结，仅验证集选择读出正则。原raw3584／PCA768／current28基线和起点读出均固定并回放。

## 正式评价和归因边界

a000、a010分别与同种子a030比较，并对起点作保留检查。两个既有研究集合、两个种子、best和last全部报告，不挑有利子组。正式736项配对检查分开记录：

- 用途增益：综合用途相对同预算a030至少改善5%。
- 价格增益：同末端80/128近期收盘路径至少改善5%，单独命名，不代表通用表示提升。
- 保留：相对对照及起点的用途、方向／波动、近期价格、远处结构、留出／末端查询分项；相对对照的共同历史差异，以及当前七字段绝对保留。
- 活动保留：留出位置和128末端的历史活动误差，相对对照及起点最多退化10%，独立报告。

用途与价格路线分别判断；只有用途增益、保留和活动保留在全部种子／集合／best+last共同满足，才标为`balanced_utility_candidate`，仍不自动晋升。用途增益伴随活动损失明确标为取舍；只改善价格就只记录价格收益。完整raw/PCA/current用途协议另外输出，不能因相对对照改善便声称绝对可用。保留边界详见manifest和逐项decision，不以通过比例放宽门槛。

这些集合已经反复用于研究，周级配对区间未做多重比较校正，不能冒充新的独立确认。源码和数据哈希、预算／梯度检查、研究用途分别是工程可靠性、训练对照和表示证据，三者不互相替代。
