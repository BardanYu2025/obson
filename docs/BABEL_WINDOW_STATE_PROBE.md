# 冻结窗口表示的当前行情状态读出

## 研究目的与固定范围

检验已交付512维状态能否通过一个轻量线性读出，保留当前行情的方向、趋势强弱和波动信息。只读 `babel_window_state` 两个已验证种子，原best第196/199轮不变。编码器更新为0，旧源码和模型包不改，不训练主模型拟合规则，不添加MLP或重开架构矩阵。

这是一项信息可读性诊断：历史公式提供可复算的参照，不是唯一正确的“市场趋势”定义，也不是开仓依据。能读出这些量，不等于证明市场机制、预测能力或所有用途上的通用表示。

## 六个目标

分别取截至当前已收盘bar的最近16、64个收盘，使用窗口内15、63个相邻收盘log收益。原28通道第0/1维的反双曲正弦还原gap/body log百分比，相加得到close变化；不使用波动归一化通道代替价格收益，不使用窗口外第一个收益。目标包括当前bar，全部历史可见。

每个尺度三个连续量：

1. **方向效率**：累计收益 / 绝对收益总和，范围[-1,1]；零变动设0。表示在这段历史内向某方向移动的效率。
2. **趋势强度**：log收盘路径对时间做含截距直线拟合的R²，范围[0,1]；常数路径设0。这是线性趋势形态，不代表未来延续概率。
3. **已实现波动**：窗口内收益RMS的自然对数，下限1e-8。RMS包括漂移，按每根bar计，不年化；15/30/60分钟必须分组报告。

方向效率另用固定±0.2阈值派生“下行／混合／上行”三类，只用于解释和分类诊断；不另训分类器、不调阈值、不把“混合”冒称价格绝对横盘。报告混淆矩阵、各类支持数、准确率、仅对实际出现类别计算的balanced accuracy/macro F1。读出结果不裁剪到目标区间，避免掩盖拟合错误。

六个目标按训练集均值/标准差标准化，等权MSE为主指标，每类任务两尺度权重相同。每个目标另报原单位MAE和R²；真值方差不足时R²为null。直接计算目标是参照上限，不拿同一公式当作需要被模型打败的预测器。

## 五个公平对照与一个无信息基线

| 表示 | 输入维度 | 定义 |
|---|---:|---|
| embedding42 | 512 | 原种子42滚动128窗口末端状态 |
| embedding43 | 512 | 原种子43，同一输入、独立报告 |
| pca512 | 512 | 对同一128×28输入仅在训练集拟合PCA |
| raw3584 | 3584 | 完整128×28输入展平，未压缩线性基线 |
| current28 | 28 | 当前bar原28通道，包含已有EMA上下文的简单基线 |
| train_mean | 无 | 恒定输出训练集六目标均值，不选参数 |

输入PCA新拟合的是因果输入矩阵，不是既有目标解码PCA。按训练集每个展平列标准化后做FP64协方差特征分解，保留前512个方向；不接触验证/研究数据。输入信息相同，但PCA无时序非线性，神经表示有已冻结的预训练；不声称训练计算预算相同。

所有可训练读出都为带截距Ridge：对每个目标最小化 `mean_over_samples(squared_error) + alpha * squared_weight_norm`，截距不惩罚，输入/目标缩放只在训练集拟合。相同alpha网格：1、0.1、0.01、0.001、0.0001，各表示用六目标平均验证MSE选一个alpha，精确平局取更强正则。闭式求解没有epoch/早停差异，共25组参数候选；除raw3584/current28维度不同导致参数数不同外，算法与调参机会一致。两种子embedding不择优、不平均。

## 数据隔离与来源

沿用原固定4789训练、978验证、984原品种研究、453跨品种研究窗口，不扩展38549候选训练池，不随机重分割。来自已核验coverage清单，每行与原始缓存一一对应；检查合约/周期身份、512根来源预热、重复行、时间先后及同合约跨时间分区的128根输入不重叠。跨品种研究与训练/验证/原研究集的品种集合必须不相交。

时间分区允许同一合约在不同时间出现，因此不能称为合约完全留出。因果EMA可使用分界线以前的历史，这不是向未来读取。跨品种集虽与训练品种隔离，但已经在先前多轮研究中使用，仍只作为研究集，不宣称新独立泛化证据。

所有表示的alpha选择及PCA、缩放、读出权重指纹锁定后，才允许研究输入提取和评价。程序会复查完整来源、原模型权重、数据hash和源码hash。原编码器保持eval、无梯度，提取前后参数指纹不变。新PCA和线性头允许拟合，报告明确与0次编码器更新区分。

## 评价与停止标准

保留逐窗口六目标真值、各路预测、综合/任务族误差、两种子、分品种/周期/合约指标。候选对PCA、完整输入、当前输入作配对比较；按日历周block bootstrap给区间，分组区间未经多重比较校正，只作诊断，不按结果挑品种路由。

固定的“跨基线增量证据”判据：两个种子、两个研究集均满足六目标R²>0；相对三个基线综合误差改善至少5%，`candidate - 0.95 * reference`的周区间上界<0且至少50窗口/5周；每个任务族误差均不超过相应基线的1.05倍。每项判断均单独输出，任一失败记为 `no_uniform_incremental_evidence`。这是事先声明的探索性工程筛查，不是上线门槛，也不是“失败意味着embedding无信息”。即使通过也不自动晋升模型或生成交易信号。

本轮完成即停止。结果不稳定时保留既有基线、定位哪类信息仍难读，不自动加MLP、调标签、加层或延训。独立新区间确认留到真正未观测的新数据阶段，不把旧研究集改名为新留出。

## AutoDL运行和导出

```bash
cd /root/autodl-tmp/obson
git pull --ff-only origin features/babel
mkdir -p logs /root/autodl-tmp/download
nohup bash scripts/babel_window_state_probe_autodl.sh all \
  > logs/babel_window_state_probe.log 2>&1 &
tail -f logs/babel_window_state_probe.log
```

一次运行完成五路对照；先冻结提取，再一次输入PCA和25组闭式读出，不启动200轮训练。默认提取batch256，可在首次启动前通过 `BABEL_STATE_PROBE_BATCH` 指定；已有目录配置不可更改。正式计算在AutoDL CUDA，FP32提取禁TF32，PCA/Ridge用FP64。GPU有空闲可能处在来源hash、数据读写或小矩阵统计阶段；不需要为了显存占满扩大模型。

同命令可恢复：已完成且指纹匹配的分区缓存复用，锁定的PCA/读出不重拟合；未完成的闭式拟合阶段从头重算。完整完成后再次运行只核验，不重新推理。来源/配置变更或文件篡改会拒绝。
