# 重建阶段的终点：足够保留信息，而非逐点无损

2026-09-25。用户要求明确重建任务何时算成功，避免无限逼近100%还原。本文件区分阶段验收、候选替换和停止投入；不回改任何旧实验判据或失败记录。

## 1. 真正的目标

学习可复用的因果bar状态。历史重建是检查信息保留的工具，不是最终产品目标。允许有损压缩，但必须声明保留哪些信息、哪些误差可以接受，并证明压缩后这些信息仍容易使用。

历史中随机发生的变化已经被观察到，原则上可以编码；不能用“未来不可预测”解释历史重建误差。我们不追求逐点零误差，是因为需要在状态容量、保真、鲁棒性和后续用途之间作取舍。精确复制可能保留噪声，平滑重建也可能抹掉有用细节，两者都不能单凭外观判定优劣。

## 2. 三个不同的判定

| 判定 | 回答的问题 | 当前状态 |
|---|---|---|
| 回读原型成立 | 一个受限向量能否恢复有意义的历史结构？ | 已有真实研究集证据；不是通用信息充分性证明 |
| 重建阶段达到使用要求 | 有损程度是否影响预先声明的用途，困难窗口是否可接受？ | 当前768尚缺同一权重的统一用途验收 |
| 某候选替换既有基线 | 是否满足该实验预声明的改善及保留条件？ | path768完整升级仍失败，不能改写 |

停止优化也可以发生在未达标时：如限定预算内收益不足，则保留有限原型并记录失败。不能把“停止投入”包装成“验收成功”。

## 3. 可执行的验收方向

### 信息通路必须正确

因果性、仅经声明维数的状态进入decoder、归一化与数据分区来源均须核验；训练后检查点需接受因果检查，不能只引用初始化检查。当前滚动128窗口的末端向量可以回读历史，不等于单次前向得到的所有中间向量都具备完整128根上下文，也不等于无限历史状态。

### 保留结构，而非只有一条平滑曲线

沿用已有价格路径、多尺度变化、实体、交易活动评分，分别看总体、品种/周期和困难窗口；同时报告中位、90/99分位与极端错误，不用平均值抵消尾部，也不因最大误差非零就无限追训。整体位置、幅度、转折和局部变化都要纳入解释；不能通过真实历史的均值/终点跳接修正图形。

不现在拍定“价格误差小于若干bp就算赢”：15/30/60分钟、不同品种的价格尺度与用途代价不同。实际可接受误差应在用途协议中由验证集与对照标定，并在打开新的评分结果前锁定。现有研究图仅展示有限固定样例，不能用其观感定全局阈值。

当前主重建监督只覆盖窗口前127根，排除了当前bar；最新bar的信息保留需要单独列出检查，不能借当前损失冒称全覆盖。本轮目标也没有完整监督OHLC上下影线，不能宣称已经成功重建全部K线字段。

### 冻结表示后仍然有用

重建阶段的实用终点应由冻结embedding的预声明用途组合确认。使用同一候选权重、固定任务/尺度/标签和共同训练验证划分，对比同信息的完整输入、同维输入PCA和当前bar特征；读出算法与调参机会匹配。编码器不为这些评价目标重新训练，防止把研究目标变成拟合手工规则。

后续已将“保留接近完整输入的用途性能”落实为[冻结768用途协议](BABEL_UTILITY768.md)：四项方向/波动主要用途综合标准化误差最多比完整输入高5%，并分别检查任务族代价、同维PCA与当前特征的增量及两种子配对区间。当前bar七项保留与趋势形状诊断单列。5%是事前工程容差，并非自然常数，不能在结果返回后反复调整。完整任务、阈值、对照有效性与停止规则已锁定并实现，正式结果仍待AutoDL；旧失败记录不改。

完整输入读出本身若无法完成某项任务，不能用“与一个失效对照相近”证明信息已保留。历史规则读出可以提供信息诊断，但不是市场机制或预测能力证明；规则无法覆盖通用表示的全部要求。

## 4. 收束顺序

1. 价格历史压缩原型已经值得进入冻结用途验证，不需要先把所有重建误差降到零。旧512用途结果不能直接移植给当前768；使用同一权重统一检验，避免连续新增孤立读出。
2. path768输入支线按既定决定结束。尾部偏移作为已知问题保留；在判断其用途影响之前，不默认再开解码器网格或追加100轮。此前提到的低频位置/形态分解是备选假设，不是必须完成的下一训练轮。
3. 如果用途表现达到事前条件且关键失真在声明范围内，即使重建loss还能下降，也结束重建优化，转入下一阶段。若用途明显受损，优先处理对应信息缺口；不能为修某张图而无限训练。
4. 补新数据不阻塞当前研究与用途试验。由于现有研究集被反复查看，最终独立泛化确认仍需留待后续；研究阶段过关不能冒充已完成独立确认。

最初本文件只明确终点与工作顺序。用户随后确认的冻结用途协议已实现；没有修改主模型或重选权重，正式提取和读出拟合仍待AutoDL。
