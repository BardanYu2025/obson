## 训练曲线与解释边界

验证局部综合误差相对epoch0改善4.80%/3.40%，best在最后100轮。最后20轮仅再下降0.258%/0.142%；仍非严格平台期，但增速已小。不能宣称充分收敛，也没有证据支持不加区分地继续100轮就能获得中途位置5%收益。

与前次随机新头相比，本次从原函数出发避免了明显退化，说明原头的已有学习有价值。然而两次使用的编码器版本、初始化及状态处理不同，不能将数值差异单因归为warm-start，更不能把前次随机头结果当作本次同预算对照。

本轮削弱了“仅靠同规格原局部头在这组固定覆盖/预算下继续适配，就能明显解决中途回读”的解释。它没有证明中途状态不存在所需信息，也没有检验其他读出结构、输入覆盖或编码目标。因此不据此宣布编码器已到极限，或直接推导应加层、加头、加指标。

## 主线决定

当前实质进展仍是control600更强的末端历史重建；这次没有新的中途bar回读突破。当前可称为研究用历史状态压缩和回读原型，完整用途门槛未通过，不能称通用bar表示已经完成。

1. 保留control600及其原局部头、已校准用途头为默认研究组合，保留新头作为小幅微调记录；既有512交付基线不自动替换。
2. 结束随机新头与原头warm-start这两种已完成的固定适配配置，不把下一轮默认排成更多epoch或更大头。
3. 跨周期方向继续保留，但本轮局部适配结果不会反过来证明跨周期0.10约束可以接受。
4. 下一次若改模型，应先针对整体历史与中途状态的信息分配提出可检验假设，并说明预期改善哪个缺口；不能用反复换读出替代主线表示学习。当前未实现新的训练入口，本次不要求再跑一轮类似实验。

本轮结论是“局部头安全微调，但未达到有意义的中途增益”，而不是“模型毫无作用”或“训练白做”。完整研究结论、原始失败门槛与用途限制都保留。
