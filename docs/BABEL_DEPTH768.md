# Depth768：固定状态宽度的4／8／12层对照

2026-09-28。研究目的仍是把已观察到的价格与活动压缩为可复用的因果bar状态。历史重建、共同历史回读和冻结用途检查一起判断是否值得保留新编码器；不以无损重建或下一根行情预测为本轮目标。[上一轮汇聚已收束](BABEL_CAUSAL_POOL768_REVIEW.md)，分尺度未确认额外价值。本轮不要求四层先通过所有指标，也不预判深层一定更好。

## 固定矩阵与归因

从已完成`babel_causal_pool768/plain_s42/best.pt`、`plain_s43/best.pt`出发，保留输入28特征、因果路径输入包装及其开关、768维宽度、8头、FFN3072、相对历史查询头和训练划分。实际来源选择必须与源模型锁和完成清单一致；不硬编码98轮以替代核验。不加载已清理的旧实验last。

在原4层末尾追加4或8个prenorm Transformer块。新attention输出投影和FFN第二层置零，所以第0轮继承原函数；Q/K/V、FFN第一层照常初始化，新输出投影先获得梯度，其余参数随后随残差开启而学习。8/12层新增的前4块同初始化，旧层、坐标投影和查询头均可训练。没有pool、降维入口、双状态拼接、真假行情跳接或新位置编码。

| 评价组 | 深度 | 每个学习率试验累计轮数 | 用途 |
|---|---:|---:|---|
| d4 | 4 | 100 | 相同曝光基线 |
| d8 | 8 | 100 | 相同曝光加深 |
| d12 | 12 | 100 | 相同曝光继续加深 |
| d4_c8 | 4 | 191 | 接近8层100轮训练矩阵运算量 |
| d4_c12 | 4 | 281 | 接近12层100轮训练矩阵运算量 |

每个深度和种子都有两档编码器峰值学习率`1e-5/3e-5`，两档均完整训练；不会用短试跑过早淘汰适应慢的深层。查询头峰值`3e-4`、局部诊断头`3e-5`相同。共12个worker试验；四层的100/191/281是同一轨迹的不可变快照，不从头重训三次。每个种子、每个预算只用验证集在两档LR之间选择，tie固定较小LR；best和last来自同一选中试验，不能分别挑LR。共享预训练下两种子不是独立预训练复现。

每轮4789组三视图、14367视图、38次更新，有效batch128组。前100轮所有深度/两LR用同种子的同一采样流；四层续训使用后续新流，不重复前100轮的抽样计划。最终四层10678步/4,037,127视图，8/12层3800步/1,436,700视图。所有优化器在起点统一重置，四层越过100/191时保留Adam与RNG，仅按预先分段计划重新warmup/cosine；每段5轮warmup，末端为峰值0.1倍。相同曝光比较的前100轮调度完全一致。

## “相近计算预算”的精确边界

固定解析矩阵乘法估算包含encoder的线性层、attention矩阵乘积、每视图5个127距离查询、4个局部头，并以3倍近似前向加反向。按4/8/12层的单视图估算向上取整四层轮数，得到191/281；误差小于一轮四层训练量。既列单选中轨迹成本，也保留两LR搜索的全部试验成本。

它不等于精确FLOPs，也不是相同GPU小时：未计softmax/norm/激活、Adam、验证、数据准备及不同CUDA kernel的差异。训练耗时、含数据的训练阶段耗时、显存峰值、参数数和裁剪前梯度范数另行记录。新编码器参数约为2897万／5732万／8567万，状态和查询入口始终是768维，没有通过降维通道制造同宽假象。四层额外训练段及更长验证搜索是明确的优化机会，不冒称只改变层数的纯单变量因果比较。相同曝光和相近矩阵运算量各回答不同问题，两轴结果都报告。

## 训练、选模和评价

所有组沿用uniform历史查询＋1.0粗结构＋0.25断开编码器梯度的局部诊断目标。主查询输入只有一个768维bar状态和相对历史距离；标签只有当时可见历史。粗结构继续为4/16根分组的相对价格位置/变化，影线不作为强重建目标；当前bar七字段作为单独保留检查，不混进历史用途得分。不增加未来预测或一致性损失。

各预算epoch0可回退；验证使用原32/64/96/128查询及64/128同末端过去16根和远处65..127结构。query/近期/远处相对epoch0保留5%，差异与远处分项保留10%；在合格轮次按near/far最差相对误差、均值、早轮次选模。48/80/112仍只用于研究评价。LR选择在完整验证轨迹上完成，所有20份选中best/last锁定后才拟合13用途目标×原五档alpha，共1300个闭式候选，并统一进入研究集。

五个正式比较：d8/d4、d12/d4、d12/d8、d8/d4_c8、d12/d4_c12。每比较独立报告近期至少5%改善、远处至少5%改善、原能力保留和用途至少5%增益；同一改善路线须覆盖两个种子×两个研究集合×best/last。近期、远处、查询分项、共同历史、用途及当前字段仍受保护，原raw/PCA/current完整用途协议独立报告。两个预算轴都支持才记录对应深度候选；不按通过比例晋升，不凭某个种子或最后loss选赢家。

研究test/cross已多轮使用，周级区间未作多重比较校正，不冒称最终独立确认。失败只约束本次来源、identity扩层、两档LR及训练预算，不证明深度方向无效；末尾曲线仍下降也不自动追加训练。固定矩阵结束即归档，后续根据表示与用途收益决定保留、收束或独立确认。

## AutoDL运行与导出

默认两个worker、micro8组三视图，有效batch128组不变。12GB3080Ti优先保证深层双并行可运行；更换micro需新输出目录，并重新通过实际micro的零更新反向检查。默认环境保持来源Torch/NumPy版本。

```bash
cd /root/autodl-tmp/obson
git pull --ff-only origin features/babel
mkdir -p logs
nohup bash scripts/babel_depth768_autodl.sh all > logs/babel_depth768.log 2>&1 &
tail -f logs/babel_depth768.log
```

按上一轮实际state大小推算，本轮峰值需约18GiB可用磁盘（包括暂存和余量），完成后阶段权重约7.2GiB；脚本仍以实际模型大小重新计算，数字不是绕过磁盘检查的承诺。启动前验证保留来源/数据身份、原评分数值回放、因果性及新层实际梯度通路；基于实际模型state、Adam矩、阶段快照、并行原子保存临时文件估算磁盘，另留25%和1GiB报告空间。每个worker全部完成并写入可核验完成清单后，才清理本次worker冗余的`last.pt/best.pt`临时恢复文件；所有预算节点的`e100/e191/e281_best/last.pt`、训练历史与选择凭据保留，原来源权重不动。未完成worker继续保留Adam/RNG；跨完成写入中断也可恢复核验。显存检查使用实际micro零更新前后向峰值加Adam/并行余量，不能保证覆盖所有驱动分配差异；不足在训练前退出，无自动删除。可用`BABEL_DEPTH_JOBS=1`减少并行而保持同输出恢复；更改micro或研究配置须新目录。

按上一轮3080Ti实际速度，本完整双LR/双预算矩阵暂按30–40小时安排；不是完成保证，逐worker日志报告实测秒/轮和该worker剩余时间，全部训练后另做统一评价。不开新训练轮数网格。
