# 完整月份合约批次的数据资格核对

F02/F04/F10 的本地 CPU 核对给出真实合约各收盘端点可回读的报价范围，以及 F11 的方向分类、极值顺序样本。读取月份合约原价，主连仅提供时钟见证，映射仅提供交易日和合约身份。指数、主连价格、旧权重均无数据通路。运行绑定 configs/protocol.json 的交付清单、说明、月份窗口、映射与元数据 SHA。t 是上海时区分钟结束时刻，源文件 datetime 是分钟开始时刻。每个输入在解码前按实际字节校验 SHA，与同次读取的 Parquet 字节绑定。

## 样本含义

- 有效报价要求同一合约有限、正价且 OHLC 边界合法。每份源窗口独立起算；同完整交割年月的窗须无时间重叠。郑商所三位月码用注册窗口内该合约确为主力的日期解出唯一交割年月，不用今天的合约简称拼十年前的数据。源端空交付以原 checkpoint 登记。
- 严格时钟采用连续墙钟分钟，另接同一天的固定日间小休或午休，要求同品种主连上两端相邻且日期在映射内。商品采用 10:14→10:30、11:29→13:30，股指采用 11:29→13:00（均为分钟起点）。这是该源表口径的可核查下界。扩展时钟另允许收盘→夜盘、夜盘→日盘或相邻映射交易日的日盘→日盘，要求端点为已知边界、同时是主连相邻两行。其历史逐日休市及夜盘变更仍须签发，不能把两数据源的共同缺失证明为正常休市。主连有中间分钟、时间证据缺失、报价无效均切断。输出分别计数。运行卡中的交易所链接作规则参照，不将当前快照倒推为十年历史规则。
- 1/5/15/60 分钟各按 256/128/64/64 个位置封顶。粗栏以日间每个连续交易小节开盘、夜盘 21:00 为原点，夜盘跨午夜。只保留分钟齐全的格子；日间按小节已知收盘保留有真实时长的尾格，夜盘只取完整周期。O/H/L/C 来自首开、最高、最低、末收。给定 C_t，使用能落在最近一分钟视图同一条已知价格链的最新粗栏收盘，沿该周期连续完整栏的价比反推；只计有此构造证书的栏，更远处标未证，不能推断必然需要新锚。相邻回报的合法系数来自该窗自己的开盘对前收和实体。按周期计实际闭合源栏、每端点可读栏、剔除当前已给收盘的严格过去查询及全窗口覆盖。一个源栏可以被多个端点查询，查询数不同于唯一源栏数。FP64 还原检查在每条链以不超过各视图容量的小段锚核对 O/H/L/C；这是数据变换的数值误差。未核历史跳价的合约不据此签发逐跳模型精度。
- 分类需要 65 个连续有效收盘产生 64 个收益。以净对数涨跌除以绝对涨跌之和，达到 +0.5/-0.5 归上行/下行主导，中间与全平归方向不明显。顺序用 37 个收盘，重复极值取首次，全平独列。成交为零的源 bar 保留原标记，另报全窗每分钟成交为正的子集。18 项需要 257 个收盘和最后 256 根量仓支持；数值齐全仅为源单位口径，历史量仓单位尚未全期签发。
- 2016–23、2024、2025 至旧分钟起点截止、之后分别列出；IF/SA/lh/sn/OI 单列为留品种候选。标签不越分区。自然输入的额外保守清除，要求源窗口起点已在本分区，或各周期在新边界后有至少容量加 65 个完整栏，以覆盖最长输入与波动预热。源窗口首端冷启动允许。同期市场周按周一合并，仅用于覆盖，不能充当已证独立样本。合约窗口按当时整理的主力与换月边缘选择，选择偏差仍在。汇总不用于选模型，V13 独立资格仍开放。
- 更强顺序题使用每源文件零基行号 511 起每隔 4096 行的固定抽样，跨分区、量仓不全或四周期没有完整连续支持分别计原因。依路线图找首组合格三根活跃分钟，在同一价格对比等权区及同一已闭合 5/15/60 分钟父栏内交换构造的极值。元数据跳价只接受匹配交割年月的快照值。原分钟重算、核对三根聚合、全 160 个 FP32 值，以及原价量定义的 18 个 FP64 数；持仓尺度暂用 1，对两条路径相同的原量仓在共同尺度下仍相同。三根聚合及所有未改分钟相同意味着各完整父栏相同。未提供按历史日生效的涨跌停价、跳价版本与最终量仓合同，因此通过计作待签的代数候选。自然顺序不依赖这些反事实条件。
- 填空的来源筛选要求在同一当前可追溯的最近 256 分钟里存在两段严格早于 t、互不重叠的连续 8 分钟合法报价。真正的模型遮挡闭包与数值前反向不在本次审计。


reports/completed_months_20261127 保存结果、按品种/合约/分区统计、周覆盖、源文件与每个本地资产 SHA。runs 同名目录存逐端点索引，原价序列不入 Git。查询脚本 src/lookup.py 接受完整合约如 SHFE.rb202210 及上海收盘时间。代码 0 表示无资格，分类 1/2/3 为下行/方向不明显/上行，顺序 1/2/3 为高先/低先/全平。标签类别本身按扩展时钟，严格、活跃、分区清除需结合相应标志。NPZ 的分钟、各周期栏起末行及每端点可达栏数可定位具体历史查询。价位连接证书给出可核对的范围；没有证书的区间仍保留原始真值。训练期示例单列，完整结果的使用范围见同期资格报告。
